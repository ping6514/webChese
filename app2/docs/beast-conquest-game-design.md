# 獸穴征服 - 完整遊戲設計文檔

**遊戲名稱**：獸穴征服（Beast Conquest）  
**類型**：回合制策略卡牌遊戲  
**主題**：奇幻國戰 + 魔物娘  
**版本**：3.0  
**更新日期**：2026-03-21

---

## 📋 遊戲概述

### 世界觀

在這個世界，各個魔物種族為了爭奪領地而戰。每個種族由強大的魔物娘首領統領，她們率領各自的軍團，攻略敵方的獸穴。

### 勝利條件

將敵方獸穴生命值降至 0 → 我方勝利 ⭐

---

## 🎮 核心機制

### 遊戲模式

1. **對戰模式**（PvP）
   - 玩家 vs 玩家
   - 自訂牌組（40-60 張）
   - 線上對戰

2. **單機模式**（PvE）
   - 爬塔挑戰（30 層）
   - Roguelike 機制
   - 遺物系統
   - 超模敵人

### 區域說明

**我方獸穴**：
- 起始位置
- 有結界石保護（4 個）
- 可放置防禦工事（最多 2 層）

**戰場**：
- 中立區域
- 雙方爭奪
- 可放置防禦工事（最多 2 層）

**敵方獸穴**：
- 攻略目標
- 有結界石保護（4 個）
- 可放置防禦工事（最多 2 層）

### 防禦工事系統

```
防禦工事（原磚堆）：
- 每個區域最多 2 層
- 阻擋首領移動
- 需要清除才能通過
- 被清除時，擁有者抽 1 張牌
```

## 👑 首領系統

### 首領配置

```
對戰模式：4 位首領（固定）
單機模式：1-4 位首領（隨關卡增加）
```

### 首領卡結構

```typescript
type LeaderCard = {
  id: string
  name: string
  race: RaceType  // 種族
  class: ClassType  // 職業
  
  // 基礎屬性
  baseToughness: number  // 堅韌度（HP）
  baseSupport: number    // 協助力
  baseAttack: number     // 對敵力
  
  // 被動能力
  passive: {
    name: string
    description: string
    effect: Effect
  }
  
  // 主動技能（只有 1 個）
  skill: {
    name: string
    cost: Cost
    cooldown: number
    counterCost?: Cost
    counterCooldown?: number
    canCounter: boolean
    effect: Effect[]
  }
  
  // ⭐ Tags 系統
  tags: Tag[]  // 種族、職業、特殊屬性標籤
  
  // ⭐ 連動支援（取代固定聯合攻擊）
  linkSupport?: {
    name: string
    condition: (partner: Leader) => boolean  // 連動條件
    bonus: {
      attackBonus?: number      // 對敵加成
      supportBonus?: number     // 協助加成
      additionalEffects?: Effect[]  // 額外效果
    }
  }
  
  // 軍團槽
  legionSlots: number  // 1 或 2
}
```

### 種族系統（6 種）⭐ 魔物娘主題

```
1. 哈比族（Harpy）

   - 特色：高機動、空中優勢

   - 主題：蛇人、娜迦

   - 代表色：紫色

3. 龍族（Dragon）
   - 主題：龍娘、龍人
   - 特色：高攻擊、高堅韌
   - 協同：對敵+1，清除防禦工事+1
   - 代表色：紅色

4. 史萊姆族（Slime）
   - 主題：史萊姆娘
   - 特色：分裂、復原

5. 半人馬族（Centaur）
   - 主題：馬娘、鹿娘

6. 海族（Aquatic）
   - 主題：人魚、海龍、魚人
   - 特色：治療、水流

   - 代表色：藍色
```

### 職業系統（4 種）

```
1. 破壞者（Destroyer）
   - 特色：清除防禦工事、範圍攻擊
   - 代表種族：龍族、史萊姆族

2. 征服者（Conqueror）
   - 特色：高機動、單體爆發
   - 代表種族：哈比族、半人馬族

3. 統御者（Commander）
   - 特色：遠程、控制、輔助
   - 代表種族：拉米亞族、海族

4. 守護者（Guardian）
   - 特色：高防禦、修建防禦工事
   - 代表種族：龍族、史萊姆族
   - 特殊能力：可執行「修建防禦工事」通常動作
```

### 首領狀態 ⭐

```
1. 普通狀態（Normal）
   - 可正常行動
   - 可提供協助力
   - 可參與聯合攻擊

2. 暈眩狀態（Stunned）
   - 無法主動行動
   - 可提供協助力（被動）
   - 可參與聯合攻擊（被動）
   - 再受傷 → KO
   - 回合結束時自動恢復為普通狀態

3. KO 狀態（KO_Turn1, KO_Turn2）⭐
   - 立即退回我方獸穴
   - 無法行動
   - 無法提供協助力
   - 無法參與聯合攻擊
   - 無法被攻擊（在基地內）
   - 所有軍團觸發「首領被擊破時」效果
   - KO_Turn1 → KO_Turn2 → Reviving

4. 復活中狀態（Reviving）⭐
   - 補充階段開始時可選擇復活位置
   - 選項 A：我方獸穴（安全）
   - 選項 B：戰場（如果沒有防禦工事）
   - 選項 C：特殊能力指定位置
   - 復活後變為普通狀態
```

## ⚔️ 軍團系統

### 軍團卡結構

```typescript
type LegionCard = {
  id: string
  name: string
  race: RaceType
  type: LegionType
  rank: 'normal' | 'elite' | 'legendary'  // ⭐ 軍團等級
  toughness: number  // 堅韌度（可被擊破）
  
  // ⭐ Tags 系統
  tags: Tag[]  // 種族、類型、等級、特殊屬性標籤
  
  // ⭐ 召喚需求（升級召喚）
  summonCost?: {
    tributeCount: number  // 需要獻祭的軍團數量
    tributeRace?: RaceType  // 獻祭的種族限制（可選）
  }
  
  // 被動能力（自動生效）
  passive: {
    name: string
    effect: Effect
  }
  
  // ⭐ 首領被擊破時的處理
  onLeaderKO?: {
    type: 'discard' | 'keep' | 'choice'  // 丟棄/保留/選擇
    cost?: Cost  // 保留時需要支付的代價
    effect?: Effect  // 額外效果
  }
  
  // 主動技能（消耗手牌發動）
  activeSkill?: {
    name: string
    cost: Cost
    cooldown: number
    effect: Effect
  }
  
  // 犧牲技能（捨棄本卡發動）
  sacrificeSkill?: {
    name: string
    effect: Effect
  }
  
  // 協同效果
  synergy?: {
    condition: (leader: Leader) => boolean
    bonus: Effect
  }
  
  // 擊破效果
  onDestroy?: Effect
}
```

```
1. 步兵（Infantry）
   - 堅韌度：3-5
   - 特色：防禦、坦克

2. 騎兵（Cavalry）
   - 堅韌度：2-4
   - 特色：機動、突襲

3. 弓箭手（Archer）
   - 堅韌度：2-3
   - 特色：遠程、對敵

4. 法師（Mage）
   - 堅韌度：2-3
   - 特色：魔法、技能增益

5. 攻城器械（Siege）
   - 堅韌度：4-6
   - 特色：破壞、清除防禦工事
```

### 軍團等級系統 ⭐

```
1. 普通軍團（Normal）
   - 堅韌度：2-4
   - 召喚方式：通常召喚或特殊召喚
   - 獻祭需求：無

2. 精英軍團（Elite）
   - 堅韌度：5-7
   - 召喚方式：獻祭 1 個軍團
   - 獻祭需求：1 個普通軍團

3. 傳說軍團（Legendary）
   - 堅韌度：8-10
   - 召喚方式：獻祭 2 個軍團
   - 獻祭需求：2 個軍團（至少 1 個精英）
```

### 軍團召喚系統 ⭐

#### 通常召喚（Normal Summon）

```
規則：
- 每回合只能進行 1 次通常召喚
- 在裝備階段進行
- 從手牌安裝軍團卡到首領
- 不需要額外條件

限制：
- 1 回合 1 次
- 消耗手牌
- 需要有空的軍團槽
```

#### 特殊召喚（Special Summon）

```
規則：
- 通過特定效果觸發
- 不計入通常召喚次數
- 可以在任意時機（依效果而定）
- 可以從手牌、墓地、牌組召喚

觸發方式：
- 首領技能
- 軍團卡效果
- 事件卡
- 建築卡效果
- 軍團擊破觸發
```

#### 升級召喚（Tribute Summon）⭐

```
規則：
- 獻祭場上的軍團召喚更強大的軍團
- 不計入通常召喚次數
- 算作特殊召喚

流程：
1. 選擇要召喚的高級軍團（從手牌）
2. 檢查獻祭需求
3. 選擇要獻祭的軍團（從場上）
4. 執行獻祭（軍團進墓地，觸發擊破效果）
5. 召喚高級軍團

範例：
- 精英軍團：獻祭 1 個普通軍團
- 傳說軍團：獻祭 2 個軍團（至少 1 個精英）
```

#### 安裝規則

```
安裝時機：裝備階段

限制：
- 每位首領基礎 1 個軍團槽
- 部分首領/技能可擴充至 2 個軍團槽
- 通常召喚：1 回合 1 次
- 特殊召喚/升級召喚：依效果而定
```

### 軍團技能發動 ⭐

```
行動階段可使用：

1. 首領技能
   - 消耗手牌
   - 有冷卻

2. 軍團主動技能
   - 消耗手牌
   - 有冷卻
   - 獨立於首領技能

3. 軍團犧牲技能
   - 捨棄軍團卡
   - 發動強力效果
   - 無冷卻（因為軍團被犧牲）
```

### 軍團擊破機制

```
軍團擊破條件：

1. 受到對敵攻擊
   - 敵人對首領進行對敵時
   - 可選擇攻擊軍團而非首領
   - 軍團堅韌度歸 0 → 擊破

2. 主動犧牲
   - 使用犧牲技能
   - 軍團卡進入墓地

3. 區域效果
   - 某些技能/建築會破壞軍團

擊破效果：
- 軍團卡進入墓地
- 觸發擊破效果（如果有）
- 首領失去該軍團的被動能力
```

### 軍團替首領擋傷機制

```
對敵流程：

1. 敵人宣告對首領進行對敵
   ↓
2. 首領擁有者選擇：
   a) 首領直接受傷
   b) 軍團替首領擋傷害
   ↓
3a. 首領受傷：
   - 正常對敵判定
   - 可以反擊
   - 可以觸發戰術卡
   ↓
3b. 軍團擋傷害：
   - 軍團堅韌度-X
   - 軍團堅韌度歸 0 → 擊破
   - 觸發軍團擊破效果
   - 首領不受傷
```

## 🔄 回合流程

### Step 1：補充階段

可進行以下行為 **2 次**：
1. 將牌庫 1 張牌抽取至手牌
2. 將牌庫 1 張牌放在我方戰場防禦工事或我方獸穴防禦工事（1 回合只能 1 次）

**牌庫規則**：
- 若抽牌時牌組為空，則把墓地的卡牌重新洗牌放在牌組下方

---

### Step 2：主要階段

- 可以打出 **1 張建築卡**
- 可以打出 **複數事件卡**

---

### Step 3：行動階段

選擇本回合沒有執行過行動流程的首領進行 1 次行動（1 回合最多 4 次）

**行動流程**：

1. **移動首領**（可停留原地）
   - 移動到相鄰區域
   - 如果目標區域有防禦工事，無法移動（需先清除）
   - 守護者特殊：可以停留原地修建防禦工事

2. **選擇行動類型**（2 選 1）：

   **選項 A：單獨行動**
   - 選擇 1 位未行動的首領
   - 消耗 1 次行動
   
   **選項 B：聯合攻擊** ⭐
   - 選擇 2 位未行動的首領（同區域，都是普通狀態）
   - 消耗 2 次行動
   - 基礎對敵力 = 首領 A 對敵 + 首領 B 對敵
   - 基礎協助力 = 首領 A 協助 + 首領 B 協助
   - 檢查連動支援：
     * 首領 A 的連動支援條件滿足 → 加成
     * 首領 B 的連動支援條件滿足 → 加成
   - 總傷害 = (基礎對敵力 + 連動加成) + (基礎協助力 + 連動加成)

3. **執行通常動作**（4 選 1）：
   
   a) **清除防禦工事**
   - 移除敵對應位置的防禦工事 1 層
   - 被清除的玩家抽取 1 張卡
   
   b) **對敵** ⭐
   - 使用對敵力對敵人的首領或軍團進行攻擊
   - 單獨行動：與同位置的 1 位首領的協助力互相疊加
   - 聯合攻擊：基礎傷害 + 連動支援加成
   
   **對敵判定流程**：
   1. 宣告攻擊目標（敵首領或敵軍團）
   2. 計算總傷害
   3. 防禦方選擇：首領受傷 或 軍團擋傷
   4. 傷害判定：
      - 傷害 < 堅韌度 → 無事
      - 傷害 ≥ 堅韌度 → 暈眩（Stunned）
      - 傷害 ≥ 堅韌度 × 2 → 擊破（KO）
      - 已暈眩再受傷 → 擊破（KO）
   5. 首領被擊破處理：
      - 立即回到我方獸穴
      - 狀態變為 KO_Turn1
      - 所有軍團觸發「首領被擊破時」效果
      - 觸發首領被擊破效果（如果有）
   6. 觸發反擊（如果有）
   
   c) **攻略**
   - 條件：對手獸穴沒有防禦工事
   - 效果：對手移除 1 個結界石並抽取 1 張牌
   - 勝利：如果敵此時沒有可以移除的結界石，則我方勝利
   
   d) **修建防禦工事**（守護者專屬）
   - 在當前區域修建 1 層防禦工事
   - 限制：該區域防禦工事 < 2 層

4. **使用技能**（可選，3 選 1）：
   
   a) **首領技能**
   - 消耗手牌
   - 有冷卻
   - 可以反擊（部分技能）
   
   b) **軍團主動技能**
   - 消耗手牌
   - 有冷卻
   - 獨立於首領技能
   
   c) **軍團犧牲技能**
   - 捨棄軍團卡
   - 發動強力效果
   - 無冷卻

---

### Step 4：裝備階段

可以不限次數進行以下操作：

1. **安裝戰術卡**（原反應卡）
   - 從手牌打出戰術卡
   - 安裝到任一首領
   - 1 位首領最多安裝 1 張戰術卡
   - 如果已有戰術卡，可以替換（舊卡進墓地）

2. **召喚軍團卡** ⭐
   
   a) **通常召喚**（1 回合 1 次）
   - 從手牌召喚軍團卡到首領
   - 安裝到軍團槽
   
   b) **特殊召喚**（依效果觸發）
   - 通過技能/事件/建築效果
   - 可從手牌/墓地/牌組召喚
   - 不計入通常召喚次數
   
   c) **升級召喚**（獻祭召喚）
   - 獻祭場上的軍團
   - 召喚更強大的軍團
   - 不計入通常召喚次數

---

### Step 5：結束階段

1. 宣告結束本回合
2. 手牌超過 6 張則捨棄到墓地至 6 張
3. **所有我方首領的技能冷卻 -1**
4. **所有我方軍團的技能冷卻 -1**
5. 將回合交給對手

## 🎴 卡牌系統

### 卡牌類型（5 種）

```
1. 首領卡（4 張）
   - 不計入牌組
   - 遊戲開始時直接配置

2. 軍團卡
   - 可安裝到首領
   - 有堅韌度，可被擊破

3. 戰術卡（原反應卡）
   - 觸發式效果
   - 安裝到首領

4. 建築卡
   - 放置在區域
   - 有堅韌度，可被破壞

5. 事件卡
```
