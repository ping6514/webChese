## 🔧 核心概念速查

### ATB 系統
- Tick 間隔：100ms
- 充能公式：`(speed / 100) × 10` per tick
- 達到 100 時獲得回合

### 動作時間
| 動作 | 時間 |
|------|------|
| 移動 | 0.7s |
| 待機 | 0.3s |
| 攻擊 | 3.5-5.6s |

### 攻擊範圍類型
- **melee**：前方扇形 3 格
- **projectile**：直線 2 格
- **zone**：半徑 1 格
- **arcane_cast**：十字 1 格
- **breath**：前方扇形 3 格
