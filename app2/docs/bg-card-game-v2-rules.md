## 🎮 遊戲基本規則

### 勝利條件
在敵人城牆區為 0 的情況下，讓 BG 進行攻城動作成功 → 我方勝利

### 場地結構
```
┌─────────────┬─────────────┬─────────────┐
│ 我方主堡區   │   廣場區     │  敵主堡區    │
│             │             │             │
│ [BG] [BG]   │  [BG] [BG]  │  [敵] [敵]  │
│ [BG] [BG]   │             │  [敵] [敵]  │
│             │             │             │
│ 磚堆: ██    │  磚堆: ██   │  磚堆: ██   │
│ 城牆: ●●●● │             │  城牆: ●●●● │
└─────────────┴─────────────┴─────────────┘
```

### 牌組規則
- **牌組數量**：40-60 張
- **同名卡限制**：最多 3 張
- **手牌上限**：6 張
- **起始手牌**：先攻 5 張，後攻 7 張
- **調度**：可進行 1 次（全部洗回重抽）

### 遊戲開始準備
1. 擺放 4 個指示物作為城牆
2. 在我方廣場區磚堆與我方主堡區磚堆各抽取 2 張牌蓋上（代表磚堆 2 層）
3. 配置 4 位 BG 卡在我方主堡區域

## 🔄 回合流程

### Step 1：補充階段
可進行以下行為 **2 次**：
1. 將牌庫 1 張牌抽取至手牌
2. 將牌庫 1 張牌放在我方廣場區磚堆或我方主堡區磚堆（1 回合只能 1 次）

**牌庫規則**：
- 若抽牌時牌組為空，則把墓地的卡牌重新洗牌放在牌組下方

### Step 2：主要階段
- 可以打出 **1 張建築卡**
- 可以打出 **複數事件卡**

### Step 3：行動階段
選擇本回合沒有執行過行動流程的 BG 進行 1 次行動（1 回合最多 4 次）

**行動流程**：
1. 移動角色（可以停留在原地）
2. 執行通常動作（清磚/對敵/攻城）
3. 可在任意時機使用 **1 次技能**（⭐ 新增：受冷卻限制）

### Step 4：反應階段
可以不限次數在沒有安裝反應卡牌的任一 BG 安裝反應卡牌
- 1 位 BG 最多安裝 1 個反應卡
- 如果安裝反應卡時已經有反應卡，則可以丟棄舊反應卡安裝新的

### Step 5：結束階段
1. 宣告結束本回合
2. 手牌超過 6 張則捨棄到墓地至 6 張
3. **⭐ 新增：所有我方 BG 的技能冷卻 -1**
4. 將回合交給對手

## ⚔️ BG 角色系統

### BG 屬性
```
名稱：角色名稱
職業：BOM / ATK / SHT / BLC
堅韌度：HP（每回合恢復至基本值）
協助力：協助其他 BG 對敵時的加成
對敵力：攻擊時的基本傷害
技能 1：通常技能
技能 2：究極技能
```

### BG 狀態
1. **普通狀態**（正放）：可正常行動
2. **暈眩狀態**（橫放）：無法主動行動，再受傷 → KO
3. **KO 狀態**（倒放）：退回主堡區，2 回合後恢復

### 通常動作（3 選 1）

#### 1. 清磚
- 移除敵對應位置的磚堆
- 被清除的磚堆的玩家需要從對應的磚堆抽取 1 張卡進手牌

#### 2. 對敵
- 使用對敵力對敵人的 BG 進行攻擊判定
- 與同位置的 1 位 BG 的協助力互相疊加
- 判定公式：`(對敵力 + 協助力) vs 堅韌值`
- 超過 → 暈眩
- 超過 2 倍或暈眩再受傷 → KO

#### 3. 攻城
- 條件：對手主堡區沒有磚堆
- 效果：對手移除 1 個城牆指示物並抽取 1 張牌
- 勝利：如果敵此時沒有可以移除的城牆指示物，則我方勝利

## ⭐ 技能系統（新版）

### 技能使用規則

#### 主動使用
```
技能使用條件：
1. ✅ 支付手牌消耗（任*N 或 技*N）
2. ⭐ 技能冷卻為 0
3. ✅ BG 為普通狀態（部分技能例外）
4. ✅ 滿足技能的使用條件（如位置限制）

技能使用後：
1. 執行技能效果
2. 設置技能冷卻
```

#### ⭐ 反擊使用（新增）
```
反擊觸發條件：
1. ✅ 本 BG 受到對敵攻擊時
2. ✅ 技能標註「可反擊」
3. ✅ 技能冷卻為 0
4. ✅ 支付反擊消耗（通常比主動使用更高）
5. ✅ 在 30 秒內決定是否發動

反擊效果：
1. 執行技能效果
2. 閃避這次受到的傷害
3. 設置反擊冷卻（比主動使用更長）
```

### 冷卻機制

```typescript
技能冷卻規則：
- 技能使用後進入冷卻
- 冷卻期間無法再次使用該技能
- 每個我方回合結束時，所有我方 BG 的技能冷卻 -1
- 冷卻歸 0 時，技能可再次使用

主動使用冷卻時間：
- 技能 1（通常技能）：1 回合
- 技能 2（究極技能）：2 回合

⭐ 反擊使用冷卻時間（懲罰）：
- 技能 1：2 回合（+1 回合懲罰）
- 技能 2：3 回合（+1 回合懲罰）
```

### 技能類型

#### 技能 1（通常技能）
- **消耗**：任*1-2
- **冷卻**：1 回合
- **特點**：使用頻率高，效果適中

#### 技能 2（究極技能）
- **消耗**：技*1 + 任*1-2
- **冷卻**：2 回合
- **特點**：需要技能牌，效果強大

#### 小白（BOM）

```
技能 1：穿刺炸彈
消耗：任*1
冷卻：1 回合（主動） / 2 回合（反擊）
條件：僅在非我方主堡區域發動
效果：敵主堡區清磚 1 & 敵廣場區清磚 1
```

#### 小橘（ATK）- 可反擊技能範例

```
消耗：技*1（主動）
反擊消耗：技*1 + 任*2 ⭐
冷卻：2 回合（主動） / 3 回合（反擊）⭐
可反擊：暈眩狀態也可使用 ⭐
效果：1 回合堅韌度+4
      回復暈眩狀態
```

#### 其阿莫（ATK）- 可反擊技能範例

```
消耗：技*1（主動）
反擊消耗：技*1 + 任*1 ⭐
冷卻：2 回合（主動） / 3 回合（反擊）⭐
可反擊 ⭐
效果：1 回合堅韌度+2
      區域內 1 位敵 BG 對敵 3
      區域內清磚 1
      反擊時閃避這次傷害 ⭐
```

### 使用範例

#### 主動使用範例
```
回合 1（我方回合）：
- 小白使用技能 1 → 技能 1 冷卻 = 1
- 小黑使用技能 1 → 技能 1 冷卻 = 1
- 小橘使用技能 2 → 技能 2 冷卻 = 2
- 其阿莫使用技能 1 → 技能 1 冷卻 = 1

回合 1 結束：
- 所有 BG 冷卻 -1
- 小白：技能 1 冷卻 = 0（可用）
- 小黑：技能 1 冷卻 = 0（可用）
- 小橘：技能 2 冷卻 = 1（還要等 1 回合）
- 其阿莫：技能 1 冷卻 = 0（可用）

回合 2（敵方回合）：
- 冷卻不減少（只有我方回合結束時才減少）

回合 3（我方回合）：
- 小白可以再次使用技能 1 ✅
- 小橘技能 2 冷卻 = 1（還要等）

回合 3 結束：
- 小橘：技能 2 冷卻 = 0（可用）✅
```

#### ⭐ 反擊使用範例
```
回合 2（敵方回合）：
- 敵方小白對我方小橘進行對敵（傷害 4）
- 系統提示：小橘可以發動反擊「午餐時間」
  消耗：技*1 + 任*2
  效果：堅韌+4，回復暈眩，閃避傷害
- 玩家選擇發動反擊
- 支付：1 張技能牌 + 2 張任意牌
- 效果：小橘堅韌+4（1 回合），閃避 4 點傷害
- 冷卻：技能 2 冷卻 = 3（反擊懲罰）⭐

回合 3（我方回合結束）：
- 小橘：技能 2 冷卻 = 2

回合 4（敵方回合）：
- 冷卻不變

回合 5（我方回合結束）：
- 小橘：技能 2 冷卻 = 1

回合 7（我方回合結束）：
- 小橘：技能 2 冷卻 = 0（可用）✅

結論：反擊使用後需要等 3 個我方回合才能再次使用
```

## 🛡️ 反應卡系統

### 反應卡規則
- 安裝在 BG 下方
- 觸發條件滿足時可以發動
- **⭐ 新增：每回合每張反應卡最多觸發 1 次**
- 回合結束時重置觸發標記

### 反應卡列表

#### 1. 閃避（ALL）
- 觸發：本 BG 受到對敵判定時
- 效果：那個對敵改為 0，抽 1 張牌

#### 2. 冷靜思考（ALL）
- 觸發：此 BG 進入 KO 狀態時
- 效果：抽 3 張牌

#### 3. 阻擋（ALL）
- 觸發：本 BG 區域內的敵 BG 進行「清磚動作」時
- 效果：無效那次清磚並抽 1 張牌

#### 4. 玉石俱焚（ALL）
- 觸發：本 BG 進入暈眩狀態時
- 效果：區域內的 1 位敵 BG 對敵 5

#### 5. 誤導（ALL）
- 觸發：本 BG 受到「對敵行動」時
- 效果：那個對敵改為 0，本區域清磚 1

#### 6. 靈動（ATK）
- 觸發：本 BG 受到對敵時
- 效果：1 回合堅韌+4，並且可以執行一次角色移動（無視磚堆阻擋）

#### 7. 威嚇（SHT）
- 觸發：敵 BG 移動角色動作時進入本 BG 所在的區域時
- 效果：對方玩家選擇一項執行：
  - A. 該 BG 受到對敵 4
  - B. 回到移動前的位置

- 主要階段可打出複數張事件卡

```
❌ 單一角色 spam
- 回合 1：小白技能 1 × 4 次
```

```
- 回合 2：冷卻恢復，可再次使用
- 結果：需要規劃技能使用時機
```

### 技能規劃
1. **技能 1**：1 回合冷卻，可頻繁使用
2. **技能 2**：2 回合冷卻 + 需要技能牌，關鍵時刻使用
3. **輪流使用**：確保每回合都有 BG 可以使用技能
4. **保留技能牌**：為關鍵回合準備究極技能

### 資源管理
1. **手牌**：技能消耗 vs 保留好牌
2. **技能牌**：稀缺資源，謹慎使用
3. **磚堆**：防禦 vs 抽牌資源
4. **城牆**：生命值，需要保護

## 🔧 技術實作要點

### 新增資料結構
```typescript
type BGInstance = {
  id: string
  cardId: string
  zone: ZoneId
  state: 'normal' | 'stunned' | 'ko'
  toughness: number
  
  // ⭐ 新增：技能冷卻
  skill1Cooldown: number  // 剩餘冷卻回合數
  skill2Cooldown: number
  
  // ⭐ 新增：反應卡觸發標記
  reactionCard: {
    cardId: string
    triggeredThisTurn: boolean
  } | null
  
  hasActed: boolean
}
```

### 核心邏輯
```typescript
// 1. 檢查技能是否可用
function canUseSkill(bg: BGInstance, skillNum: 1 | 2): boolean {
  const cd = skillNum === 1 ? bg.skill1Cooldown : bg.skill2Cooldown
  return cd === 0 && bg.state === 'normal'
}

// 2. 使用技能
function useSkill(bg: BGInstance, skillNum: 1 | 2) {
  // 支付消耗、執行效果...
  
  // 設置冷卻
  if (skillNum === 1) {
    bg.skill1Cooldown = 1
  } else {
    bg.skill2Cooldown = 2
  }
}

// 3. 回合結束時
function onTurnEnd() {
  // 減少冷卻
  for (const bg of myBGs) {
    bg.skill1Cooldown = Math.max(0, bg.skill1Cooldown - 1)
    bg.skill2Cooldown = Math.max(0, bg.skill2Cooldown - 1)
    
    // 重置反應卡觸發標記
    if (bg.reactionCard) {
      bg.reactionCard.triggeredThisTurn = false
    }
  }
}
```

## 🛡️ 反擊系統詳解

### 反擊機制說明

**反擊**是一種特殊的技能使用方式，允許 BG 在受到對敵攻擊時，支付額外代價發動技能來反制。

### 反擊 vs 主動使用 vs 反應卡

| 特性 | 主動使用 | 反擊使用 | 反應卡 |
|------|---------|---------|--------|
| **觸發時機** | 行動階段 | 受到對敵時 | 特定事件時 |
| **消耗** | 基本消耗 | 額外消耗 ⭐ | 無（已安裝） |
| **冷卻** | 標準冷卻 | 懲罰冷卻 ⭐ | 無 |
| **閃避傷害** | ❌ 否 | ✅ 是 | ✅ 是（部分） |
| **效果** | 完整效果 | 完整效果 | 固定效果 |
| **需要安裝** | ❌ 否 | ❌ 否 | ✅ 是 |

### 反擊的優勢
1. ✅ 可以在受攻擊時立即反制
2. ✅ 閃避傷害（價值極高）
3. ✅ 執行完整技能效果
4. ✅ 部分技能可在暈眩狀態使用
5. ✅ 打亂對手節奏

### 反擊的代價
1. ❌ 消耗更多手牌（獨立參數設定）
2. ❌ 冷卻懲罰（+1 回合）
3. ❌ 需要即時決定（30 秒）
4. ❌ 不是所有技能都能反擊

### 反擊流程

```
1. 敵方 BG 對我方 BG 進行對敵
   ↓
2. 系統檢測：我方 BG 是否有可反擊技能？
   - 技能標註「可反擊」
   - 技能冷卻為 0
   - 手牌足夠支付反擊消耗
   ↓
3. 顯示反擊選項（30 秒決定）
   ┌─────────────────────────────┐
   │ ⚠️ 即將受到 X 點傷害！      │
   │                             │
   │ 是否發動反擊？              │
   │ 技能：XXX                   │
   │ 消耗：技*1 + 任*2           │
   │ 冷卻：3 回合（反擊懲罰）    │
   │                             │
   │ [發動反擊] [放棄]           │
   └─────────────────────────────┘
   ↓
4a. 選擇發動：
   - 支付反擊消耗
   - 執行技能效果
   - 閃避這次傷害
   - 設置反擊冷卻（+1 懲罰）
   ↓
4b. 選擇放棄：
   - 正常受到傷害
   - 檢查反應卡（如有）
```

### 反擊技能設計原則

#### 消耗設計
```
反擊消耗 = 主動消耗 + 額外代價

範例：
主動消耗：技*1
反擊消耗：技*1 + 任*2（額外 2 張任意牌）

理由：
- 反擊可以閃避傷害（價值高）
- 反擊可以打亂對手節奏
- 需要額外代價來平衡
```

#### 冷卻設計
```
反擊冷卻 = 主動冷卻 + 1 回合懲罰

範例：
技能 1：1 回合（主動） → 2 回合（反擊）
技能 2：2 回合（主動） → 3 回合（反擊）

理由：
- 防止反擊過於頻繁
- 增加使用時機的策略性
- 主動使用更有效率
```

### 戰術應用

#### 防禦型使用
```
場景：我方 BG 堅韌度低，即將被擊倒
策略：使用反擊技能
- 閃避致命傷害
- 回復堅韌度（如小橘技能 2）
- 爭取時間重整
```

#### 反制型使用
```
場景：敵方 BG 發動強力攻擊
策略：使用反擊技能
- 閃避傷害
- 反擊對敵（如其阿莫技能 2）
- 扭轉戰局
```

#### 資源管理
```
考量：
- 反擊消耗手牌較多
- 反擊冷卻較長
- 需要權衡：
  ✓ 現在反擊保命
  ✗ 之後無法使用技能
```
