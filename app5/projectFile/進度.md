## v2 核心設計摘要

### 玩法定位
「讀戰況 → 投資資源 → 等待成果」，無即時指揮操作。
類比魔獸爭霸 III 種族機制。

### 三種資源
| 資源 | 來源 | 用途 |
|---|---|---|
| 靈力 | 主堡產出 + 佔領節點 + 擊殺 | 從者生產、建造設施 |
| 經驗 | 擊殺 + 佔領首次 | 隊長技能樹節點 |
| 命運點 | 時間累積 + 摧毀敵方設施 | 計策牌輸送帶加速 |

### 從者系統
- 消耗品，陣亡不復活
- 全局單一生產列，隨機骰出類型（訓練卡影響機率）
- 庫存最多 3 個
- 部署時短暫延遲後補充隊長護盾層
- 軍營節點加速生產

### 小隊結構
- 隊長：多段 HP（護盾層 + 真實 HP），陣亡後裸體復活
- 從者：護盾層實體，有獨立 ATB 攻擊，棋盤上不顯示 ATB
- 棋盤顯示：隊長 HP 條 + 護盾層圓點數量

### 暫停系統
- 事件自動暫停（陣亡/佔領完成/新波次）
- 手動暫停有 CD（以 ATB tick 計）

### 兵種與相剋（5 種從者，相剋只看隊長）
```
普通兵（均衡）/ 高速兵（衝撞）/ 低速兵（高護盾）
遠程兵（破甲）/ 攻城兵（範圍濺射）

相剋鏈：騎士→步兵/弓手，重甲→騎士，步兵→重甲，弓手→步兵
```

### 戰鬥前裝備
- **隊長卡**：隊長本體 + 抽兵偏好 + 固有被動 + 開通被動（戰中解鎖）
- **召喚師裝備卡**：玩家體質（造兵/計策/設施加成、初始資源）

## 架構決策記錄

1. **Pixi.js v8**：地圖需拖曳/縮放，選 Pixi 從頭做
2. **兩時鐘架構**：引擎 tick（120ms÷速度倍率）驅動邏輯；Pixi Ticker（60fps）驅動視覺 lerp
3. **從者為消耗品**：陣亡不復活，讓每次陣亡有補盾資源壓力
4. **相剋只看隊長**：從者純數值層，降低認知複雜度
5. **ATB 不顯示在棋盤**：只在詳情面板顯示，棋盤保持簡潔
6. **無手動指令**：玩家透過 AI 模式切換 + 資源投資影響戰局，事件觸發 + CD 限制手動暫停
