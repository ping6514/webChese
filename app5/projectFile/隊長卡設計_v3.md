# 魔物娘戰場 — 隊長卡設計 v3

> v3 結構：隊長本體 + SP技能 + 從者生產偏好 + 科技樹 + 主堡工具列
> 每張「卡」是角色 × 版本，同角色可有多張不同偏好的卡

---

## 隊長卡結構說明

```
隊長卡
  ├── 隊長本體數值（HP / ATK / DEF / ATB / 移速 / 射程 / 復活延遲 / 佔領速率 / 從者槽）
  ├── SP技能（手動觸發，三種類型：瞬間傷害 / 全局效果 / 區域持續）
  ├── 特殊從者（此卡專屬，加入骰池的強化兵種 × 1）
  ├── 科技樹（戰中消耗經驗解鎖，每場重置）
  │     ├── 節點1（線性，10 exp）
  │     ├── 節點2A / 節點2B（分支擇一，20 exp）
  │     └── 開通被動（全場生效，30 exp）
  └── 主堡工具列（此卡帶入戰場後解鎖的戰中按鈕，限用 N 次）
```

### 從者卡池說明

```
基本卡池（所有玩家永遠有）
  普通兵 / 高速兵 / 低速兵 / 遠程兵 / 攻城兵
  → 基礎數值，便宜，可靠

特殊從者（帶入的隊長卡各提供一種）
  → 對應基礎兵種的強化延伸版，數值更高且有召喚時效果
  → 骰出機率與基礎兵種相同，但效果更強
```

帶 3 張隊長卡 = 骰池共 8 種（5 基礎 + 3 特殊）

## 衝鋒隊長・突破者版（近戰輸出型）

### 隊長本體
```
HP：300    ATK：120    DEF：75
ATB速度：1.0    移速：1.0    射程：1
復活延遲：10 tick    佔領速率：10    從者槽：2
```

### SP技能：「戰吼衝鋒」（瞬間傷害 + 短時強化）
```
向前方直線衝鋒，對沿路每個敵方單位造成 ATK×120% 傷害
抵達最遠格後：自身 ATB速度 +50%，持續 30 tick
冷卻：SP 充滿後可再次觸發（SP 條由受傷和出手累積）

空間類型：直線瞬間
使用時機：敵方多個單位排成一線時效益最高
```

### 特殊從者：「衝鋒騎士」（強化版高速兵）
```
基礎：高速兵強化版
護盾 HP：120    ATK：135    DEF：70
ATB速度：1.3    移速：1.8    射程：1
生產費用：9 靈力    生產時間：35 tick

召喚時效果：
  部署瞬間對當前目標造成 ATK×150% 衝撞傷害，目標 ATB 清零
  （比基礎高速兵的衝撞效果更強）
特性：首次衝撞傷害提升，後續保持高速攻擊節奏
```

### 科技樹
```
節點1（10 exp）：「精銳武裝」
  → 隊長 ATK +20

節點2A（20 exp）：「衝撞訓練」（技能解鎖）
  → 友軍 [cavalry] 從者解鎖「衝撞」：首次接觸敵方打斷目標 ATB

節點2B（20 exp）：「反醪戰術」（tag 傷害加成）
  → 本場所有友軍對 [heavy] 敵方傷害 +30%

開通被動（30 exp）：「衝鋒先鋒」（全場生效）
  → 本場所有小隊進入 fighting 狀态時，ATB 立即 +30
```

### 主堡工具列
```
按鈕：「緊急衝鋒令」（每場限用 2 次）
費用：20 靈力
效果：指定一支己方小隊，移速 +80%，持續 20 tick
用途：快速增援或追擊逃跑敵方
```

## 設計注意事項

- **每場科技樹重置**：鼓勵根據當前戰況動態選擇分支，而不是固定最優解
- **開通被動是全場最強的投資**：30 exp 的門檻讓它不能輕易觸及，逼玩家在「先升分支」vs「搶開通被動」間做選擇
- **主堡工具列次數上限**：防止玩家純依賴按鈕，但在關鍵時刻用出去有明確價值感
- **從者骰池是全場累積的**：帶越多同類偏好的隊長卡，骰出偏好兵種的機率越高，強化了建組邏輯
