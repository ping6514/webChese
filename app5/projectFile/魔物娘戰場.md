# 魔物娘戰場 — 設計文件 v0.5

## 遊戲概念

PvE 爬塔策略遊戲。玩家組建小隊對地城發起進攻，戰鬥全自動，玩家透過調整 AI 策略與升級技能影響戰局。摧毀敵方主堡為主要勝利目標。

**核心體驗**：讀戰況 → 調策略 → 等時機，而非即時微操。

---

## 遊戲大迴圈

```
爬塔（主要推進）
  └─ 戰鬥前：預覽關卡腳本偏向 → 選隊、配置技能
  └─ 戰鬥中：調整 AI 策略、消耗資源升級技能
  └─ 戰鬥後：獲得材料

村莊（塔外系統，待詳細設計）
  └─ 解鎖小隊技能樹
  └─ Roguelite 永久升級（主堡防禦、開局資源、主堡反擊等）
```

---

## 戰鬥骨架

### 基本規則
- 六角棋盤地圖（PvE 不對稱設計，玩家方小、地城方大）
- ATB 時間線驅動，**不暫停**
- 玩家可隨時調整播放速度（×1 / ×2 / ×3）

### 勝敗條件
| 條件 | 說明 |
|---|---|
| 主要 | 摧毀敵方主堡 → 玩家勝；玩家主堡 HP 歸零 → 玩家敗 |
| 可選（關卡腳本） | 存活指定時間、累積資源量、擊敗 Boss |

### 玩家介入方式（不暫停）
- 隨時用 radio 按鈕切換**小隊 AI 策略目標**
- 隨時消耗戰場資源**升級小隊技能**
- 可調整**ATB 播放速度**

## 不對稱地圖設計

玩家扮演**進攻方**，從臨時營地出發推進，逐步佔領地城設施翻轉地形優勢。

### 區域結構（左→右）

```
玩家區(col1-3) → 第一交戰區(col4-12) → 城牆/城門(col13-14) → 地城內部(col15-29) → 敵主堡(col30)

- 城門為可破壞建築，破門才能進入地城內部
- 中央爭奪設施分布在第一交戰區與地城內部之間

## 出兵機制

- 玩家攜帶 **10 個小隊棋子**進入關卡
- 戰鬥前選擇 **5 個**上場部署
- 開戰前可預覽**關卡腳本偏向**（大方向提示），據此調整選隊與技能配置

## 關卡腳本系統（概要）

每場戰鬥是一條**時間軸腳本**，由預設事件積木組合而成：

```
範例時間軸
T+00:00  開局，雙方部署
T+02:30  事件：雜兵小隊出現在中路橋頭
T+05:00  事件：空投突襲，無隊長小隊攻擊玩家基地
T+07:30  事件：中央工坊解鎖（可佔領）
T+10:00  事件：Boss 從地城深處現身
T+13:00  事件：第二波空投
```

- 事件種類：雜兵增援、空投突襲、地形變化、Boss 登場、限時任務觸發
- 開戰前玩家會收到「大方向提示」，但不是完整腳本
- 詳細設計另立文件：`關卡腳本系統.md`

## 敵方單位分類

### 指揮小隊（有隊長）
- 完整 AI 策略，主動推進威脅玩家主堡
- 死亡後在地城出生點復活
- 有技能樹、SP 系統

### 雜兵小隊（無隊長）
- 靜態或半靜態，佔據路線作為路障
- 死亡後**不復活**
- 無技能樹、無 SP
- 擊敗可獲得戰場資源與佔領進度
- 部分由關卡腳本觸發（空投突襲型，攻擊玩家基地）

## 小隊結構

### 組成
```
小隊棋子
├── 隊長（Captain）× 1   ← 玩家攜帶的 10 個主體
└── 從者（Follower）× 1~3  ← 依隊長強度決定槽數
```

槽數規則：隊長本身越強 → 從者槽越少（最多 3 槽）

### 隊長
- 擁有**真實血量**：歸零 → 小隊敗退，等待復活
- 技能樹綁定在隊長身上
- 擁有 **SP 條**，AI 自動依條件發動技能
- 兵種套用六種類型（精英版）

### 從者
- 擁有**護盾值**：優先承傷，歸零後從者死亡（移除）
- 純數值附加，無特殊判定邏輯
- 同類型從者疊加有額外加成
- 3 個同類可解鎖預設特殊效果（規則內預定，非特例）

### 雙層血量與擋槍
```
受傷流程：
  1. 比較所有存活成員的 blockPriority 值
  2. 最高者承傷（同值時隨機）
  3. 從者承傷 → 扣護盾值（歸零 → 從者死亡）
  4. 隊長承傷 → 扣真實血量（歸零 → 小隊敗退）

技能可動態修改 blockPriority（例：從者 HP < 30% 時隊長優先擋槍）
```

### 小隊死亡與復活
- 敗退後在出生點等待復活
- 復活等待時間 = 基礎時間 + 各成員 reviveDelay 加總
- 雜兵小隊死亡不復活

## 屬性標籤系統（Tag System）

傷害計算的雙向標籤，所有單位（隊長+從者）皆適用。

```
atkTags（攻擊屬性）→ 對持有指定 defTag 的目標傷害 +X%
defTags（防禦屬性）→ 來自持有指定 atkTag 的攻擊傷害 -X%
```

### 五種標籤定義

| 標籤 | 適用兵種 |
|---|---|
| 重型 | 重甲兵、重射擊、重裝騎士B |
| 輕型 | 騎兵（一般）、輕射擊 |
| 騎士 | 所有騎兵類 |
| 步兵 | 所有步兵類、重甲兵 |
| 射手 | 輕射擊、重射擊 |

單位可同時持有多個 defTag（例：重甲兵 = [重型, 步兵]）

## 異常狀態系統

### 三種基礎異常

| 狀態 | 效果 | 持續時間 | 主要來源 |
|---|---|---|---|
| 毒 | 每 N 秒扣固定 HP | 較長 | 輕射擊類攻擊 |
| 破甲 | 防禦力 -X% | 中等 | 輕射擊兵種特效 |
| 緩速 | 移速 -X% | 短 | 特定從者/技能 |

### 累積觸發規則

```
1. 攻擊命中 → 目標小隊累積值 +X（小隊共用同一條累積條）
2. 累積值達到閾值 → 異常觸發，計時開始，累積值歸零
3. 持續時間結束 → 狀態消失
4. 狀態期間繼續受同類攻擊 → 只累積下一次觸發，不延長當前持續時間
```

### 未來被動擴充方向（記錄用）
- 特定異常免疫（累積值永遠不增加）
- 累積減免（只增加 X%）
- 觸發閾值提升
- 持續時間縮短

## 六種兵種

### 定義與特色

| 兵種 | 移速 | 兵種共用特效 |
|---|---|---|
| 騎兵 | 高 | 到達目標格觸發衝撞 |
| 步兵 | 中 | 特化目標加成（配置時選定） |
| 重甲兵 | 低 | 被騎兵衝撞自動反擊，騎兵癱瘓 |
| 輕射擊 | 高 | 攻擊附帶破甲效果 |
| 重射擊 | 低 | 攻擊有前搖，前搖結束才造成傷害 |
| 補助 | 中 | 小隊佔領建築時貢獻值翻倍 |

### 相剋關係
```
騎兵     → 剋 步兵、輕射擊、重射擊（衝撞踐踏）
重甲兵   → 剋 騎兵（拒馬癱瘓反擊）
步兵     → 剋 特化目標（騎/重甲/遠程 三選一）
輕射擊   → 剋 步兵（破甲 + 毒累積）
重射擊   → 剋 重甲兵（高傷貫穿）
補助     → 無直接剋制，功能性靈光
```

### 兵種數值走向

| 兵種 | HP | 攻擊 | ATB速度 | 防禦 | 射程 | 擋槍優先 | 復活延長 | 佔領貢獻 |
|---|---|---|---|---|---|---|---|---|
| 騎兵 | 中 | 中 | 高 | 中 | 1 | 高 | 高 | 低 |
| 步兵 | 中 | 中 | 中 | 中 | 1 | 中 | 低 | 中 |
| 重甲兵 | 高 | 高 | 低 | 高 | 1 | 最高 | 高 | 低 |
| 輕射擊 | 低 | 低 | 高 | 低 | 2 | 低 | 低 | 低 |
| 重射擊 | 中 | 最高 | 最低 | 中 | 3~4 | 低 | 高 | 低 |
| 補助 | 中 | 低 | 中 | 低 | 1 | 低 | 中 | 最高 |

## 從者單位設計

### 從者結構

```
從者單位
├── 基礎數值（各 stat）
├── 配置成本（消耗配置點數）
├── defTags / atkTags
├── 牌組效果（Synergy）
│   ├── 觸發條件（隊長類型 / 特定從者存在 / 計數）
│   ├── 效果數值
│   └── 從者死亡 → 效果立即消失
└── 靈光效果（補助兵種專屬）
    ├── 被動型：隨時隨地生效，效果較弱
    └── 觸發暫時型：需要激活條件，效果較強有時限
```

**配置點數公式**：關卡基礎點數 + 隊長被動加成 + 村莊永久升級加成

移速：中    射程：1    captureRate：最高
靈光：被動型 → 範圍內友方 captureRate +50%
              爭奪狀態下敵方累積值增長速度降低
牌組：小隊中有另一補助單位 → 爭奪時敵方累積值不增長
```

**補助C（戰吼型）**
```
成本：中    defTags：[步兵]    atkTags：無
移速：中    射程：1    captureRate：中
靈光：觸發暫時型 → 每次攻擊為靈光範圍內所有友方小隊
              疊加暫時防禦提升（最多 5 層，每層獨立計時）
              從者死亡 → 停止疊加，現有層數繼續倒數消失
牌組：隊長是步兵型 → 每層防禦提升數值 +50%
```

## 戰鬥單位數值清單（Stat Schema）

```
所有戰鬥單位共用
├── hp              隊長=真血 / 從者=護盾值
├── atk             攻擊力（基礎傷害）
├── atbSpeed        出手頻率
├── moveSpeed       移動速度（小隊取平均）
├── def             防禦力（承傷減免）
├── range           攻擊射程（格數）：近戰=1, 輕射擊=2, 重射擊=3~4
├── blockPriority   擋槍優先度（越高越先承傷）
├── reviveDelay     死亡後附加復活等待
├── captureRate     佔領貢獻值（輸出到建築的佔領進度）
├── atkTags         攻擊屬性標籤 ['anti_cavalry', 'anti_heavy', 'anti_ranged', 'siege'...]
├── defTags         防禦屬性標籤 ['cavalry', 'heavy', 'ranged', 'infantry'...]
└── statusBuildup   每次攻擊附加的異常累積值 { 毒: 0, 破甲: 0, 緩速: 0 }

隊長專屬
└── sp              技能能量（0~100），玩家手動施放（可勾選自動）

SP 充能來源（可疊加）
├── 造成傷害
├── 承受傷害
└── ATB 自然成長（每 tick 微量）
```

**傷害計算**：
```
最終傷害 = atk - def + Σ(atkTags 命中對方 defTags 的加成值)
```

**延遲傷害區域（DDZ — Delayed Damage Zone）**：

引擎通用原語，凡是「延遲後對區域造成傷害」的效果皆統一走此機制，不設特例邏輯。

```
DDZ 屬性
├── 位置        目標格或格組（支援任意形狀範圍）
├── 延遲        N ATB ticks 後觸發
├── 傷害        觸發時對區域內所有單位結算
├── 可視性      雙方皆可見（顯示警示標記）
└── 來源        任何單位 / 建築 / 關卡腳本皆可發出

閃避條件：延遲觸發前移出區域即可免傷
  → 移速高（騎兵/輕射擊）有機會閃開
  → 移速低（重甲兵/重射擊）大機率躲不掉
```

適用場景：

| 來源 | 說明 |
|---|---|
| 炮擊轟炸（重射擊隊長A SP） | 延遲爆炸，目標格鎖定 |
| 重射擊前搖 | 前搖期間目標格標記，移走可躲 |
| 防禦塔弩砲模式 | 高傷慢速，可閃避 |
| 未來戰車類單位 | 移動路徑產生輾壓區域 |
| 關卡腳本事件 | 隕石、落石等地圖事件 |

> 重射擊「前搖結束才造成傷害」統一視為 DDZ，引擎不另設前搖特例。

---

**atbSpeed 與 moveSpeed 的關係**：
- 兩者共用同一條 ATB 時間軸（ticks），但機制完全獨立
- atbSpeed：控制 ATB 條充能速度，滿了才觸發攻擊
- moveSpeed：控制小隊在地圖上的移動速率，持續進行，不受 ATB 條影響
- 小隊移動途中，各成員的 ATB 條同時在充能

## 遊戲節奏基準

> 設計參考用，不寫入引擎，用於校正數值合理性。

**時間基準**：步兵移動 1 格所需時間 ≈ 步兵標準攻擊 1 次所需時間

**1v1 對決擊破次數目標**：
```
同等素質對戰：3~5 次攻擊交換擊破
相剋對戰    ：2~3 次
抵抗對戰    ：5~10 次
```

**圍毆補償**：
- 1v2 以上時，HP 設計基準放大約 2 倍
- 確保玩家有足夠時間做戰場調度才分出勝負

**數值推導原則**（以步兵為例）：
```
HP ÷ (atk - def) ≈ 3~5（同等素質淨傷約佔 HP 的 20~33%）
```

## AI 策略系統

每支小隊有獨立的設定面板，玩家調整完後**送出命令**立即生效，並進入 `commandCooldown` 冷卻（冷卻時間為隊長數值，是隊長特色之一）。

### 設定面板結構

```
① 移動序列（命名區域，依序執行）
   玩家從預設區域清單選擇，AI 自動尋路
   範例：[上路前段] → [城門前] → [地城內部]
   到達最後區域後：○ 停留  ○ 重複序列

   預設命名區域（依地圖定義）：
   - 我方主堡區 / 我方後線
   - 上路前段 / 中路前段 / 下路前段
   - 城牆前
   - 地城內部（上/中/下）
   - 敵方主堡區

② 警戒範圍（觸發目標與動作判斷的偵測距離）
   ● 近 1格   ○ 中 2格   ○ 遠 3格

③ 目標優先級（拖排順序 → 決定打誰）
   可排列：
   - 最靠近自己的敵隊
   - 綜合血量最低的敵隊
   - 存活成員數最多的敵隊（從者+隊長總數）

④ 動作優先級（拖排順序 → 決定做什麼）
   可排列：
   - 攻擊敵方單位
   - 佔領設施
   - 只移動不戰鬥

[送出命令] → 立即生效，進入 commandCooldown
```

### 動作優先級行為說明

```
判斷邏輯：由上到下依優先順序檢查，第一個「可執行」的動作就執行

範例組合：
  攻擊 > 佔領 > 移動  →  標準戰士，打完再推進
  佔領 > 移動 > 攻擊  →  速攻佔點，無視敵人衝設施
  移動 > 攻擊 > 佔領  →  快速穿插，被擋才打
  攻擊 > 移動 > 佔領  →  純戰鬥，完全不佔點
```

### 目標達成後的備用行為

移動序列執行完畢（或無有效目標）時：
- 設定為「停留」→ 在最後區域原地警戒
- 設定為「重複序列」→ 從第一個區域重新開始

> 進階目標選項（指定兵種標籤、撤退閾值等）預計透過技能升級解鎖

## 技能系統

所有技能綁定在**隊長**身上，從者無獨立技能。

### 插槽配置

每個隊長有 **3 個統一插槽**，戰前從已解鎖的技能池選擇裝入，裝入即生效。
SP 技能為隊長內建，**不占插槽**。

```
插槽 1  ┐
插槽 2  ├─ 從技能池（兵種共通 8 個 + 隊長專屬 2 個）中選擇裝入
插槽 3  ┘

SP 技能  ← 隊長內建，每位隊長唯一，不可更換
```

---

### 技能類型

**一般技能（裝入插槽）**
- 裝入後開局自動生效
- 戰中可消耗**低階資源**升級，每個技能有獨立升級上限
- 依效果分三類（見兵種共通技能池）：數值疊加型 / 被動觸發型 / 整隊收益型
- 整隊收益型無法在戰中升級

**SP 技能（隊長內建）**
- SP 充滿後玩家**手動選擇觸發時機**
- 每個隊長面板可勾選「**SP 滿自動施放**」，勾選後 SP 充滿瞬間自動觸發
- 凡是需要目標的 SP 技能，觸發後為小隊施加 buff，**下次隊長攻擊命中時**執行效果
- SP 天賦分支（見下方天賦系統）在**地城內持續有效**，離開地城後還原

> 注意：文件中所有「持續時間」皆為 **ATB 時間單位**，非現實秒數。

---

### SP 技能天賦系統（風暴英雄式）

```
每層各二選一，消耗高階資源解鎖，戰中選擇

        [SP 技能]
             │
     ┌─── 第一層 ───┐     ← 高階資源解鎖，AB 二選一
    [A]             [B]
             │
     ┌─── 第二層 ───┐     ← 高階資源解鎖，CD 二選一
    [C]             [D]
             │
     ┌─── 第三層 ───┐     ← 未來擴充
    [E]             [F]

共 4 種搭配（三層後 8 種）：A+C / A+D / B+C / B+D
```

- 每層選擇互斥，選了就定
- 各層獨立，第一層選擇不影響第二層選項
- 高階資源稀少（來源：擊敗敵人），需要主動戰鬥才能累積
- **天賦選擇在地城內累積有效**：第 1 層解鎖的分支，第 3 層仍然生效
- 離開地城（通關或撤退）後天賦還原，下次地城重新選擇

## 地城系統

### 攜帶上限（MVP）

```
進入地城攜帶：隊長 5 個 + 從者 10 個（進地城鎖定，不可補充）
```

從者視為**裝備**，無跨場景累積技能，每層戰前自由重新分配給隊長。

### 技能插槽配置規則（地城內）

```
地城開始時  → 插槽可以是空的
每層戰前    → 可對空插槽安裝技能（已裝的不能替換）
戰中        → 消耗低階資源升級已裝技能，升級進度跨層累積
地城結束    → 插槽配置與升級進度全部還原
```

**決策張力**：早裝技能受益更多層但提前鎖定方向；晚裝可觀察地城需求再投入，但少獲得幾層的升級積累。

### 戰前準備流程（每層）

```
① 戰場預覽（地圖 + 敵方佈局大略）
② 從攜帶的隊長中選出本場部署數量（由戰鬥類型決定）
③ 為本場隊長分配從者（從攜帶的 10 個從者池中選）
④ 對空插槽安裝技能（已裝者不可替換）
⑤ 開始戰鬥
```

- 每層戰前皆可重新選擇出場隊長與從者配置（技能插槽受地城內規則限制）
- 隊長每層戰後 **HP 全回滿**（戰鬥中有復活機制，跨層累積傷害邏輯不一致）
- 隊長 SP 天賦分支選擇在**地城內持續有效**

### 戰鬥類型與部署數量

| 戰鬥類型 | 說明 | 部署小隊數 |
|---|---|---|
| 閃電戰 | 速攻限時目標，地圖小 | 1~2 |
| 一般戰鬥 | 標準推進，摧毀主堡 | 3 |
| 佔領戰 | 多點佔領為主，持久戰 | 3~4 |
| 防守戰 | 玩家守方，阻擋敵方進攻 | 3~4 |

> 部署數量不超過攜帶隊長數（5）

## 村莊系統

村莊是地城外的基地，管理玩家的**隊長**、**從者**、**資源**，走手遊基地管理風格。

### 四種玩家資產

| 資源 | 名稱 | 主要用途 | 來源 |
|---|---|---|---|
| 魔石 | 魔石 | 解鎖兵種共通技能 | 地城結算獎勵 |
| 財產 | 財產 | 抽取隊長、購買從者（可購買複數同種） | 地城結算、事件 |
| 戰功 | 戰功 | 升級指定從者個體屬性 | 地城戰績結算 |
| 源力 | 源力 | 升級全局被動、升級基地等級、解鎖商店、擴充兵營容量 | 地城稀有掉落 |

### 兵營容量（源力擴充）

```
隊長儲存上限  ← 源力擴充（初始值待定）
從者儲存上限  ← 源力擴充（初始值待定）
```

- 攜帶進地城的數量受上限制約（MVP：5 隊長 + 10 從者）
- 儲存上限影響玩家能持有的備用陣容深度

### 技能解鎖（魔石）

- 兵種共通技能雖為共通池，仍需**消耗魔石解鎖**才能裝入插槽
- 解鎖後對該兵種所有隊長永久可用
- 讓魔石不只是抽卡資源，也是技能投資選擇

### 從者升級（戰功：克制化特化）

```
升級材料：戰功（依升級項目消耗不同）
升級對象：玩家持有的特定從者個體（不是全部同種）
升級內容：基本數值提升（HP / atk / def 等）
升級上限：各項目有上限，且無法全項目滿級（強迫選擇方向）
```

- 同種從者可以有不同 build（例：輕射擊A 一個升攻擊、一個升移速）
- 增加配隊深度與遊戲歷程

### 全局永久被動（源力）

- 消耗源力升級，跨地城永久有效
- 範例方向（具體項目待定）：
  - 全體隊長 commandCooldown 縮短
  - 主堡 HP 上限提升
  - 開局低階資源增加
  - 從者護盾上限微幅提升（全體）

### 基地等級（源力）

- 消耗源力升級基地等級
- 效果：解鎖商店新種類從者、擴充兵營上限、解鎖更多村莊功能

## 地城打寶系統

地城是取得**村莊系統無法提供**的特殊裝備的唯一管道。三類掉落物均可賣掉換取資源。

### 召喚師物品

```
裝備對象：玩家本身（全局生效）
效果方向：類似源力強化的全局被動，但效果更強或有特殊條件效果
持久性：永久持有，被更好的裝備淘汰後可賣掉換資源
```

- 村莊源力強化是數值微調，召喚師物品可以有更顯著或條件型效果
- 例：「深淵契約：地城內所有隊長 SP 自然回復 +50%」

### 特殊體質從者

```
裝備對象：加入玩家從者庫存，當普通從者使用
效果方向：比商店同種從者多一個副屬性或體質特效
持久性：永久進入庫存，可用於升級素材（犧牲）或賣掉
```

- 副屬性範例：「輕射擊A・淬毒」→ 標準輕射擊A 數值 + 每次攻擊額外毒累積
- 特殊體質不可在村莊升級系統中複製，只能靠刷地城取得

### 隊長裝備

```
裝備對象：單一隊長，每位隊長只能裝備 1 件
裝備條件：依兵種 tag 限制（例：[騎士] tag 隊長才能裝備騎士系裝備）
效果方向：特化數值強化（無傳奇特殊效果，純粹強化某項 stat）
持久性：永久持有，可賣掉換資源
```

- 村莊版本：可製造/購買弱版隊長裝備（數值較低）
- 地城版本：數值更高，是村莊版的強化上限天花板
- 插拔時機：**村莊限定**（進入地城後不可更換）
