## 從者兵種（5 種）

從者在 v2 設計中是**消耗品護盾層**，陣亡不復活。
每個從者佔隊長一個護盾槽（標準上限 2 槽）。

### 從者戰鬥規則

- 從者**有自己的 ATB**，會獨立出手攻擊
- ATB 條只顯示在**詳情面板**，棋盤上不顯示
- 棋盤上的小隊圖示只顯示：隊長 HP 條 + 護盾層數量（小圓點）
- 從者死亡 = 該護盾層消失，不再參與戰鬥

### 數值說明

| 欄位 | 說明 |
|---|---|
| 護盾 HP | 此從者作為護盾層時的耐久值 |
| ATK | 從者自己的攻擊力（有獨立 ATB，會攻擊） |
| DEF | 防禦力（承傷減免） |
| ATB速度 | 攻擊頻率，基準值 1.0 |
| 移速 | 小隊移動速度加成，基準值 1.0 |
| 射程 | 1=近戰，2=中程，3~4=遠程 |
| 生產費用 | 靈力消耗 |
| 生產時間 | tick 數（基準約 30 tick） |
| 特性 | 此兵種的戰鬥特色 |

## 隊長（第一批）

> 隊長在 v2 是戰場上的持久核心，有多段 HP（護盾層由從者提供），陣亡後裸體復活。
> 隊長卡的固有/開通被動另外設計，這裡只定義基礎數值與 SP 招式。

### 數值說明

| 欄位 | 說明 |
|---|---|
| HP | 真實血量（護盾破後才扣） |
| ATK / DEF | 基礎攻防 |
| ATB速度 | 出手頻率 |
| 移速 | 自身移動速度（影響小隊整體速度） |
| 射程 | 攻擊射程 |
| 復活延遲 | 陣亡後幾 tick 復活（從者消耗品不影響） |
| 佔領速率 | 每 tick 貢獻的佔領進度 |
| 從者槽 | 初始從者槽上限（技能樹可升） |
| SP招式 | SP 滿後觸發的技能 |

## 相剋系統

**相剋只看隊長兵種，從者不參與相剋計算。**
從者是純數值層（護盾 HP、ATK、DEF、攻速），玩家選從者只需考慮戰力需求，不需考慮相剋關係。

### 相剋關係（攻擊方 → 防守方，傷害 +35%）

```
騎士隊長  →剋→  普通步兵隊長（衝撞碾壓輕裝步兵）
騎士隊長  →剋→  弓手隊長    （快速突進讓遠程來不及輸出）
重甲隊長  →剋→  騎士隊長    （拒馬+反擊，騎兵衝上去反虧）
步兵隊長  →剋→  重甲隊長    （特化破甲，硬鑿重甲）
弓手隊長  →剋→  步兵隊長    （遠程壓制+破甲，步兵靠不了身）
攻城隊長  →剋→  建築/設施   （攻城武器天剋防禦工事）
```

### 相剋視覺化

```
    攻城 ──剋──→ 建築
      ↑
  步兵 ←剋← 弓手
    │
    剋
    ↓
  重甲 ←剋← 騎士 →剋→ 步兵 / 弓手
    │
    剋
    ↓
  騎士（重甲反制）
```

相剋不是絕對壓制，數值差距大仍可逆勝，+35% 傷害讓相剋有意義但不決定性。

## 傷害計算（簡化版）

```
基礎淨傷 = max(1, ATK - DEF)
相剋加成：攻擊方隊長兵種剋制防守方 → 傷害 ×1.35
破甲狀態：目標 DEF 暫時 -30%
攻城兵濺射：主格全傷，周圍 1 格 ×0.6 傷害

承傷順序：護盾層（從者 HP）優先 → 護盾歸零後才傷隊長真實 HP
```

## 隊長技能樹節點

每位隊長消耗**經驗**解鎖節點，分支一旦選擇不可逆，每場戰鬥重置。

### 樹狀結構（共用格式）

```
[基礎節點 1]（便宜，每個隊長都有）
      │
[基礎節點 2]（解鎖第二從者槽）
      │
  ╱───────╲
[分支 A]  [分支 B]（選一，不可兼得）
    │          │
[A 進階]  [B 進階]（解鎖第三從者槽 + 影響 SP 招式）
```

經驗花費參考：基礎節點 5/8 經驗，分支節點 12/20 經驗

## 敵方單位定義

### 雜兵小隊（無隊長）

靜態或半靜態，守在固定節點，死亡不復活，擊敗給靈力和經驗。

| 類型 | HP | ATK | DEF | ATB | 移速 | 射程 | 行為 |
|---|---|---|---|---|---|---|---|
| 守衛步兵 | 200 | 90 | 65 | 0.9 | 0.8 | 1 | 原地不動 |
| 守衛弓兵 | 150 | 80 | 40 | 1.0 | 0 | 3 | 原地射擊 |
| 精英重甲 | 350 | 100 | 90 | 0.6 | 0 | 1 | 原地守點 |
| 突擊騎兵 | 180 | 110 | 55 | 1.2 | 1.4 | 1 | 巡邏+發現玩家就追 |

雜兵小隊**沒有從者系統**，只有單層 HP。

---

### 敵方指揮小隊（有隊長）

主動推進威脅玩家主堡，死亡後在敵方出生點復活，有完整 AI。
數值約為玩家同類型隊長的 80~100%（保持對等壓力）。

| 隊長類型 | 對標玩家 | 行為偏向 |
|---|---|---|
| 衝鋒型 | 衝鋒隊長 | 主動推進，優先攻擊玩家弱線 |
| 防守型 | 防守隊長 | 守在城門附近，不主動追擊 |
| 騎士型 | 騎士隊長 | 快速穿插，繞開玩家防線攻主堡 |

敵方指揮小隊**有護盾層**（1~2 個從者），擊殺後給大量靈力+經驗。

## 第一關腳本（草稿）

> 目標：讓玩家熟悉基本系統（從者生產、節點佔領、城門破壞）
> 規模：標準地圖，5 支小隊

### 地圖結構

```
玩家主堡(左) → 前哨×2 → 軍營×1 → 城門 → 前哨×2 → 敵主堡(右)
                                  ↑
                               高地×1
```

三條路線（上/中/下），各有一道城門。

### 敵方配置

```
初始：
  守衛步兵×3（分守三條路線前哨）
  守衛弓兵×2（守城門）

T+300 tick：敵方指揮小隊（衝鋒型）從敵主堡出發，走中路
T+600 tick：突擊騎兵×2 從上路繞側翼
T+900 tick：敵方指揮小隊（防守型）開始主動推進
```

### 勝利條件
- 摧毀敵方主堡

### 失敗條件
- 計時器 1200 tick 歸零
- 玩家主堡 HP 歸零

### 設計意圖
- 前 300 tick：玩家熟悉從者生產+佔領前哨節點
- T+300 後：第一個威脅出現，學習「AI 模式切換」
- T+600 後：騎兵繞側翼，學習「多線管理」
- 城門是主要卡關點，引導玩家使用攻城兵或計策牌
