# 魔物娘戰場 — v3 方向草稿
# 領地爭奪 + 攻城器 + 戰役腳本

> 本文件記錄 v2 討論後的設計方向修正，尚未實作
> 核心轉向：從「消滅所有敵人」→「領地爭奪 + 攻城壓力決勝」

---

## 設計核心轉變

### v2 的問題
- 勝利條件（消滅敵軍 / 佔領主堡）太單點，缺乏過程張力
- 設施建造後決策就結束，地圖是靜態的
- 戰鬥視覺混亂，玩家不知道看哪裡
- 從者生產感覺是管理負擔，不是有趣的戰術選擇

### v3 的核心方向
- **領地爭奪是主軸**，所有系統圍繞領地運作
- **隊長 SP 技能 + 從者部署** = 玩家主要即時互動（兩種「出牌」）
- **攻城器** = 把領土優勢轉換成勝利進度的機制
- **兵種行為 AI** = 讓戰鬥視覺有層次、可讀性高
- **主堡 = 玩家本體**，攜帶的卡決定戰中工具列

## 核心系統：領地（Territory）

### 概念
地圖由多個**領地**組成，每個領地在棋盤上占據 **3~5 格**：
- 有歸屬（player / enemy / neutral）
- 有一格**佔領核心格**（小隊占到此格才推進 captureHp）
- 其餘格為**領地範圍格**（移動、側翼、設施位置）
- 有 **2 個插槽**（MVP），每插槽綁定到一格指定格子
- 可以有一支小隊**駐守**

```
領地示意（5格）
    [ ]「插槽 A」
  [★核心]「插槽 B」
    [ ][ ]
```
類比：英雄連隊的戰略點系統，但加上了插槽建造

### 領地 HP
```
領地基礎 HP = 100
  + 防禦性設施（每個） × 50
  + 駐守小隊存在       × 30（小隊離開後上限下降）
```
領地 HP 歸零 → 領地進入「爭奪中」狀態 → 敵方小隊走完佔領流程才算易主

### 設施插槽
- 每個領地 MVP 固定 **2 個插槽**，每插槽綁定一格領地內的格子
- 插槽可建造設施，也可拆售（回收 60% 靈力，需 20 tick 拆除延遲）
- 拆除期間設施效果暫停
- 強力設施未來可占用 **2 個插槽**

### MVP 設施種類（4 種）

**設計原則：前線建防禦、中繼建訓練場、後方建採集、關鍵領地建攻城**

| 設施 | 效果 | 費用 | 適合位置 |
|---|---|---|---|
| 採集站 | 靈力 +0.4/tick | 6 | 後方安全領地 |
| 訓練場 | 從者輸送帶速度 +30%（全場） | 8 | 中繼領地 |
| 防禦塔 | 每 20 tick 對相鄰格敵方造成 25 傷害 | 10 | 前線 / 通道口 |
| 攻城砲台 | 每 50 tick 對敵方主堡造成 20 傷害 | 15 | 占領後立即建 |

**訓練場機制：**
- 輸送帶速度加快 = 更快骰到特殊從者
- 多個訓練場疊加，建議上限 2 個（開始報酬遞減）

**攻城砲台機制：**
- 傷害隨雙方領地數量差放大：多一個領地 +5%
- 可疊加，建多台累積傷害速率

**設施獨立 HP：**
- 每個設施有自己的 HP，可被敗方小隊獨立攻擊處置
- HP 歸零 = 設施摧毁（不需佔領整個領地）
- 攻城阓8 `buildingAtk` 對設施造成額外傷害（面對防禦塔等）
- 領地易主時，剩餘設施一併被摇毁

**後期可加入（MVP 後）：**急救站（駐守小隊回血）、瞭望台（警戒範圍 +1）

### 駐守 AI 行為
小隊可被指定「駐守某領地」：
- 小隊移動至該領地格
- 停留並防禦（仍會攻擊進入警戒圈的敵方）
- 敵人撤退後自動回到領地格（不追擊）
- 領地淪陷時駐守解除，小隊恢復一般行為

## 核心系統：主堡互毆 + 攻城器

### 機制
- 雙方主堡都有 **HP 條**（顯示在 UI 最上方）
- 建造**攻城砲台**設施後，每 N tick 自動對敵方主堡造成傷害
- 小隊到達敵方主堡相鄰格時也可直接攻擊主堡

### 壓力設計
- 攻城傷害隨雙方**領地數量差**放大：
  ```
  攻城傷害加成 = max(0, (我方領地數 - 敵方領地數)) × 5%
  ```
- 龜縮不推進 = 對方攻城越來越快，不是最優解

### 勝敗條件
| 條件 | 說明 |
|---|---|
| 勝利 | 敵方主堡 HP 歸零 |
| 失敗 A | 我方主堡 HP 歸零 |
| 失敗 B | 計時器歸零（可選，逼玩家積極進攻）|

## 核心系統：主堡（玩家本體）

主堡不只是防禦目標，而是玩家帶入戰場的裝備中心。

```
主堡
  ├── HP 條（被攻城砲台打掉，歸零就輸）
  └── 戰中工具列（由備戰帶入的卡決定有哪些按鈕）
        ├── 隊長卡 A → 解鎖「快速造兵」按鈕
        ├── 隊長卡 B → 解鎖「緊急維修設施」按鈕
        └── 召喚師卡 → 提供全場被動效果
```

主堡被攻擊不只是「快輸了」的訊號，也意味著工具列的持續壓力。

## 核心系統：玩家主要即時互動

### 兩種出牌方式
1. **隊長 SP 技能**：SP 充滿後玩家手動觸發，效果涵蓋廣域空間影響
2. **從者部署**：從庫存指定一支小隊，觸發召喚時效果 + 補護盾

### SP 技能範例（含空間效果，取代原計策設計）
| 隊長類型 | SP 技能效果 |
|---|---|
| 重甲隊長 | 在當前格放置防禦光環，持續 60 tick 區域內友軍防禦 +30% |
| 騎兵隊長 | 向前直線衝鋒，沿路造成傷害並推開敵方 |
| 法師隊長 | 在指定格放置詛咒區域，敵人踩到移速減半 + 受傷 |
| 弓箭隊長 | 對警戒範圍內所有敵方同時造成一次傷害 |
| 指揮隊長 | 全場友軍 ATB 立即 +30 |

### 從者召喚時效果偏向（小隊 / 個人）
| 從者類型 | 召喚時效果 |
|---|---|
| 騎兵從者 | 部署瞬間隊長往前衝一段並造成傷害 |
| 治療從者 | 立即回復隊長 20% HP |
| 重甲從者 | 部署後 20 tick 內該小隊變成「嘲諷」目標 |
| 弓兵從者 | 部署後立即對最近敵方造成一次遠程傷害 |

### 後期可加入：玩家保險按鈕（低風險擴充）
> 備戰時選定 2~3 張一次性消耗品，戰中作為緊急手段使用。
> 例：快速建造設施、快速生產從者、緊急回血。
> 此系統不影響核心迴圈，可在 MVP 驗證後再補上。

## 兵種 AI 行為（讓戰鬥視覺有層次）

| 兵種 | 核心行為 | 視覺特徵 |
|---|---|---|
| 騎兵 | 接觸後後撤 N 格 → 等待 → 全速衝鋒 | 循環衝退節奏 |
| 弓箭 | 維持安全距離，敵人逼近就退一格 | 始終在邊緣遊走 |
| 重甲 | 原地不動，等敵人來 | 穩如磐石 |
| 法師 | 最大射程攻擊，優先打 HP 最低目標 | 精準後排輸出 |

## 從者卡池系統

```
基本卡池（所有玩家永遠有）
  普通兵 / 高速兵 / 低速兵 / 遠程兵 / 攻城兵
  → 基礎數值，便宜可靠

特殊從者（每張隊長卡各提供 1 種）
  → 對應基礎兵種的強化延伸版
  → 數值更高 + 召喚時有觸發效果
  → 骰出機率與對應基礎兵種相同，但效果更強

帶 3 張隊長卡 = 骰池共 8 種（5 基礎 + 3 特殊）
```

**核心抉擇：** 現在用便宜基礎兵補護盾，還是等特殊從者骰出再部署？

## 資源決策張力

```
靈力
  ├── 召喚從者（立即戰力，基礎 or 等特殊）
  ├── 建設施（長期效益）
  └── 建攻城砲台（勝利進度）

經驗
  ├── 隊長科技樹節點（分支選擇）
  └── 開通被動（全場最強，但門檻最高）

SP（各隊長獨立）
  └── 現在觸發 vs 等更關鍵時機
```

## 戰役腳本的優勢

採用領地系統後，關卡設計大幅簡化：

### 不平等開局
- 敵方一開始就佔有 60% 領地（包含攻城砲台）
- 玩家從弱勢出發，有「逆轉奪回」的敘事張力
- 不需要特殊腳本，只要調整初始地圖歸屬即可

### 關卡個性化
- 某些領地初始有強設施（玩家需要優先搶）
- 某些地圖有計時器限制（逼玩家積極推進）
- 某些地圖敵方攻城砲台已建好（玩家一開局就在扛傷害）

### 中期壓力
- 不再需要「敵方波次升級」腳本
- 攻城器的積累傷害自然製造壓力
- 玩家主堡 HP 可見，創造「差點輸掉」的緊張感

## UI 佈局設計

### 整體架構

```
┌──────────────────────────────────────────────────────┐
│  [我方主堡 HP ████████░░]    [敵方主堡 HP ████░░░░░]  │
├────────┬─────────────────────────────────┬───────────┤
│        │                                 │           │
│ 隊長列  │     遊戲畫面（Pixi 六角棋盤）    │  生產面板  │
│        │                                 │           │
│[頭像][SP]  點擊領地 → 彈窗建造/駐守      │ [靈力/經驗]│
│[頭像][SP]  點擊空格 → 無反應             │ [輸送帶]  │
│[頭像][SP]                               │ [庫存×3]  │
│        │                                 │           │
└────────┴─────────────────────────────────┴───────────┘
```

### 左側：隊長列

- 每列顯示：頭像（HP 狀態色調）+ SP 按鈕
- **SP 按鈕**：SP 未滿時暗色顯示進度，充滿時脈衝發光可點擊
- SP 點擊後進入「選目標模式」，地圖 highlight 合法格，點格確認發動
- **頭像點擊** → 彈窗，包含：
  - HP / ATB / 從者槽狀態
  - 科技樹（節點解鎖，消耗經驗）
  - AI 模式切換（進攻 / 守點 / 佔領）

### 右側：生產面板

```
靈力 45  經驗 12
─────────────────
生產中：？？ 兵種
████████░░░░ 68%
─────────────────
庫存
[🗡️]  [🛡️]  [空]
 點擊 → 指定目標小隊部署
```

- 與地圖畫面完全分離，不影響視野
- 庫存槽點擊後，左側隊長列高亮可選隊長，點隊長完成部署

### 地圖點擊彈窗

**已佔領領地：**
```
┌─────────────────┐
│ 前哨站  ██████   │  ← 領地 HP 條
│ 插槽1 [採集站 ✅]│
│ 插槽2 [空]      │
│       [建造 ▼]  │  ← 展開費用與選項
│ [派駐守軍]       │  ← 選目標小隊駐守
└─────────────────┘
```

**敵方或中立領地：**
- 僅顯示領地 HP + 現有設施，無操作選項

**設計原則：所有空間決策都由地圖點擊觸發，不需要切換面板模式**

```

  4  [M] [M] [│] [ ] [ ] [中路領地        ] [ ] [ ] [M] [M]
  5  [M] [M] [│] [ ] [ ] [領地格        ] [ ] [ ] [M] [M]
  6  [ ] [ ] [ ] [ ] [ ] [   核心   ] [ ] [ ] [ ] [ ]

 10  [ ] [ ] [ ] [ ] [ ] [   核心   ] [ ] [ ] [ ] [ ]

 [M] = 主堡區域  [│] = 通道框架  [核心] = captureHp 棋格  [M] = 敵方主堡
```

### 建議尺寸：**19 寬 × 11 高**

| 區塊 | 寬度 | 用途 |
|---|---|---|
| 各方主堡 | 2格 | 主堡小隊出發點 + 3 插槽 |
| 第一段通道 | 3格 | 移動空間，可設場地障礙 |
| 中央領地（×3） | 4~5格各 | 核心格 + 2 插槽格 + 小樓道 |
| 第二段通道 | 3格 | 繼管區、可歡形容印 |

**尺寸合理性：**
- 從主堡到第一領地 ≈ 4 格 × 20 tick/格 = 80 tick （90 秒 1x 速度）
- 從領地到敵方主堡 ≈ 7 格 = 140 tick
- 全場升温約 200~400 tick，不會太短或拖延
