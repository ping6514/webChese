# 魔物娘戰場 — 設計文件 v2.2

> 核心方向：玩家透過資源投資與 AI 調整影響戰局，無即時指揮操作
> 本文件只談戰鬥核心，不涉及村莊/Meta 層

---

## 核心體驗定位

```
類比：魔獸爭霸 III 的種族機制
  隊長卡   = 英雄（技能樹、多段HP、SP招式、全場被動）
  從者     = 兵種（戰中生產、隨機骰出、部署補盾、消耗品）
  設施     = 建築（佔領後建造，持續效益）
  計策牌   = 軍師計策（輸送帶推進、一次性消耗）
  召喚師卡 = 玩家體質（造兵速度、計策偏向、設施加成等）

玩家的決策：
  - 接受這個從者類型還是重骰？
  - 從者現在部署給哪支小隊？
  - 經驗先解鎖哪個隊長的開通被動？
  - 計策牌現在用還是等更關鍵的時機？
  - 佔領的節點蓋什麼設施？
```

## 戰鬥前裝備系統

### 隊長卡（Captain Card）

每張卡代表一支出戰小隊，玩家依地圖規模裝備：

| 地圖規模 | 裝備數量 |
|---|---|
| 小地圖 | 3 張 |
| 標準地圖 | 5 張 |
| 大地圖 | 7 張 |

**卡片內容：**
```
隊長卡
  ├── 隊長本體（角色固定，基礎數值固定）
  ├── 抽兵偏好權重（此卡的從者骰出機率偏向）
  │     例：「騎士隊長卡A」→ 騎兵從者 +40%
  ├── 固有被動（全場生效，天生擁有）
  │     例：「全體小隊造兵速度 +10%」
  └── 開通被動（戰鬥中消耗經驗解鎖，全場生效）
        例：「佔領設施後，下一個從者免費」
```

**同角色多卡版本：**
同一個隊長角色可以有多張不同卡（掉落變體），固有被動不同。
玩家收集同角色不同版本的卡，選擇最符合當前關卡需求的版本出戰。

### 召喚師裝備卡（Summoner Card）

玩家自身裝備，1~3 張，影響全場體質。

**可能的效果範圍（每張卡選其中幾項）：**
```
造兵體質：
  - 所有從者生產速度 +X%
  - 特定兵種生產速度 +X%
  - 庫存上限 +1

計策體質：
  - 軍師輸送帶速度 +X%
  - 特定計策種類機率提升
  - 手牌上限 +1

設施體質：
  - 防禦塔攻擊力 +X%
  - 採集站產出 +X%
  - 急救站回血量 +X%
  - 建造費用 -X%

開局體質：
  - 初始靈力 +N
  - 初始計策牌 +1 張
  - 第一支小隊提前 N tick 入場

其他：
  - 手動暫停 CD 縮短
  - 軍師輸送帶事件加速量 +X%
```

## 資源系統（兩種）

### 靈力（主貨幣）

| 來源 | 金額 |
|---|---|
| 主堡基礎產出 | +0.5/tick |
| 佔領前哨（每個）| +0.3/tick |
| 擊殺雜兵 | +2~5（一次性）|
| 擊殺指揮 | +10~15（一次性）|

用途：從者生產費用、建造設施

### 經驗（共享池）

| 來源 | 金額 |
|---|---|
| 擊殺雜兵 | +1~3 |
| 擊殺指揮 | +8~12 |
| 佔領節點（首次）| +5 |

用途：解鎖隊長技能樹節點 / 解鎖隊長開通被動

**共享特性**：全體擊殺流入同一個經驗池。
核心決策：**先升哪個隊長的技能/被動？**

## 從者生產系統

### 流程

```
玩家在生產面板排隊建造
  → 隨機骰出從者類型
     （機率受：當場隊長卡的抽兵偏好加總影響）
  → 完成後進入庫存（最多 3 個）
  → 手動發動：指定目標小隊
  → 短暫召喚延遲
  → 延遲結束：從者加入小隊，立即補充一層護盾
  → 若延遲期間隊長陣亡：召喚中斷，從者消失
```

### 重骰

不滿意骰出的類型 → 取消 → 額外停工延遲 → 重新建造

### 軍營

佔領軍營節點 = **加快生產速度**（不增加生產列）

### 庫存

- 最多屯 3 個（召喚師卡可提升上限）
- 庫存滿時生產自動暫停

### 從者 = 消耗品

從者陣亡後**不隨隊長復活**。
隊長復活時裸體重新出場，需重新花靈力部署從者。

## 小隊結構

### 隊長多段 HP

```
護盾層（有從者時）
  → 觸發進攻型被動
  → 護盾歸零 = 從者死亡，護盾消失
  → 補回方式：部署新從者

真實 HP
  → 護盾破後直接受傷
  → 低血量觸發瀕死被動（例：SP 立即充滿）
```

### 從者上限

| 狀況 | 上限 |
|---|---|
| 標準 | 2 個護盾層 |
| 技能樹升級後 | 3 個護盾層 |

### 從者強化方式

從者本身無獨立升級，強化效果來自：
- 隊長技能樹節點（例：「重甲配備」→ 護盾值 +50%）
- 召喚師裝備卡（例：生產速度、特定兵種加成）

### 隊長復活

```
隊長陣亡 → 等待 reviveDelay tick 後裸體復活
從者為消耗品，不跟著復活
玩家需重新花靈力部署從者恢復護盾層
```

## 隊長技能樹

消耗**經驗**解鎖，分支不可逆，每場戰鬥重置。

```
      [基礎被動 Lv1]
           │
      [基礎被動 Lv2] ← 解鎖第二從者槽
           │
    ╱────────────╲
[分支 A]        [分支 B]
（攻擊向）      （生存向）
    │                │
[A 進階]        [B 進階] ← 解鎖第三從者槽
（影響SP效果）

另：
[開通被動] ← 消耗經驗解鎖，全場生效（每場重置）
```

## 計策牌系統（軍師）

### 軍師輸送帶

- 進度條隨 ATB tick 自動推進
- 到達節點 → 生成一張計策牌（進入手牌）
- 手牌上限：3 張（召喚師卡可提升）
- 手牌滿時輸送帶暫停

**加速來源：**
- 摧毀敵方設施
- 完成腳本事件任務

**計策種類偏向：** 受召喚師裝備卡影響

### 計策牌範例

| 計策 | 效果 |
|---|---|
| 火攻 | 對目標格周圍造成範圍傷害 |
| 陷阱 | 放置地圖格，敵人踩到觸發傷害+緩速 |
| 激勵 | 指定小隊 ATB 速度大幅提升 |
| 鐵壁 | 指定小隊下次受傷時護盾自動回復 |
| 援護 | 指定小隊立即獲得臨時護盾（不需從者）|
| 急行軍 | 指定小隊移速 +50%，持續一段時間 |

## 入場順序

玩家部署時設定 3~7 支小隊的入場順序與初始路線。

```
第 1 支：開局立即出現
後續：固定 tick 間隔 or 腳本事件觸發
```

目的：開局操作簡單，中後期逐步增加管理複雜度。

```
│                                  │                 │

│                                  │  建造選項/現況   │
├──────────────────────────────────┴─────────────────┤
│                    玩家面板                           │
│  靈力/經驗  [從者生產列][庫存×3]  [計策1][計策2]  ⏸  │

```

### 脈絡面板——小隊模式

**現況**：HP（護盾/真實）/ ATB / SP / 從者狀態 / 異常
**AI 設定**：行為模式 / 目標偏好 / SP 釋放
**升級**：技能樹節點 / 開通被動（消耗經驗）

### 脈絡面板——設施模式

佔領進度 / 建造選項 / 已建設施效果

### 玩家面板

從者生產進度條 + 庫存槽 + 計策手牌 + 資源顯示 + 暫停鍵

## 暫停系統

**自動暫停觸發：**
- 敵方新波次抵達
- 我方隊長陣亡
- 節點佔領完成
- 新小隊入場

**手動暫停：** CD 以 ATB tick 計算（約 200 tick 一次）

## 地圖節點

| 節點 | 效果 | 佔領後建造選項 |
|---|---|---|
| 一般前哨 | 靈力 +0.3/tick | 防禦塔 / 急救站 / 採集站 |
| 軍營 | 靈力 +0.2/tick + 造兵加速 | 徵兵所（進一步加速）|
| 高地 | 靈力 +0.1/tick | 瞭望台（全體警戒 +1）|
| 城門 | 阻擋通道 | 無，摧毀後解鎖下一區段 |
| 敵主堡 | 最終目標 | — |

## 建造選項

每節點限建一種，不可更換。

| 設施 | 效果 | 靈力費用 |
|---|---|---|
| 採集站 | 靈力產出 ×1.5 | 8 |
| 防禦塔 | 節點自動攻擊敵方 | 10 |
| 急救站 | 駐紮小隊每 30 tick 回血 5% | 8 |
| 徵兵所 | 造兵速度 +30% | 10 |
| 瞭望台 | 全體警戒範圍 +1 | 15 |

## 勝敗條件

| 條件 | 說明 |
|---|---|
| 勝利 | 摧毀敵方主堡 |
| 失敗 A | 計時器歸零 |
| 失敗 B | 玩家主堡 HP 歸零 |

敵方壓力：計時器（逼進攻）+ 波次升級（拖越久越難）

## 打寶與收集

戰鬥結算後掉落：
- **隊長卡變體**：同角色、不同固有被動的版本
- **召喚師裝備卡**：新的體質組合

收集深度：
- 同一個隊長有多張不同固有被動的卡可收集
- 不同召喚師卡組合出不同打法風格

## 核心決策張力

```
靈力：  生產從者（馬上補盾）vs 建造設施（長期效益）
經驗：  技能樹節點 vs 開通被動，升誰先？
計策：  現在發動 vs 等更關鍵時機
從者：  接受這個類型 vs 重骰（多等一段時間）
```
