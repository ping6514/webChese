# Death Oath 最新版設計

## 核心方向

- **帥血是資源**
- **壓血換爆發**
- **擊殺或承傷後有續戰補償**
- **士負責護帥與反制**
- **相負責戰況與功能支援**

## 目前共識

- **`FREE_SHOOT_DRAIN`**
  - 體感差且已知有 bug，應逐步移除

- **`BLOOD_TITHE_ON_KILL`**
  - 複雜且不直覺，建議改成更直接的擊殺回血或指定回血

- **`DEATH_COUNTER`**
  - 保留，適合放在車或馬，作為 death-oath 的亡命特色

- **`BLOOD_SACRIFICE`**
  - 保留為族群主軸
  - 適合串接 `PIERCE`、`CHAIN`、`DAMAGE_BONUS`

- **`BLOOD_RAGE_AURA`**
  - 可保留，但不應讓整族過度重複成同一種全場光環

- **`UNDERDOG_AURA`**
  - 可保留少量單卡使用
  - 不宜再作為整族主要辨識

## 士（advisor）重做方向

### 士 A：鐵誓

- 角色定位：
  - 宮廷核心
  - 帥低血時帶動全隊
  - 兼具護主功能

- 建議能力方向：
  - `BLOOD_RAGE_AURA`（global）
  - 護主 / 替帥分攤傷害

### 士 B：末命

- 角色定位：
  - 反制型護衛
  - 被打就反咬

- 建議能力方向：
  - `COUNTER`：目標為 `SELF` + `ALLY_BASE: king`
  - 第二能力可走受傷後變硬、受傷後加防，或其他護衛型被動

## 相（elephant）重做方向

### 相 A：戰況反轉（正）

- 己方活著單位數比敵方多 2 以上時
- 全體己方單位偏防禦向收益

### 相 B：戰況反轉（逆）

- 己方活著單位數比敵方少 2 以上時
- 全體己方單位偏攻擊向收益

## 建議優先順序

1. **先整理卡池定位**
2. **逐步移除 `FREE_SHOOT_DRAIN` / `BLOOD_TITHE_ON_KILL`**
3. **完成士與相的重做**
4. **再決定是否補主動型 `輸血` 或指定回血**

## 全族重製總綱

### 族群目標

- **把帥 HP 從風險改成可操作資源**
- **讓 death-oath 從「逆風才有功能」改成「主動壓血換節奏」**
- **補上續戰手段，避免只掉血不回本**
- **讓士與相重新取得明確職責**

### 兵種分工

- **車**
  - 血祭爆發
  - 死前反擊
  - 收頭型壓制

- **馬**
  - 殘血狂化
  - 逆境突擊
  - 中高風險換輸出

- **砲**
  - 帥血轉火力
  - 血祭換額外傷害 / 特效
  - 作為族群最直接的壓血兌現點

- **士**
  - 護帥
  - 反制
  - 宮廷核心

- **相**
  - 戰況調節
  - 功能支援
  - 攻守反轉

## 全兵種建議配置

### 車（rook）

#### 血裂

- 目前問題：
  - `FREE_SHOOT_DRAIN`
  - `BLOOD_TITHE_ON_KILL`
  - 兩個能力都在淘汰名單

- 建議重做方向：
  - 改成**擊殺回血**或**擊殺補帥**
  - 讓車成為收頭後回本的單位

- 建議能力類型：
  - `HEAL_SELF_AND_KING_ON_KILL`
  - 建議數值可先定為：擊殺後自身回復 2、己方帥回復 2
  - 第二能力可搭配 `BLOOD_SACRIFICE -> DAMAGE_BONUS`
  - 建議方向為：消耗帥 2 HP，換取本次攻擊傷害 +2
  - 整體設計應明確回到「成功投資 HP，就要拿到明顯回報」

#### 赤殞

- 建議保留方向：
  - `BLOOD_SACRIFICE -> PIERCE`
  - `DEATH_COUNTER`

- 角色定位：
  - 高壓血祭車
  - 死前還手
  - 單純的殺手，不額外承擔支援職責

### 馬（knight）

#### 命焰

- 目前問題：
  - `MOVE_THEN_SHOOT` 語意偏危險
  - 容易與其他陣營重複或誤導

- 建議重做方向：
  - 保留血祭主題
  - 但改成較清楚的輸出或穿透收益

- 可考慮：
  - `BLOOD_SACRIFICE -> FREE_SHOOT`
  - `HEAL_KING_ON_KILL`
  - 讓命焰與血裂形成呼應：前者偏節奏推進，後者偏收頭回本

#### 逆魂

- 建議保留方向：
  - `UNDERDOG_AURA self`
  - `DEATH_COUNTER`

- 定位：
  - 逆風時發揮
  - 不作為全族主引擎，只作單卡補充

### 砲（cannon）

#### 炎誓

- 目前問題：
  - 殘留 `FREE_SHOOT_DRAIN`

- 建議重做方向：
  - 移除 `FREE_SHOOT_DRAIN`
  - 保留血祭增傷核心

- 建議能力：
  - `BLOOD_SACRIFICE -> DAMAGE_BONUS +2`
  - 第二能力建議改為受傷後提高防禦，增加站場與續壓能力
  - 可整理為新模板，例如：`ON_DAMAGED_GAIN_DEFENSE`
  - 效果方向可先定為：受傷後雙防 +2
#### 怒魄

- 建議保留方向：
  - `BLOOD_SACRIFICE -> CHAIN`
  - `BLOOD_RAGE_AURA self`

- 定位：
  - 帥低血時爆發最強的砲位之一
  - 維持現有設計方向，優先透過 `BLOOD_RAGE_AURA` 的門檻與數值微調平衡

### 士（advisor）

#### 鐵誓

- 建議方向：
  - `BLOOD_RAGE_AURA global`
  - 護帥 / 替帥擋傷

- 定位：
  - 帥低血時的宮廷核心

#### 末命

- 建議方向：
  - `COUNTER`（`SELF` + `ALLY_BASE: king`）
  - 第二能力走受傷後加防 / 抗性 / 硬化

- 定位：
  - 反制型護衛
  - 與影姬的差異應偏「血誓硬扛」而非「陰影閃避」

### 相（elephant）

#### 焚魂

- 目前問題：
  - 殘留 `FREE_SHOOT_DRAIN`
  - 殘留 `BLOOD_TITHE_ON_KILL`
  - 與相的支援定位不合

- 建議重做方向：
  - 由資源 bug 技改為戰況 / 支援技
  - 可考慮作為「正向反轉」相

#### 絕域

- 建議保留部分：
  - `BLOOD_SACRIFICE -> IGNORE_BLOCKING`
  - 但第二技能不建議長期停在普通 `UNDERDOG_AURA self`

- 建議重做方向：
  - 與另一張相形成正 / 逆反轉搭配

## 相的最終建議：戰況反轉雙相

### 戰況反轉（正）

- 條件：
  - 己方活著單位數比敵方多 2 以上

- 效果：
  - 全體己方單位偏防禦向收益
  - 可做成 `DEF +2`
  - 或通用減傷

### 戰況反轉（逆）

- 條件：
  - 己方活著單位數比敵方少 2 以上

- 效果：
  - 全體己方單位偏攻擊向收益
  - 可做成 `ATK +2`
  - 或輸出增傷

## 計畫移除 / 淘汰的舊技能

### 優先移除

- **`FREE_SHOOT_DRAIN`**
  - 原因：
    - 體感差
    - 已知有 bug
    - 與 death-oath 主題關聯不足

- **`BLOOD_TITHE_ON_KILL`**
  - 原因：
    - 複雜
    - 收益不直觀
    - 難以成為族群可感知核心

### 降低使用頻率

- **`UNDERDOG_AURA global`**
  - 原因：
    - 太像被動等逆風
    - 不能作為全族主辨識

- **`BLOOD_RAGE_AURA global`**
  - 原因：
    - 可以保留，但不能讓多張卡只是在堆同一種全場模板

### 謹慎使用

- **`MOVE_THEN_SHOOT`**
  - 原因：
    - 容易語意混亂
    - 應用時要確認引擎與玩家理解一致

## 預計引入 / 強化的新模板

### 已完成

- **`FIRST_DAMAGED_REDUCTION`**
  - 每回合首次受到傷害時減傷
  - 已先用在 `dark_moon_advisor_yingji`

### 後續可考慮

- **`HEAL_SELF_ON_KILL`**
  - 擊殺後恢復自身生命

- **`HEAL_KING_ON_KILL`**
  - 擊殺後恢復己方帥生命

- **`HEAL_SELF_OR_KING_ON_KILL`**
  - 擊殺後回復自身或帥
  - 若後續要做選擇邏輯，可升級到此版本

- **`BLOOD_TRANSFER`**
  - 消耗自身 HP，回復友方生命
  - 適合未來士或相的主動支援技能

## 重製流程建議

1. **先完成文件藍圖**
2. **先替換最差技能**
   - `FREE_SHOOT_DRAIN`
   - `BLOOD_TITHE_ON_KILL`
3. **先定士與相**
   - 因為目前最影響族感
4. **再回頭整理車馬砲**
5. **最後補新模板與精修數值**
