## 0. 遊戲定位

自我挑戰型爬塔（Roguelite）。
玩家透過反覆挑戰地城，帶回戰利品強化自己，下次挑戰更深更難的地城。

**核心循環：**
```
村莊準備（換裝 / 轉蛋 / 購買）
  → 自訂地城（難度/區域）
  → 挑戰 10 層 + Boss
  → 帶回戰利品
  → 回到村莊
```

## 1. 地城系統

### 1.1 結構

- 固定 10 層，第 10 層為 Boss 戰
- 地圖大小：16×16 格
- 每層：數個房間（Room）透過走廊連接，房間從模板庫隨機挑選
- 補給層：隨機出現（見 §1.5），不計入 10 層總數

### 1.2 自訂參數

| 參數 | 說明 |
|------|------|
| **難度係數** | 連續數值（0.5 ~ 3.0），縮放怪物強度與掉落品質 |
| **地城區域** | 森林 / 遺跡（MVP1）；火山 / 冰窟 / 深海（之後擴充）|
| **失敗條件** | 全滅才失敗（預設）/ 任一人死亡失敗（多人困難，加掉落加成）|

### 1.3 雙路線系統（安穩 / 試煉）

每次進地城時，系統**同時預生成兩條完整的 10 層路線**（安穩 + 試煉），種子來自 `run_seed`。

玩家每層打完，下樓梯時可**自由選擇下一層走哪條路線**，門口只顯示路線符號，不透露內部內容。

**各層配置對比：**

| 層數 | 安穩路線 | 試煉路線 |
|---|---|---|
| 1 | 戰鬥房 ×1，入門難度 | 戰鬥房 ×2，含陷阱 |
| 2–3 | 普通怪，補給機率 40% | 普通怪 + 菁英 ×1，補給機率 20% |
| 4–6 | 中期，機關目標為選項 | 中期，強制機關目標，菁英 ×1–2 |
| 7–9 | 後期，補給機率 60% | 後期，菁英 ×2，特殊目標，補給機率 30% |
| 10 | Boss（標準數值） | Boss（數值 ×1.3）|

**每層生成參數：**

| 參數 | 安穩 | 試煉 |
|---|---|---|
| 怪物數量 | 2–4 | 4–7 |
| 菁英出現 | 無（1–6）/ 稀少（7–9）| 固定 ×1（4 層起）|
| 陷阱 / 機關密度 | 低 | 高 |
| 掉落品質倍率 | ×1.0 | ×1.3 |

**最終結算加權：**
```
試煉層數比例 = 選過的試煉層數 / 10
最終掉落品質係數 = 難度係數 × (1 + 試煉層數比例 × 0.5)

範例：全走試煉 → ×1.5；全走安穩 → ×1.0；走一半 → ×1.25
```

### 1.4 層目標類型

```typescript
type FloorObjective =
  | { type: 'reach_exit' }                          // 抵達出口（預設）
  | { type: 'kill_all' }                            // 消滅所有怪物
  | { type: 'survive'; duration: number }            // 存活 N time
  | { type: 'activate_mechanism'; count: number }    // 啟動 N 個機關
  | { type: 'protect'; targetId: string }            // 保護目標（多人用）
```

### 1.5 補給層

- 補給層夾在正規層之間，不計入 10 層
- 無戰鬥，可替換裝備 / 補充消耗品 / 查看下一層路線提示
- 安穩路線補給機率較高（見 §1.3）

### 1.6 掉落品質公式

```
武器最終攻擊力 = 武器基礎攻擊力 × 最終掉落品質係數 × 詞條品質倍率
最終掉落品質係數 = 難度係數 × (1 + 試煉層數比例 × 0.5)
```

### 1.7 失敗與帶回規則

| 資產類型 | 規則 |
|---|---|
| **金幣** | 永遠帶回 |
| **裝備（武器/防具/消耗品）** | 通關帶回全部；失敗帶回 5 件（結算畫面自選）|
| 防具詞條可擴充帶回格數（例：+1 格）||

## 2. 角色系統

### 2.1 沒有固定角色，用「職業證」代替

玩家帳號本身沒有等級或屬性，一切能力來自**裝備**。
**職業證**是代表職業的特殊裝備，進入地城前必須裝備一張。

### 2.2 玩家數值總覽

所有數值皆由「職業證 + 防具 + 武器詞條效果」疊加而來：

| 類別 | 數值 | 主要來源 |
|------|------|----------|
| **能量資源** | 最大 HP / SP / MP | 職業證 + 防具 |
| **參照屬性** | STR / INT / AGI / LCK | 職業證 + 防具（詳見下方） |
| **移動力** | 每次移動可走的格數 | 職業證 + **鞋子**為主 |
| **抗性（%）** | 劈砍 / 碎裂 / 穿刺 / 水 / 火 / 木 / 光 / 暗，各自獨立（共 8 種） | 防具詞條 |
| **防禦力（flat）** | 劈砍 / 碎裂 / 穿刺 / 水 / 火 / 木 / 光 / 暗，各自獨立（共 8 種） | 防具詞條 |

### 2.3 參照屬性設計哲學（TRPG 風）

STR / INT / AGI / LCK **本身不自帶機制**。
它們是「判定時被引用的數值」，由武器/效果公式定義「每點屬性貢獻多少」。

```
效果值 = 動作基本值 + 屬性值 × 動作插槽倍率 + Σ 詞條加成
```

這代表：
- 同一個屬性，不同武器的插槽倍率完全不同（例：同樣的 LCK=30，高倍率武器爆擊率遠超低倍率武器）
- 沒有「全局爆擊率」「全局掉落率」這種說法，只有「這把武器/這個效果用了多少 LCK」

**LCK 特殊說明：**
- LCK 的成長來源受限（職業證固定值 + 少數防具詞條），避免無限膨脹
- 公式內有 `min(95%, ...)` 上限，防止確定觸發
- LCK 可被以下公式使用：暴擊率、掉落品質浮動、特殊事件觸發率（不強制，由武器/效果各自定義）

---

### 2.4 傷害結算公式（全傷害類型統一）

```
玩家實際抗性上限 = 75% − 難度懲罰%（難度係數越高，上限越低）
實際抗性%        = min(玩家實際抗性上限, max(−50%, 目標抗性% − 抗性削減%))
實際防禦力       = max(0, 目標防禦力 − 防禦削減)
最終傷害         = max(1, 原始傷害 × (1 − 實際抗性%) − 實際防禦力)
```

- **先算抗性**（百分比乘算），**再扣防禦力**（flat 減法），最低傷害為 1
- **玩家抗性上限 75%**（參考 D2），但受**難度係數懲罰**往下壓：
  - 難度 1.0 → 懲罰 0%，玩家上限維持 75%
  - 難度 2.0 → 懲罰 20%，玩家上限降至 55%
  - 難度 3.0 → 懲罰 40%，玩家上限降至 35%
  - 具體數值待平衡調整
- **抗性最低值 −50%**：削減過頭時傷害上限為 ×1.5，防止弱點爆傷失控
- 適用全部 **8 種傷害類型**：
  - **物理 3 種**：劈砍 / 碎裂 / 穿刺（各有獨立抗性與防禦力）
  - **魔法 5 種**：水 / 火 / 木 / 光 / 暗（各有獨立抗性與防禦力）
- **抗性削減 / 防禦削減**來自 Debuff（武器詞條觸發 or 工具主動施加），可疊加
- 設計意圖：面對高防怪物，玩家有三條應對路線：
  1. **換屬性**：攜帶對應弱點屬性的武器直接打弱點
  2. **削防先手**：用削減抗性/防禦力的武器詞條或工具先撕防，再用主力武器收割
  3. **異常狀態破局**：特定武器詞條或工具可施加異常狀態（例：「腐蝕」降低目標防禦力、「燃燒」繞過物理防禦造成持續火傷），從側面突破高防禦組合

### 2.3 能量資源（HP / SP / MP）

三種能量資源**所有職業統一擁有**，上限由職業證 + 防具決定。

| 資源 | 用途 | 回復方式 |
|------|------|----------|
| **HP** | 生命值，歸零即死亡 | 無自然回復；靠消耗品、回復格、特定武器效果 |
| **SP** | 物理技能資源（類 WoW 盜賊能量） | **每次行動後**由 `spRecoveryFlat` 自動回復（見下方）；職業證被動可提供額外加成 |
| **MP** | 魔法資源 | 預設**無自然回復**；跨層、特定消耗品/工具、一次性回復區域 |

**SP 回復機制（per-action recovery）：**
SP 採用「行動後回復」設計——每次完成動作（consumeATB）後，自動回復 `spRecoveryFlat` 點 SP。
這是全職業的**通用機制**，沒有任何職業在正常戰鬥中會耗盡 SP 而卡住。

| 來源 | 說明 |
|---|---|
| `spRecoveryFlat`（引擎預設）| 每次 consumeATB 後補 N SP，職業證定義預設值（目前 20） |
| 職業證被動：條件觸發回復 | 「受傷後回 SP」等特殊條件（戰士被動） |
| 職業證被動：時間持續回復 | 「每 N time 回復 M SP」（遊俠被動，MVP1 後實作） |

> **設計意圖：** SP 作為動作燃料，不應成為卡關瓶頸。玩家在戰場上面對的壓力來自怪物威脅，而非資源耗盡。強大技能（例如 AoE、爆發傷害）消耗更多 SP，迫使玩家在節奏上做取捨，但基礎攻擊永遠可用。

**時間壓力設計哲學（Time Pressure Design）：**

> **不使用「每層最大時間限制」作為強制壓力機制。**

等待自然回復或刻意「凹資源」（等 SP/MP 回滿）在 ATB 系統中本質上是自殘行為：
- 時間軸持續推進，怪物持續行動、攻擊玩家
- 站著不動 = 被怪物持續傷害，得不償失
- 真正的壓力來自**敵人本身**，而非計時器

時間效率的軟性誘因透過**掉落品質**體現：
- 完成度評分（如通關速度、受傷程度）影響最終獎勵品質
- 探索時間拉長 = 累積傷害越多、消耗品消耗越多，隱性成本已存在
- `survive` 目標類型（`{ type: 'survive', duration: N }`）已覆蓋需要計時的場景

回復能力是**職業證被動技能**提供的進階分化，不同職業資源管理風格由此分化：

**被動技能類型：**

| 類型 | 說明 | 範例 |
|---|---|---|
| **能量上限擴充（屬性倍率）** | max 資源 += 屬性值 × 倍率 | 高階戰士：max HP `+STR × 5` |
| **資源定量回復（跨層）** | 跨層固定回復 N 點 | 高階戰士：跨層 +50 SP |
| **資源持續回復（時間）** | 每 N time 自動回復 M 點 | 遊俠：每 500 time +30 SP |
| **條件觸發回復** | 特定行為觸發回復 | 遊俠：命中敵人回 8 SP |
| **能量上限擴充（固定值）** | max 資源 += 固定值 | 法師：max MP +80 |
| **資源跨層回復率** | 跨層時回復比例 | 法師：MP 跨層全回復（預設 50%→100%）|

**職業等級範例（同職業不同階）：**

| 職業證 | 被動技能 |
|---|---|
| 低階戰士 | HP 增幅 `+STR × 2` |
| 高階戰士 | HP 增幅 `+STR × 5`；跨層 +50 SP |
| 法師 | MP 增幅 `+INT × N`；MP 跨層全回復 |
| 遊俠 | SP 持續回復：每 500 time +30 SP |

> 被動技能可有多條，高階職業證通常比低階多一條以上。具體倍率待職業設計階段調整。

### 2.4 職業證

```
職業證 = 資源成長公式 + 移動規則 + 裝備 tag 列 + 被動技能列
```

職業證的核心是**定義規則與公式**，不是給固定數值。
裝備（防具）在公式結果之上疊加 flat 加成。

**提供的內容：**

| 類型 | 說明 | 範例 |
|---|---|---|
| **資源成長公式** | 基礎值 + 屬性倍率，決定 max HP/SP/MP 規模 | 高階戰士：`基礎50 + STR×5`；法師：`基礎150 + STR×1` |
| **參照屬性基底** | 職業的 STR / INT / AGI / LCK 初始值 | 戰士 STR 高，法師 INT 高 |
| **移動規則** | 每次移動的格數上限 | 遊俠：4 格；重騎：2 格 |
| **裝備 tag 列** | 決定能裝備哪些武器 | `[近戰, 物理, 戰士, 初階職業]` |
| **被動技能列** | 資源回復規則、特殊判定加成等 | 遊俠：每 500 time +30 SP |

**最終資源上限計算：**
```
max HP = 職業基礎HP + STR × 職業HP成長倍率 + Σ 防具HP加成
max SP = 職業基礎SP + AGI × 職業SP成長倍率 + Σ 防具SP加成
max MP = 職業基礎MP + INT × 職業MP成長倍率 + Σ 防具MP加成
```

職業基礎值讓「不擅長體質成長的職業」也有保底資源池：

| 職業 | 基礎HP | HP成長 | 特色 |
|---|---|---|---|
| 高階戰士 | 50 | STR × 5 | 低基礎，靠 STR 滾大 |
| 法師 | 150 | STR × 1 | 高基礎保底，STR 幾乎不影響血量 |
| 重騎 | 200 | STR × 3 | 高基礎 + 中等成長，最耐打 |
| 遊俠 | 80 | STR × 2 | 靠 AGI/SP 優勢補足戰鬥持久度 |

> 具體數值待職業設計階段調整，此為結構示例。

**tag 列範例：**
```
[近戰, 物理, 戰士, 初階職業]
[遠程, 魔法, 法師, 中階職業]
```

**獲得方式：**
- 起始：每個帳號永遠有一張**初始職業證**，不可刪除
- 村莊轉蛋機可抽出更多職業證
- MVP1 後：職業證升級系統

## 3. 武器系統

### 3.1 概念

武器是玩家的**主動技能**，不只是提升傷害的數值裝備。
玩家攜帶 **4 把武器 + 2 個工具**，輪到行動時從中選一個執行。

### 3.2 武器的裝備條件（在武器上定義）

```json
{
  "name": "鐵劍",
  "requiredTags": ["戰士"],
  "compoundTags": { "require": 2, "from": ["近戰", "物理", "初階職業", "中階職業"] }
}
```

- `requiredTags`：職業證必須**全部具備**
- `compoundTags`：職業證必須滿足列表中的 **N 項以上**

### 3.3 武器結構（5 詞槽）

每把武器 = **基底 + 5 類詞槽（每類限 1）**：

| 槽 | 類型 | 範例 |
|----|------|------|
| 1 | **元素/屬性** | 攻擊型：劈砍 / 碎裂 / 穿刺 / 水 / 火 / 木 / 光 / 暗；防禦型：穿刺抵抗 / 火焰抵抗… |
| 2 | **攻擊模式** | 攻擊：劈砍（前方橫 3 格）/ 突刺（直線）/ 旋風 / 爆破 / 投擲；防禦：防禦反擊 / 格擋 |
| 3 | **特性** | 全力（傷害×1.5，硬直+50）/ 快速（讀條-30%）/ 廣範圍（+1格）/ 聚焦 |
| 4 | **動作** | 飛越（施放前前移 3 格）/ 飄移（任意移 2 格）/ 定點 / 腿軟 |
| 5 | **附魔** | 燒傷 / 減速 / 怒吼 / 堅固 |

**武器動作 Tags（`actionTags`）：**

每個武器基底帶有一個 `actionTags` 陣列，描述動作的施放性質。Tags 用於：
- 決定哪些中斷/取消效果可以針對此武器
- 決定職業證裝備條件（`requiredTags` / `compoundTags`）

**Tag 匹配採廣義包含：** 中斷詞條指定的 tag 只要在 `actionTags` 內存在即命中。
例：「蓄力中斷」附魔只檢查目標武器 `actionTags.includes('蓄力')`，
不管它同時是 `法術蓄力` 還是 `物理蓄力`，都成立。

| Tag | 說明 |
|---|---|
| `法術` | 魔法類施放 |
| `物理` | 物理類動作 |
| `蓄力` | 讀條時間顯著較長的蓄力動作（法術或物理均可附加） |
| `即發` | 施放時間極短（中斷時間窗口極小，但非免疫） |
| `防禦` | 防禦姿態動作 |
| `召喚` | 召喚或部署類動作 |

範例：
```json
{ "id": "heavy_slash",  "actionTags": ["物理", "蓄力"] }
{ "id": "fireball",     "actionTags": ["法術", "蓄力"] }
{ "id": "quick_stab",   "actionTags": ["物理", "即發"] }
{ "id": "block_stance", "actionTags": ["物理", "防禦"] }
{ "id": "ice_lance",    "actionTags": ["法術"] }
```

**關於物理 3 子類型（劈砍 / 碎裂 / 穿刺）：**
純粹是傷害分類標籤，無內建機制差異。
設計意圖：讓怪物弱點設計有更多破口（例：重甲怪高劈砍/碎裂抗性但無穿刺抗性；蟲型怪無穿刺抗性但高火焰抗性），同時讓玩家的「防禦類武器詞條」設計更具體（例：穿刺抵抗 vs. 物理全抵抗）。

### 3.4 武器行動類型：攻擊型 vs. 防禦姿態型

武器的行動不只是「瞬間攻擊」，**攻擊模式**（槽 2）也可以是「進入持續姿態」：

**攻擊型（立即結算）：** 讀條 → 傷害結算 → 硬直 → CD
**防禦姿態型（持續效果）：** 讀條 → 進入姿態（持續 N time）→ 期間：
  - 自身增益（來自槽 1 的防禦型詞條，例：穿刺抵抗 +30%）
  - 武器動作提供的防禦力加成
  - 被攻擊時觸發反擊傷害
  - 姿態結束 → 進入硬直 → CD

**防禦姿態範例：「穿刺抵抗‧火焰反擊小圓盾」**

| 項目 | 來源 | 效果 |
|------|------|------|
| 槽 1（防禦屬性） | 穿刺抵抗詞條 | 姿態期間：自身穿刺抗性 +30% |
| 槽 2（攻擊模式） | 防禦反擊（6000 time） | 物理三系防禦力 +（2.0 × 難度係數 × STR）|
| 反擊傷害 | 同槽 2 | 對攻擊自己的敵人造成碎裂傷害 +（2.0 × 難度係數 × STR）|
| 槽 1（攻擊屬性） | 火焰詞條 | 反擊附加火焰傷害 = 難度係數 × 詞條品質浮動 |
| 反擊距離 | 槽 2 基底 | 預設：無論距離；可加條件「自身 1 格半徑」 |
| 廣範圍（槽 3） | 特性詞條 | 反擊半徑條件 +1 格 |

> **設計備注**：槽 1 可以同時持有「防禦屬性」+「攻擊屬性」（如上例），因為防禦姿態的被動增益與反擊傷害屬性是兩個不同的觸發時機，不衝突。

### 3.5 傷害公式

**物理攻擊（劈砍/碎裂/穿刺公式相同，查各自的抗性/防禦欄）：**
```
傷害 = 基底倍率 × 難度係數 × STR
讀條時間 = 100 + 200 / AGI  （可被特性詞槽修改）
武器冷卻 = 1000 time
```

**元素附魔附加傷害（以火焰為例）：**
```
火焰附加傷害 = 難度係數 × 詞條品質倍率  （純詞條強度，不依賴屬性）
```
> 防具詞條可對附魔加入 INT 或固定值加乘（見第 5 節）。

**防禦力加成公式（防禦姿態武器）：**
```
防禦力加成 = 基底倍率 × 難度係數 × STR
```

### 3.6 暴擊系統（武器專屬，非全局）

暴擊**不是全局系統**。只有武器帶有暴擊相關詞條時，這把武器才有暴擊判定。
沒有爆擊詞條的武器，永遠不暴擊。

**暴擊率公式：**
```
暴擊率 = min(95%, 動作基本機率% + LCK × 動作LCK插槽倍率 + Σ 詞條爆擊機率%)
```

**暴擊傷害公式：**
```
暴擊傷害 = 基礎傷害 × (動作基本爆擊倍率 + Σ 詞條爆擊倍率加成)
```

**範例：「(幸運的爆擊)(強化爆擊的) 黃金小刀」突進穿刺**

| 項目 | 數值 |
|---|---|
| 動作基本傷害 | 動作倍率 0.3 × AGI × 武器品質 |
| 動作基本爆擊機率 | 10% |
| 動作 LCK 插槽倍率 | 每點 LCK +2% 爆擊率 |
| 幸運的爆擊詞條 | +15% 爆擊機率 |
| 動作基本爆擊倍率 | ×1.5 |
| 強化爆擊的詞條 | 爆擊倍率 +0.5 → 合計 ×2.0 |

角色屬性 AGI=50 / LCK=30：
```
基礎傷害 = 0.3 × 50 × 2（武器品質） = 30 穿刺
爆擊率   = min(95%, 10% + 30×2% + 15%) = min(95%, 85%) = 85%
爆擊傷害 = 30 × 2.0 = 60 穿刺
```

**爆擊詞條說明（槽 1 或槽 5 均可帶）：**

| 詞條名 | 效果 |
|---|---|
| 幸運的爆擊 | 爆擊機率 +N%（消耗 LCK 插槽，N 取決於品質） |
| 強化爆擊的 | 爆擊倍率 +N（疊加到動作基本爆擊倍率上） |
| 必中爆擊 | 特定條件下（例：目標 HP 低於 30%）保證暴擊 |

> **LCK 正規化：** 爆擊率有 95% 硬上限；LCK 來源受限（職業證 + 少量防具），實際遊玩中 LCK 不會高到很離譜。

## 4. 工具與消耗品

### 4.1 工具（固定 2 格）

工具是**功能性持久裝備**，進地城前裝備，地城內不消失，有 CD 或聚氣次數限制。
與武器共用行動選擇，輪到自己時可選擇使用工具。

**純 CD 制：**
- 只有冷卻時間，CD 結束即可再用（無次數限制）
- 範例：戰鼓（接下來 6000 time 內 STR +30，CD 12000 time）
- 範例：重生護符（死亡時自動觸發，CD 非常長）

**聚氣 + CD 制：**
- 有使用次數上限（地城中有限），CD 結束才能用下一次
- 補充時機：補給層 / 回村莊
- 範例：開鎖工具（3/3 次）

**功能型工具（MVP1 後）：** 偵測陷阱、開鎖、環境互動類

---

### 4.2 消耗品（基礎 5 格，可擴充）

消耗品是**一次性道具**，使用後即消耗，地城內拾取或村莊購買攜帶進入。
**不占用行動 ATB**：使用消耗品不觸發讀條，但有 1 秒短暫冷卻（防止連刷）。

**消耗品格數：**
- 基礎 5 格（固定）
- 防具詞條可擴充（例：下衣「補給袋 +2 格」→ 最多攜帶 7 件）

**消耗品類型範例：**

| 類型 | 範例 | 效果 |
|------|------|------|
| 回復 | 小型 HP 藥水 | 立即回復 HP 固定值 |
| 回復 | SP 精華 | 立即回復 SP |
| 強化 | 攻擊符文 | 下次攻擊傷害 ×1.5 |
| 輔助 | 逃脫捲軸 | 立即撤退到上一層（含道具損失） |
| 投擲 | 爆裂物 | 對目標格 AoE 傷害（含傷害類型） |

## 5. 防禦裝備

### 5.1 槽位（固定 5 槽）

頭盔 / 上衣 / 下衣 / 手套 / 鞋子

### 5.2 詞條系統

防具詞條**隨機掉落**（類似暗黑破壞神），掉落時隨機決定詞條種類與品質。

**詞條類型：**

| 類型 | 範例 |
|------|------|
| 基礎屬性加成 | STR +15 / AGI +10 / INT +8 |
| 資源上限 | 最大 HP +50 / 最大 SP +20 |
| **武器詞條強化（固定值）** | 攻擊帶有「火焰」時，火焰傷害額外 +10 |
| **武器詞條強化（品質倍率）** | 攻擊帶有「火焰」時，火焰詞條品質倍率 +0.5 |
| **消耗品格擴充** | 消耗品攜帶格數 +1（下衣為主） |
| 特殊效果 | 失敗帶回格數 +1 / 補給層出現率 +15% |

**附魔傷害計算範例（帶強化防具後）：**
```
火焰附加傷害
  = 固定基礎值
  + (詞條品質倍率 + 防具品質強化加成) × INT
  + 防具固定值強化加成
```

### 5.3 詞條改造（MVP1 後）

- 插槽系統：消除指定詞條
- 村莊合成：用特殊消耗道具寫入詞條

## 6. ATB 時間軸

### 6.1 全域時間（世界時間）

ATB 如同現實時間，**永遠持續推進**，任何單位的個人行為不影響整體時間流速。
所有單位（玩家 + 怪物）共用同一條時間軸。

- 每個單位有 `speed` 值，ATB 以 `speed × Δt` 速率累積
- ATB 到達 100 獲得行動權，行動後重置為 0
- 同時到達 100：玩家優先；同類別依 id 排序（可重現）
- 怪物回合：AI 自動決策並發出動作

**動畫結算例外：** 技能判定的瞬間有 ~200ms 的視覺暫停，純 UI 層不影響引擎時間軸。

---

### 6.2 玩家行動分支

輪到玩家（ATB=100）後，可選擇以下動作之一：

```
A. 使用武器  →  選擇目標格  →  讀條計時  →  判定結算  →  [有硬直？] 硬直  →  ATB 歸零重新累積
B. 使用工具/消耗品（流程同 A，讀條通常較短）
C. 移動  →  選擇目標格  →  移動讀條  →  抵達  →  地板觸發檢查  →  ATB 歸零重新累積
```

**移動讀條公式：**
```
移動準備時間 = ceil(職業移動基準 / (1 + AGI / 20))
```
職業移動基準由職業證定義（勇士 600、遊俠 400、重騎 900 等）。
鞋子詞條可直接提供 `-% 移動準備時間` 或等效 AGI 加成。

**讀條期間：** 其他單位的 ATB 持續累積，怪物可能在玩家讀條結束前先行動。
慢武器 = 高傷害高風險；快武器 = 低傷害低風險，這個取捨有實際意義。

---

### 6.3 單位行動佇列（Unit Action Queue）

每個單位內部維護一條**行動佇列**，代表「接下來要依序完成的事」：

```
[讀條_剩餘200] → [硬直_300] → [等待輸入]
```

ATB 推進時，依序消耗佇列最前面的項目。當佇列到達 `等待輸入` 時，單位可以選擇下一個動作。

---

### 6.4 狀態效果的佇列行為：插單 vs. 結單

狀態效果作用到正在執行行動的單位時，有兩種行為：

**插單（Queue Insert）：** 狀態效果插入佇列當前位置，原有行動**保留進度，延後繼續**。

```
原始佇列：[讀條 300/500 → 硬直 300]
被插入「暫停 700」：[暫停 700 → 讀條 剩餘200 → 硬直 300]

時間軸範例（「暫停魔法」在讀條 300/500 時命中）：
  0~300    讀條進行中（已完成 300/500）
  300~1000 暫停狀態（700 time）
  1000~1200 讀條繼續完成（剩餘 200/500）
  1200~1500 硬直（300 time）
  1500     ATB 歸零 → 重新選擇動作
```

**結單（Queue Cancel）：** 清空佇列當前行動，**進度歸零，施加新狀態**。

```
原始佇列：[讀條 300/500 → 硬直 300]
被結單「沉默」命中（武器 tag 含 [法術]）：佇列清空
→ 套用沉默 Debuff，回到等待輸入（但 [法術] 武器無法選擇）
```

**插單 / 結單 判定邏輯：**

| 狀態效果 | 行為 | 觸發條件 |
|---|---|---|
| 暫停、凍結、定身 | 插單 | 命中即插入，不論目標在做什麼 |
| 沉默 | 結單 | 目標讀條中且武器 `actionTags` 含 `法術` |
| 震懾 | 結單 | 命中即強制取消，不論動作類型 |
| 減速 | 插單（延長讀條） | 效果套用為讀條速率降低，不插入佇列 |

> **設計備注：** `即發` tag 的武器讀條時間極短，但不代表免疫所有插單，只是窗口小。真正免疫中斷需要特定職業技能或 Buff。

---

### 6.6 中斷效果矩陣（武器詞條附加能力）

中斷效果是**武器詞條的附加能力**（槽 5 附魔 or 槽 2 特殊動作），結構為：
```
[目標 tag 篩選] + [中斷效果強度]
```

**效果強度（從弱到強）：**

| 強度 | 效果 | 行為 |
|---|---|---|
| **緩速** | 讀條速率降低 N% | 插單：讀條變慢但不取消 |
| **中斷** | 讀條進度歸零 | 結單：清空進度，回到等待輸入 |
| **中斷且冷卻** | 進度歸零 + 被中斷武器進入 CD | 結單 + 武器 CD 懲罰，最強 |

**目標 tag 篩選範例（可任意組合）：**

| 詞條名稱 | 目標條件 | 效果 |
|---|---|---|
| 蓄力中斷者 | `actionTags` 含 `蓄力` | 中斷（不限物理/法術） |
| 法術沉默 | 含 `法術` | 結單（進度歸零）|
| 法術緩速 | 含 `法術` | 讀條速率 -N% |
| 物理中斷 | 含 `物理` | 結單 |
| 物理緩速 | 含 `物理` | 讀條速率 -N% |
| 蓄力封印 | 含 `蓄力` | 中斷且冷卻（最強版） |
| 全系中斷 | 無條件（震懾） | 結單，不論 tag |

> **設計備注：** tag 愈廣（`蓄力` > `法術蓄力`）= 適用範圍愈大，詞條稀有度通常對應更高；「中斷且冷卻」是同 tag 篩選下最強的效果。

---

### 6.7 中斷抗性（裝備/武器詞條）

玩家裝備可以提供對中斷效果的保護，分為**完全免疫**與**抵抗（降低效果）**：

| 詞條 | 效果 | 備注 |
|---|---|---|
| `無法被中斷且冷卻` | 免疫 CD 懲罰，中斷降級為「中斷（無 CD）」 | 防最強級詞條 |
| `無法被中斷` | 免疫進度歸零，中斷降級為「緩速」 | 防中級詞條 |
| `無法被緩速` | 免疫讀條速率降低 | 防弱級詞條 |
| `緩速抵抗 X%` | 緩速效果折減 X% | 較弱詞條，可與其他抗性疊加 |

**抗性互動原則：**
- 抗性詞條只降級效果，不會讓「中斷且冷卻」變為「無效」（需要兩層詞條）
- `即發` tag 武器本身不提供中斷抗性，只是讀條時間極短（命中窗口小）

---

### 6.5 地板觸發

移動到達目標格後，觸發地板事件（如陷阱、法陣、回復格）。
地板事件**可能產生 Debuff**（例：陷阱造成震懾 → 插入硬直到佇列），
流程如下：

```
抵達目標格 → 地板觸發檢查
  → 無觸發：ATB 歸零，重新累積
  → 有觸發（例：陷阱震懾）：插入硬直到佇列 → 等硬直結束 → ATB 歸零，重新累積
```

---

### 6.8 延遲傷害：空氣施法者模型

讀條結束後，傷害**不一定立即落地**。需要行進時間的彈幕、或持續一段時間的 AoE 區域，
以「**空氣施法者**（DelayedEffect）」實體掛在地圖上，擁有自己的讀條。

**設計原則（參考 WC3 dummy unit 機制）：**
- 施法者讀條完成 → 在目標格或行進路徑上生成 `DelayedEffect` 實體
- `DelayedEffect` 有自己的 `castRemaining`（倒計時），與施法者完全獨立
- **施法者讀條後被殺死，在途效果照常結算**（dummy unit 概念）
- `castRemaining` 歸零時，在掛載格觸發傷害/效果

**DelayedEffect 結構（引擎層）：**
```typescript
type DelayedEffect = {
  id: string
  kind: 'delayed_effect'
  pos: { x: number; y: number }     // 掛載格
  castRemaining: number             // 剩餘計時（time 單位）
  totalCast: number                 // 總計時（用於 UI 進度條）
  actionTags: string[]              // 繼承自施法武器（UI 配色用）
  sourceUnitId: string | null       // 施法者 id（可能已死亡）
  onResolve: ResolvePayload         // 到時觸發的效果描述
  affectedArea: { x: number; y: number }[]  // 影響格列表（UI 預覽用）
}
```

**AoE 持續傷害（例：火牆）：** 可用多個連續 `DelayedEffect` 疊加，每隔 N time 觸發一次，
或改用 `PersistentZone`（持續到條件解除，MVP1 後實作）。

## 9. 多人合作系統（MVP1 後）

### 9.1 ATB 時間軸

- 玩家與怪物共用同一條時間軸（方案 A）
- 輪到某玩家時，其他人等待該玩家操作完成
- 怪物行動由 AI 自動執行，不會卡住
- 玩家操作拖延屬於社交問題，系統不強制超時（MVP1 後可加超時自動跳過選項）

### 9.2 死亡與復活

**倒地：**
- 玩家 HP 歸零 → 成為**屍體**，留在原格，等待本層戰鬥結束或被復活
- ATB 不再推進（不參與時間軸直到復活）

**復活方式（優先序由低到高）：**

| 方式 | 說明 |
|------|------|
| 消耗品護身符 | 玩家自己攜帶，倒地時自動觸發，一次性 |
| 復活工具/魔法武器 | 隊友使用，目標格必須是屍體格 |
| 場地復活神像 | 地圖上特定格，隊友跑過去互動激活 |
| 戰鬥結束自動復活 | 本層所有戰鬥結束後，倒地玩家自動復活 |

**復活後的狀態：**
- HP 回復 10%，其他能量資源維持死前數值

### 9.3 失敗條件（地城設定時決定）

| 選項 | 說明 | 影響地城品質 |
|------|------|-------------|
| 全滅才失敗（預設/輕鬆） | 只要有一人存活就繼續 | 不加成 |
| 任一人死亡即失敗（困難） | 零死亡挑戰 | +地城品質倍率 |

失敗條件越嚴格 → 地城品質倍率越高 → 掉落裝備數值越強。

### 9.4 掉落分配

**個人掉落（Personal）：**
- 擊殺怪物後各人獨立獲得自己的個人寶箱抽獎機會（不可見他人）
- 類似 WoW 的個人任務寶箱，抽獎結果只有本人看到

**公開掉落（Need / Greed）：**
- 菁英怪、Boss 擊殺後，裝備掉落對全隊**可見**
- 每人選擇 Need（需要）或 Greed（貪婪）或 Pass
- Need 優先，相同選擇內隨機決定得主
- 每件只有一人能拿走

**帶回機制（多人版）：**
- 每位玩家各自擁有獨立的 5 個帶回格
- 個人掉落自動進入個人帶回格，公開掉落得主決定是否帶走

## 10. 怪物系統

### 10.1 怪物武器 Build

怪物使用**與玩家相同的武器系統**，但採預設配置（不讓怪物自行組 build）：

| 怪物等級 | 武器配置 |
|----------|----------|
| 小怪 | 1–2 把武器，1–2 個詞槽（例：攻擊模式 + 元素詞條 or 異常狀態詞條） |
| 菁英 | 2–3 把武器，3 個詞槽，可帶動作詞條（飛越等） |
| Boss | 完整 5 詞槽，手工設計，可有多階段 |

小怪的預設配置以「不容易出現設計錯誤的安全搭配」為原則，避免玩家遭遇不合理的組合。

### 9.2 掉落與「強奪」機制

- **掉落池與怪物裝備無直接關係**（掉落由難度係數 + 怪物類型 + 隨機決定）
- **強奪機制（限制版）**：
  - 特定工具（例：「掠奪者」）可以直接複製/奪取怪物裝備中的某一把武器
  - 限制：工具本身為聚氣制（地城中有限次數），不能無限奪取
  - Boss 的武器可以被強奪（提升趣味性且不影響平衡，因為 Boss 只有一個）
  - MVP1 後實作

## 11. UI 視覺設計

### 11.1 讀條系統（Per-Entity Cast Bar）

**每個有「進行中動作」的實體都在畫面上顯示自己的讀條**，不共用 UI 時間條。
這包含：玩家單位、怪物單位、`DelayedEffect`（空氣施法者）。

**讀條佈局：**
```
[動作標題]  [━━━━━━━━░░░░░░░░]
（左側文字）  （進度條，左到右填滿）
```

**讀條顏色依動作類型區分：**

| 顏色 | 動作類型 | 範例 |
|---|---|---|
| 藍色 | 法術讀條 | 「火球術」「冰封」 |
| 橘紅色 | 物理蓄力 | 「重斬蓄力」「破甲」 |
| 白/灰色 | 一般物理（即發） | 「爪擊」「刺擊」 |
| 綠色 | 移動 | 「移動」 |
| 紫色 | 工具/消耗品 | 「戰鼓」「藥水」 |
| 黃色脈衝 | 硬直 | 「硬直」（倒計時型） |
| 紅色脈衝 | DelayedEffect（敵方） | 「火球 爆炸」（倒計時型） |
| 橘色脈衝 | DelayedEffect（我方） | 「魔法陣 觸發」 |

### 11.2 目標區域預覽（Dashed Outline）

**從武器選定（不是讀條結束）那一刻起**，地圖上的影響格就顯示預告框線。
這讓玩家在讀條進行中能看到「哪裡即將被攻擊」，可選擇移動閃避或繼續。

| 框線顏色 | 意義 |
|---|---|
| **紅色虛線** | 敵方攻擊即將落在此格 |
| **黃色虛線** | 我方攻擊即將落在此格 |
| **橘色虛線** | DelayedEffect 倒計時中的影響區域 |

**多個預告共存：**
- 同一格可同時顯示多個框線（顏色疊加或輪流閃爍）
- 優先顯示最先觸發的那個（`castRemaining` 最小者框線較深）

**`DelayedEffect` 的預告框線：**
- 生成時即繪製影響格框線（`affectedArea` 欄位）
- 倒計時歸零時框線閃爍 → 觸發效果 → 框線消失
