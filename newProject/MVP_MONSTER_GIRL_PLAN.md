# MVP Monster Girl Dungeon Plan

## 核心一句話

玩家作為能夠引導與重組魔物血脈的帶隊者，率領 3 名魔物娘小隊進入短篇地城 run，透過位置、打斷、保護、區域控制與武器 build 取勝，並在村莊中用素材、基因因子與關鍵遺物解鎖新的種族證與進階證。

---

## MVP 目標

MVP 不追求大量角色、地圖或進化樹，而是先證明以下四件事同時成立：

- 3 人小隊 ATB 格子戰鬥本身足夠好玩
- 魔物娘 / 種族證包裝可以自然承載武器與成長系統
- 成長主要靠素材、工坊與換證，而不是經驗值灌數值
- 玩家會因隊伍分工、武器 build 與戰場局勢做有趣決策

---

## 世界觀骨架

### 玩家代表什麼

MVP 建議玩家不是傳統主角戰士，而是：

- 血脈調律者
- 遺傳鍛造師
- 魔物協調者
- 地城調查團帶隊者

這類身份的好處是：

- 可以合理帶領不同魔物娘組隊
- 可以合理操作種族證、基因因子與工坊強化
- 可以合理把地城戰利品解讀成素材、血脈樣本與遺物
- 玩家本身不是主戰單位，因此焦點會留在 3 人隊伍與 build 上

### 世界觀風格

方向採奇幻魔物娘，但避免過度依賴大量獨立角色美術。

核心原則：

- 種族特徵與武器表現可共用敵我美術語言
- 武器不一定是手持裝備，也可以是利爪、護腿踢擊、掃尾、撞角、翼擊等表現形式
- 同一個武器基底可以在不同種族證上用不同動畫語意重新解讀

這樣可以降低美術成本，同時讓玩家更容易理解敵我技能對應。

---

## 成長骨架

### 不採傳統經驗值升級

角色不以打怪累積經驗值作為主成長方式。

MVP 成長來源改為：

- 地城材料
- 貨幣
- 基因因子
- 關鍵遺物
- 工坊產出資格

### 種族證系統

種族證是角色的戰鬥型態與職能證明，不只是職業名稱。

它決定：

- 核心戰場責任
- 可用武器基底傾向
- 可用工具傾向
- 擅長的打斷類型
- 可進化分支方向
- 部分種族特徵 tag

### 進階證解鎖方式

進階證不靠等級，而靠：

- 素材累積
- 特定基因因子
- Boss 掉落的關鍵遺物
- 工坊製作 / 調律

這讓成長更接近：

- 解鎖新玩法
- 換新型態
- 開新 build 入口

而不是純數值上升。

### 保留少量品質隨機性

為了保留原本職業證的一點刷感與稀有感，可保留少量隨機品質，但不能主導整個系統。

MVP 建議：

- 種族證有品質等級，例如普通、優質、稀有
- 品質影響小幅基礎數值、可承載強化餘裕、或額外一個小型特徵欄位
- 品質不應改變核心戰場定位
- 新品質不應直接讓舊證報廢

也就是說，品質只提供：

- 稍好的成長空間
- 較佳的適配彈性
- 少量稀有感

而不是讓系統重新變回抽稀有度遊戲。

---

## 避免變成寶可夢式收藏遊戲的原則

魔物娘 / 種族證方向確實容易往收藏驅動偏移，因此 MVP 要明確壓住以下原則：

- 戰鬥是主體，收藏是長期動機，不可顛倒
- 3 人隊伍戰場責任與武器 build 必須比圖鑑收集更重要
- 新證主要帶來玩法分支，不是單純戰力上位
- 同一角色可透過不同種族證切換玩法，而不是一直換掉舊角色
- 地城內主要產出素材與調律資源，而不是大量角色掉落

如果以上原則守住，就不會直接滑向純收集遊戲。

## MVP 的 3 個基本職業證

MVP 正式採用以下世界觀命名：

- `牙刃證`
- `護膜證`
- `妖織證`

玩家初期持有的御三家種族證分別為：

- `月狼證`
- `凝膠證`
- `風羽證`

### 1. 牙刃證

戰場責任：

- 切入
- 破陣
- 背刺鋪墊
- 反制重蓄力

擅長打斷：

- `heavy_cast`
- 部分 `light_cast`

代表武器基底：

- 直線突刺
- 側步斬
- 裂陣橫掃

特徵語言：

- 高機動近戰
- 突入與換位
- 從角度取得優勢

### 2. 護膜證

戰場責任：

- 保護隊友
- 擋線
- 吃技能
- 維持我方陣型

擅長打斷：

- `light_cast`
- `projectile_cast`
- 部分 `guard_cast`

代表武器基底：

- 盾擊護衛
- 攔截突進
- 壁障重槌

特徵語言：

- 前線壓住空間
- 正面承受與攔截
- 讓隊友安全完成高價值行動

### 3. 妖織證

戰場責任：

- 區域控制
- 遠程壓制
- 場地塑形
- 拆特定施法

擅長打斷：

- `zone_cast`
- `projectile_cast`
- 特定控制型打斷

代表武器基底：

- 直線射擊
- 落點爆裂
- 束縛標記

特徵語言：

- 延遲爆發
- 場地危險區
- 限位與節奏干涉

## 證件結構：每系 1 基礎 + 2 進階

MVP1 採固定結構：

- 每個大類有 `1 個基礎證`
- 每個大類有 `2 個進階變體`
- 玩家初期先使用 3 張基礎證
- 敵人可先使用基礎證與進階證，以增加戰場辨識與內容變化

這樣的好處是：

- 內容結構清楚
- 敵我可共用同一套證件語言
- 後續玩家解鎖進階證時不需要重做世界觀與系統框架

### 牙刃系

- 基礎：`月狼證`
- 進階 A：`獵月證`
- 進階 B：`裂牙證`

分支方向：

- `獵月證` 偏背刺、追獵、高機動收頭
- `裂牙證` 偏破陣、重打斷、正面強突

### 護膜系

- 基礎：`凝膠證`
- 進階 A：`護潮證`
- 進階 B：`蝕黏證`

分支方向：

- `護潮證` 偏保護、吸收、攔截與前線承受
- `蝕黏證` 偏腐蝕、降抗、牽制與限位

### 妖織系

- 基礎：`風羽證`
- 進階 A：`鳴羽證`
- 進階 B：`灼羽證`

分支方向：

- `鳴羽證` 偏遠程干擾、拆施法、打斷與節奏控制
- `灼羽證` 偏燃燒、易傷、區域壓制與爆發鋪墊

## MVP1 專用武器策略

MVP1 中，每個進階證額外新增 `1 把專用武器` 即可。

這些專用武器的原則是：

- 以該系基礎武器的強化版為主
- 保留原本動作骨架
- 提升數值、適配被動或讓用途更聚焦
- 不急著加入太多新規則或過度特殊的演出

這樣可以先驗證：

- 進階證是否真的有明顯玩法分支
- 專用武器是否足以讓進階證有成長感
- 系統是否能在不暴增內容成本下成立

### 牙刃系專用武器

#### `獵月證`：`影牙連襲`

基礎來源：

- 由 `側步斬` 強化而來

強化方向：

- 更高機動
- 更高背刺收益
- 更適合追擊收頭

MVP1 先只需做成：

- 傷害略升
- cast 或 recovery 略優
- 背後命中收益略高

#### `裂牙證`：`崩牙重突`

基礎來源：

- 由 `直線突刺` 強化而來

強化方向：

- 更高打斷
- 更高正面突破能力
- 更適合處理 `heavy_cast`

MVP1 先只需做成：

- 傷害略升
- interrupt 略升
- 對重蓄力敵人的收益略高

### 護膜系專用武器

#### `護潮證`：`潮膜護撞`

基礎來源：

- 由 `盾擊護衛` 或 `凝膠護打` 強化而來

強化方向：

- 更高保護效率
- 更穩定的攔截與承傷
- 更適合站前排保人

MVP1 先只需做成：

- 傷害略升
- 保護倍率略升
- 正面減傷或攔截效率略優

#### `蝕黏證`：`蝕液重壓`

基礎來源：

- 由 `凝膠護打` 或 `重壓控場` 強化而來

強化方向：

- 更高腐蝕效率
- 更好上 `Vulnerable` 或 `Expose Impact`
- 更能限制敵方行動

MVP1 先只需做成：

- 傷害略升
- 控場值略升
- 更穩定施加腐蝕或易傷

### 妖織系專用武器

#### `鳴羽證`：`裂響羽矢`

基礎來源：

- 由 `直線射擊` 強化而來

強化方向：

- 更高遠程干擾能力
- 更高打斷適配
- 更擅長拆投射與讀條

MVP1 先只需做成：

- 傷害略升
- interrupt 略升
- 對 `projectile_cast` 或 `zone_cast` 收益略高

#### `灼羽證`：`焰羽墜爆`

基礎來源：

- 由 `落點爆裂` 強化而來

強化方向：

- 更高區域壓制
- 更穩定燃燒與易傷鋪墊
- 更適合幫主攻手創造收頭線

MVP1 先只需做成：

- 傷害略升
- DoT 或易傷施加更穩
- 區域用途略強

## 武器系統如何被魔物娘世界觀重新解讀

武器基底仍然是技能資料骨架，但對玩家表現時可改用生體 / 血脈語言描述。

例如：

- `line_thrust` 可以被解讀成裂牙突進、角衝、腿甲穿刺
- `arc_slash` 可以被解讀成爪掃、尾鞭、翼斬
- `guard_bash` 可以被解讀成殼撞、肩甲衝護、角盾頂擊
- `ground_burst` 可以被解讀成爆卵、焰囊炸裂、結晶噴發

這代表：

- 武器系統不必因世界觀而重寫
- 美術與動畫可以在同一骨架上做風格化變體
- 玩家也比較容易接受敵我共用技能語言

## 種族特徵 tags

MVP 可先只做少數幾種種族特徵 tag：

- `has_claws`
- `has_tail`
- `has_wings`
- `has_shell`
- `has_horns`
- `has_venom`

這些 tag 可用於：

- 解鎖特定武器基底表現
- 限制或加成某些戰術插件
- 決定進階證分支條件
- 讓世界觀與機制欄位連起來

例如：

- `has_tail` 可支援掃尾、尾刺、甩尾護衛
- `has_wings` 可支援俯衝、飛掠換位、風壓壓制
- `has_shell` 可支援殼撞、殼壁、重槌退敵

## MVP 武器資料結構

每個武器技能先拆成：

- 動作骨架
- 時序孔
- 戰術孔
- 附魔孔

MVP1 進一步採用「武器認主人」的方向。

也就是：

- 職業證不直接硬鎖武器清單
- 職業證提供 `family`、種族特徵 tag、承載方向與戰鬥風格
- 武器基底根據需求條件去尋找最適合的使用者
- 不同使用者可使用同一把武器，但不一定能開啟完整效果

### 動作骨架

定義：

- 命中形狀
- 施放距離
- 基礎 cast / recovery
- 基礎傷害
- 基礎打斷值
- 原生位移或保護傾向

### 武器使用模式

每把武器在 MVP1 先有兩種使用模式：

- `base_mode`
- `perfect_match_mode`

#### `base_mode`

代表：

- 角色符合最低使用條件
- 可以裝備並正常使用武器
- 能獲得基礎傷害與基礎功能

#### `perfect_match_mode`

代表：

- 使用者與武器達成完整匹配
- 開啟完整傷害公式與完整戰術效果

MVP1 的完整匹配條件先主要看：

- 職業證 `family`
- 種族特徵 tags
- 少量武器風格 tags

#### 完整匹配可影響的欄位

MVP1 先只讓以下幾種效果受匹配影響：

- 傷害公式是否完整
- 位移 / 推拉 / 換位是否啟用
- 打斷強度或打斷型別是否完整
- 附帶狀態是否啟用

這代表：

- 非完整匹配仍可使用武器
- 但會失去該武器最有辨識度的靈魂效果

### 時序孔

負責：

- 快招 / 重蓄力 / 破招 / 守勢等節奏人格

### 戰術孔

負責：

- 推位
- 拉位
- 換位
- 保護
- 擋線
- 區域效果
- 反蓄力

### 附魔孔

負責：

- 火 / 冰 / 雷 / 風 / 光 / 暗等傷害語言
- DoT、異常、控制或支援傾向

### 武器與職業證的匹配關係

MVP1 建議每把武器資料至少具有：

- `requiredTags`
- `preferredFamilies`
- `preferredTags`
- `baseMode`
- `perfectMatchMode`

判定流程可先簡化為：

- 先檢查是否符合最低使用條件
- 再檢查是否達成完整匹配
- 最後 resolve 成本次實際使用的武器效果

例如：

- `裂牙突進` 可被非牙刃系使用，但完整匹配的牙刃系可開啟前進與更完整的破招收益
- `凝膠護打` 可被非護膜系使用，但完整匹配的護膜系可開啟更完整的保護與黏著效果
- `裂響羽矢` 可被非妖織系使用，但完整匹配的妖織系可開啟更完整的遠程打斷與風壓干擾

## 打斷型別

MVP 打斷不應只看數值，還要看型別。

施放中的技能可帶：

- `light_cast`
- `heavy_cast`
- `projectile_cast`
- `zone_cast`
- `guard_cast`

武器或插件則提供對應的 `interruptTags`。

判定原則：

- 先看打斷型別是否匹配
- 再看打斷強度是否足夠

這樣能保留不同職業證處理不同威脅的分工。

---

## 職業證本體承載

MVP1 不採傳統 RPG 的頭、身、手、腳裝備欄。

改為：

- 職業證本體決定承載能力
- 一張證同時決定武器、基因與工具的承載方式

這代表角色 build 的核心不是穿了哪些部位裝，而是：

- 用哪張證
- 證上裝了哪些武器
- 證上裝了哪些基因
- 證上攜帶哪些戰術工具

### 職業證承載欄位

MVP1 每張基礎證先提供：

- 武器承載位
- `1` 個專用基因位
- `2` 個通用基因位
- `1` 個戰術工具位

其中專用基因位為：

- 該證的 `2 選 1` 核心取捨基因

未來進階證可再視需要增加：

- 更高階的專用基因
- 額外工具位
- 更高品質的承載餘裕

## 基因強化系統

MVP1 將非武器裝備正式包裝為：

- `基因強化`
- `血脈調律`
- `證件承載的遺傳模組`

### 基因系統原則

- 通用基因可自由裝配
- 不因職業證不同而禁止裝配
- 專用基因則綁定證件本體
- 系統不阻止玩家把史萊姆娘養成高攻擊型，或把狼人養成高耐久型

### 基因分類

MVP1 先分成：

- `專用基因`
- `通用基因`

#### 專用基因

- 每張基礎證提供 `2 個專用取捨基因`
- 玩家在該證上 `2 選 1`
- 用來定義該證最核心的玩法分流

#### 通用基因

- 所有證都可裝配
- 主要提供基本屬性、抗性、自然回復與小型戰鬥補強
- 看起來多樣，但資料面仍保持低複雜度

### 通用基因效果模型

MVP1 的通用基因採用：

- `baseEffect`
- `synergyEffect`

#### `baseEffect`

代表：

- 任意職業證裝上都會生效
- 提供穩定、可預期的基礎收益

#### `synergyEffect`

代表：

- 若基因與特定證件 family 或 tag 適配
- 額外再開啟一段附加效果

原則是：

- 不做硬限制
- 不做裝錯懲罰
- 不削弱基礎數值收益
- 只在適配時多給一段額外玩法效果

這樣可以同時保留：

- 玩家自由 build
- 證件身份辨識
- 程式實作上的可控性

### 專用基因：御三家基礎證

#### `月狼證`

- `獵性回響`
- `裂陣本能`

#### `凝膠證`

- `護膜再生`
- `蝕液滲透`

#### `風羽證`

- `羽咒延展`
- `裂響共鳴`

這 6 個專用基因代表：

- 月狼證可在追擊收頭與正面破陣之間做取捨
- 凝膠證可在純保護與腐蝕牽制之間做取捨
- 風羽證可在 debuff 延展與拆施法之間做取捨

### 通用基因方向

MVP1 的通用基因先集中於：

- HP / 傷害 / cast / recovery 等基本屬性
- `Burn`、`Bind`、`Shock` 等狀態抗性
- 自然回復效率提升
- 打斷值、保護效率、區域技等小型戰鬥補強

例如可先做：

- `生命增幅`
- `力量基因`
- `再生因子`
- `灼燒耐性`
- `束縛耐性`
- `震盪回路`
- `迅捷因子`
- `保護增幅`

其中像 `力量基因` 這類通用件應遵守：

- 任何證都能吃到完整基礎傷害提升
- 適配證僅額外解鎖小型附加效果
- 不可讓非適配證因此變成明顯虧損

### 進階基因的延伸方式

未來若加入：

- 進階證專用基因
- 高稀有遺傳模組
- Boss 或特殊地城掉落的特規基因

也建議沿用同一套思路：

- 以 `case` 或資料表分派效果
- 先套通用基礎效果
- 再視證件條件決定是否追加額外效果

## 玩家戰術工具

MVP1 不以傳統補血藥作為主要主動資源。

改為：

- 玩家單位攜帶有限次數的戰術工具
- 戰術工具是玩家相對地城敵人的關鍵優勢
- 地城敵人原則上不使用這套外掛工具系統

### 戰術工具的用途

戰術工具主要用於：

- 爆發窗口
- 保命
- 解狀態
- 控場
- 節奏調整

而不是單純回復血量。

### MVP1 工具欄位

每張基礎證先提供：

- `1` 個戰術工具位

未來再視內容量考慮增加到：

- `2` 個工具位

### 戰術工具範例

- `戰鼓`：短時間提升全隊傷害或打斷
- `護膜包`：提供短暫護盾或保護
- `淨化霧瓶`：解除狀態
- `驚鳴彈`：干擾讀條或投射
- `黏網膠囊`：短時間限位

這些工具的價值在於：

- 讓玩家能在關鍵局面主動打開節奏
- 放大本來就存在的三人連技
- 成為對抗森林地城進階敵人與 Boss 的核心優勢

## MVP 地城 loop

MVP1 先維持單一主題地城：

- `森林主題地城`

雖然玩家與敵人會混用狼人、鳥身女妖、史萊姆娘等種族證，但整體場景、地形與 Boss 敘事先統一在森林地城中，以降低內容製作壓力。

### 村莊

玩家在村莊中：

- 編成 3 人隊伍
- 為每位角色裝備種族證
- 裝配 3 把主武器與工具
- 進行工坊強化、附魔與調律
- 消耗素材解鎖或升格新證

### 地城 run

地城 run 目標先維持短篇：

- 數場戰鬥
- 進階職業對抗樓層
- 1 到 2 次補給
- 1 場 Boss 戰

主要獲得：

- 貨幣
- 材料
- 基因因子
- 關鍵遺物
- 少量高品質工坊產出資格

### 回村莊

玩家把地城成果轉化為：

- 新證解鎖
- 證件升格
- 工坊打造
- 新 build 嘗試

---

## 森林主題地城的對局結構

MVP1 森林地城可先簡化成以下節奏：

- 一般戰 1：認識地城中常規敵方組合
- 一般戰 2：開始出現跨職能混編敵人
- 進階職業對抗樓層：首次面對敵方進階證
- 補給
- 一般戰 3 或菁英前哨戰
- 最終 Boss 戰

這樣的好處是：

- 玩家能先熟悉御三家與基礎武器節奏
- 進階證不會太早登場，能保留辨識與壓力
- Boss 戰前會先見過高一階敵人，降低最終戰學習成本

### 進階職業對抗樓層

原本的精英怪樓層可直接改成「進階職業對抗樓層」。

其目的不是單純提高數值，而是讓玩家提早見到：

- `獵月證`
- `裂牙證`
- `護潮證`
- `蝕黏證`
- `鳴羽證`
- `灼羽證`

中的少量組合。

MVP1 可先控制成：

- 每次只出現 `1 名進階證敵人`
- 再搭配 `1 到 2 名基礎證敵人`

這樣可以讓玩家學到：

- 進階證和基礎證的差異
- 特殊被動或專用武器帶來的戰場壓力
- 後續 Boss 戰會出現更高階段敵人的心理預期

---

## 森林最終 Boss 戰

MVP1 最終 Boss 建議採用：

- `牙刃系三階 Boss`
- 視覺風格可解讀為 `巨熊獸娘`
- 系統定位上仍屬於牙刃系終階個體

Boss 戰目的不是展開完整三階系統，而是：

- 提供終極職業的期待感
- 做出傳統 RPG / SRPG 終盤 Boss 壓力
- 讓玩家用完整的 3 人連技與保護系統過關

### Boss 名稱方向

MVP1 可先用暫名：

- `山王牙證`

### Boss 戰基本結構

這場 Boss 戰建議採用標準傳統兩段式設計：

#### 第一階段：穩定壓迫

Boss 以牙刃系重突進與正面突破為主，讓玩家學會：

- 觀察重蓄力
- 使用打斷型別對應
- 用史萊姆娘保人與擋線
- 用鳥身女妖先鋪 debuff，再讓狼人爆發

此階段重點是「看懂 Boss 的主要威脅」。

#### 第二階段：山王化

當 Boss 血量降低到特定門檻後，進入強化階段：

- 主要武器升格為更高壓力版本
- 打斷與傷害提升
- 對前排與重蓄力失誤的懲罰變大

此階段重點是「測試玩家是否真的掌握整套戰鬥核心」。

### Boss 專用武器

Boss 專用武器可先定為：

- `山王崩牙`

其本質是 `崩牙重突` 的 Boss 強化版，MVP1 先只需做到：

- 傷害更高
- interrupt 更高
- 對正面目標更有壓迫
- 若未被妥善處理，會快速拉開戰局差距

### Boss 被動

MVP1 建議只給 1 個明確被動即可：

#### `獸王壓境`

概念效果：

- Boss 在施放重蓄力技能時，若未被打斷，後續牙刃攻擊會得到強化

這樣可以直接逼玩家玩你要的核心：

- 先看讀條
- 再決定打斷、保護、限位或爆發

### 弱化小狼人增援

Boss 戰中可以加入少量增援，但建議克制。

MVP1 可用：

- `1 隻弱化版月狼證敵人`

作為額外打手。

其用途是：

- 給玩家一點場面壓力
- 增加史萊姆娘保人與卡位的價值
- 讓鳥身女妖的區域技與 DoT 更有清場意義

但原則是：

- 增援數量少
- 數值低於正常同級敵人
- 不可搶走 Boss 作為主威脅的存在感

### Boss 戰成功條件

這場戰鬥理想上應讓玩家體會到：

- 沒有鋪墊時很難正面硬拼
- 有打斷、降抗、保護、限位時，Boss 也能被拆解
- 完整連技成功時，主攻手能打出非常有成就感的爆發

這會是整個 MVP1 森林地城的總結戰。

## MVP 不做的事

先不做：

- 大量角色圖鑑收集
- 複雜多階進化樹
- 過量稀有度分層
- 大量手動撿裝
- 以刷裝為主的掉寶迴圈
- 讓品質差直接決定角色是否可用

MVP 只需要證明：

- 3 個基本職業證有清楚分工
- 種族證包裝能自然承載戰鬥與成長
- 3 孔武器 build 能讓戰場決策有趣
- 玩家願意為新證與新 build 再打一輪地城
