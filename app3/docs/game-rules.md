# 魔物娘戰棋遊戲規則

## 📖 遊戲概述

**魔物娘戰棋**是一款雙人對戰的卡牌戰棋遊戲。玩家扮演魔物娘軍團的指揮官，通過召喚首領、裝備軍團、使用事件卡和反應卡，最終攻破敵方基地獲得勝利。

### 🎯 勝利條件
- **摧毀敵方基地** - 將敵方城牆生命力降至0

### 🗺️ 戰場結構
```
[我方基地] ← [我方戰場] ← [敵方戰場] → [敵方基地]
```
- **我方基地** - 玩家的基地區域，包含城牆（生命力5），守護者優勢區域
- **我方戰場** - 我方前線區域，指揮官優勢區域
- **敵方戰場** - 敵方前線區域，破壞者優勢區域
- **敵方基地** - 敵方基地區域，攻城目標
- **磚堆** - 每個區域都有磚堆，用於防禦和築城

---

## 🎴 卡牌類型

### **1. 首領卡（Leader Card）**
- **數量** - 每位玩家選擇3張首領卡
- **職業** - 破壞者、征服者、指揮官、守護者
- **屬性**
  - **堅韌（Toughness）** - 生命值，降至0時進入暈眩狀態
  - **對敵（Attack）** - 攻擊力
  - **防護協助（Defensive Support）** - 防禦支援值
  - **攻擊協助（Offensive Support）** - 攻擊支援值
  - **回復力（Recovery）** - 每回合自動回復的堅韌值
- **技能**
  - **被動技能** - 持續生效的能力
  - **主動技能（絕招）** - 需要冷卻的強力技能

### **2. 軍團卡（Legion Card）**
- **功能** - 裝備在首領身上，提供屬性加成和額外能力
- **分類** - 通用軍團、職業專屬軍團
- **效果**
  - **屬性加成** - 增加首領的各項屬性
  - **被動能力** - 裝備時持續生效
  - **主動技能** - 部分軍團卡有主動技能

### **3. 事件卡（Event Card）**
- **使用時機** - 主要階段
- **類別**
  - **移動類** - 改變首領位置
  - **增益類** - 提升我方能力
  - **控制類** - 限制敵方行動
  - **資源類** - 抽牌、築城、修城
  - **特殊類** - 獨特效果
- **成本** - 丟棄手牌或免費

### **4. 反應卡（Reaction Card）**
- **使用方式** - 安裝在首領身上
- **觸發時機**
  - 受到對敵時
  - 進入暈眩/擊敗時
  - 敵人清磚時
  - 敵人進入區域時
- **使用後** - 大部分反應卡使用後棄置

### **5. 建築卡（Building Card）**
- **放置位置** - 磚堆區
- **類型**
  - **通用區域建築** - 可放置在廣場區或主堡區
  - **基地專用建築** - 只能放置在主堡區
- **堅韌值** - 建築卡有堅韌值，可被清磚破壞
- **持續效果** - 在場上時持續生效

## 🎮 遊戲流程

### **遊戲準備**
1. **選擇首領** - 每位玩家選擇3張首領卡
2. **構築牌組** - 準備軍團卡、事件卡、反應卡、建築卡（建議30-40張）
3. **初始設置**
   - 城牆生命力：5
   - 初始手牌：5張
   - 所有首領放置在我方基地
   - 每個區域初始磚堆：2

### **回合結構**

#### **1. 回合開始階段**
- 重置所有首領的行動狀態
- 技能冷卻-1
- 觸發「回合開始時」的效果
- 所有首領根據回復力自動回復堅韌

#### **2. 抽牌階段**
- 抽1張牌（標準）
- 若手牌為0，則抽2張牌

#### **3. 主要階段**
可以進行以下行動（無順序限制）：

**A. 召喚軍團**
- 一回合一次，將手牌中的軍團卡裝備在首領上
- 每個首領同時只能裝備1張軍團卡
- 新軍團會取代舊軍團（舊軍團棄置）
- 部分軍團卡需要丟棄手牌作為成本

**B. 使用事件卡**
- 打出手牌中的事件卡
- 支付成本（丟棄手牌或免費）
- 執行效果後棄置事件卡

**C. 安裝反應卡**
- 將反應卡安裝在首領身上
- 每個首領可以安裝多張反應卡
- 觸發條件滿足時自動發動

**D. 放置建築卡**
- 將建築卡放置在磚堆區
- 每個磚堆區最多1張建築卡
- 建築卡取代該區域的磚堆

**E. 首領行動**
每個首領每回合可以進行以下行動：

1. **移動**
   - **標準移動** - 移動至相鄰區域（1格）
   - **征服者特性** - 部分征服者可以移動2格
   - **移動限制** - 移動至敵方區域時，可能觸發敵方反應卡
   - **區域順序** - 我方基地 ↔ 我方戰場 ↔ 敵方戰場 ↔ 敵方基地

2. **對敵（攻擊）**
   - 對同區域的敵方首領造成傷害
   - 傷害 = 對敵值 + 攻擊協助 - 敵方防護協助
   - 可以與同區域友軍聯手（協助力加總）

3. **清磚**
   - 清除敵方區域的磚堆
   - 清磚值 = 基礎清磚能力（通常等於對敵值）
   - 可以選擇破壞建築卡

4. **攻城**
   - **只能在敵方基地攻城**
   - 攻城值 = 對敵值
   - 攻城傷害 = 攻城值 - 磚堆值（磚堆先承受傷害）
   - 城牆生命力降至0時，遊戲結束

5. **築城**
   - 在我方區域（我方基地或我方戰場）增加磚堆
   - 築城值通常為1

6. **修城**
   - 只能在我方基地修復城牆生命力
   - 修城值通常為1

7. **使用技能**
   - 使用首領或軍團的主動技能
   - 需要支付成本（丟棄手牌）
   - 技能使用後進入冷卻

#### **4. 回合結束階段**
- 檢查手牌上限（通常為7張，超過需棄牌）
- 觸發「回合結束時」的效果
- 回合交給對手

## ⚔️ 戰鬥規則

### **對敵（攻擊）計算**
```
實際傷害 = 攻擊方對敵 + 攻擊方攻擊協助 - 防禦方防護協助
```

### **聯手攻擊**
- 同區域的多個友軍可以聯手攻擊同一目標
- 聯手時，所有參與者的對敵值和協助力加總
- 防禦方只計算一次防護協助

### **暈眩狀態**
- 首領堅韌降至0時，進入暈眩狀態
- 暈眩的首領：
  - 不能行動
  - 不能提供協助
  - 對敵值和防護協助降為0
- 暈眩的首領在下回合開始時，堅韌回復至1，解除暈眩

### **擊敗（KO）**
- 暈眩狀態的首領再次受到傷害時，進入擊敗狀態
- 擊敗的首領：
  - 返回我方基地
  - 裝備的軍團卡棄置
  - 堅韌回復至1
  - 下回合可以重新行動

## 🏰 區域與磚堆規則

### **磚堆系統**
- 每個區域都有磚堆（初始值通常為2）
- 磚堆作用：
  - 防禦：減少攻城傷害
  - 築城：增加磚堆高度
  - 清磚：減少敵方磚堆

### **築城規則**
- 在我方區域可以築城
- 築城+1磚堆
- 磚堆上限通常為5

### **清磚規則**
- 在敵方區域可以清磚
- 清磚-1磚堆
- 磚堆為0時，可以選擇破壞建築卡

### **攻城規則**
- **只能在敵方基地攻城**
- 攻城傷害 = 攻城值 - 磚堆值
- 磚堆先承受傷害，剩餘傷害才會傷害城牆

**範例：**
```
攻城值3，磚堆2 → 磚堆歸0，城牆-1
攻城值2，磚堆3 → 磚堆-2，城牆無傷害
```

### **區域推進**
- 首領需要逐步推進才能到達敵方基地
- **推進路線** - 我方基地 → 我方戰場 → 敵方戰場 → 敵方基地
- **征服者優勢** - 可以快速穿插，跳過區域

## 🎯 職業特色

### **破壞者（Destroyer）**
- **特點** - 高攻擊、清磚、攻城
- **優勢** - 快速推進、破壞建築、在敵方戰場和敵方基地戰鬥力強
- **弱點** - 防禦較弱、回復力低
- **定位** - 前線攻擊手，推進至敵方基地攻城

### **征服者（Conqueror）**
- **特點** - 高機動、快速攻擊
- **優勢** - 靈活移動、突襲、可以快速穿插多個區域
- **弱點** - 堅韌較低
- **定位** - 機動突襲手，快速移動打亂敵方陣型

### **指揮官（Commander）**
- **特點** - 高協助力、控制
- **優勢** - 支援友軍、限制敵人、在我方戰場和敵方戰場提供強力支援
- **弱點** - 單體戰鬥力較弱
- **定位** - 中場控制者，在戰場區域支援和控制

### **守護者（Guardian）**
- **特點** - 高堅韌、回復、築城
- **優勢** - 持久戰、防禦、在我方基地和我方戰場防禦力強
- **弱點** - 攻擊力低、機動性差
- **定位** - 後方防守者，保護我方基地和提供持續回復

## 📋 關鍵術語

### **基礎術語**
- **堅韌** - 首領的生命值
- **對敵** - 攻擊力
- **清磚** - 清除磚堆
- **攻城** - 攻擊城牆
- **築城** - 增加磚堆
- **修城** - 修復城牆
- **回復** - 恢復堅韌值

### **狀態術語**
- **暈眩** - 堅韌歸0，不能行動
- **擊敗（KO）** - 暈眩狀態再受傷，返回基地
- **癱瘓** - 不能行動，但保留協助力
- **禁錮** - 不能移動和行動
- **擊退** - 強制移動至指定區域

### **協助術語**
- **防護協助** - 減少受到的傷害
- **攻擊協助** - 增加友軍的攻擊力
- **聯手** - 多個單位共同攻擊

## 🎲 進階規則

### **軍團召喚規則**
- **標準召喚** - 一回合一次，免費裝備軍團卡
- **額外召喚** - 通過事件卡或技能效果，可以額外召喚
- **召喚成本** - 部分強力軍團需要丟棄手牌
- **軍團取代** - 新軍團會取代舊軍團

### **首領擊敗規則**
- 首領被擊敗時：
  1. 裝備的軍團卡棄置
  2. 安裝的反應卡保留
  3. 返回我方主堡區
  4. 堅韌回復至1
  5. 下回合可以重新行動

### **建築破壞規則**
- 敵人清磚時可以選擇破壞建築卡
- 建築卡被破壞時送入墓地
- 部分建築卡有職業破壞限制：
  - **城門** - 破壞者職業可破壞
  - **中繼點** - 守護者職業可破壞

### **建築放置規則**
- **我方基地** - 可放置基地專用建築（要塞城牆、神聖祭壇）
- **我方戰場** - 可放置通用建築（城門、箭塔、雜魚群體）
- **敵方戰場** - 可放置攻擊性建築（需要特殊卡牌效果）
- **敵方基地** - 通常不能放置建築

### **反應卡規則**
- 反應卡安裝在首領身上
- 觸發條件滿足時自動發動
- 大部分反應卡使用後棄置
- 首領被擊敗時，反應卡保留

## 💡 戰術建議

### **開局策略**
1. **平衡首領選擇** - 選擇不同職業的首領，形成互補
2. **前後線配置** - 破壞者/征服者前線，指揮官中場，守護者後方
3. **控制戰場區** - 我方戰場和敵方戰場是關鍵戰場
4. **築城防禦** - 在我方基地和我方戰場築城，建立防禦縱深

### **中期策略**
1. **推進前線** - 破壞者推進至敵方戰場，清除磚堆
2. **裝備軍團** - 為首領裝備合適的軍團卡，提升戰鬥力
3. **使用事件卡** - 在關鍵時刻使用事件卡扭轉局勢
4. **安裝反應卡** - 為首領安裝反應卡，增加防禦能力
5. **區域控制** - 控制敵方戰場，為攻城做準備

### **終局策略**
1. **推進至敵方基地** - 破壞者推進至敵方基地
2. **清除磚堆** - 先清除敵方基地的磚堆
3. **集中攻城** - 集中火力攻擊敵方城牆
4. **保護自己** - 注意防守自己的基地，避免被反殺
5. **征服者突襲** - 利用征服者快速移動能力，直接突襲敵方基地

## ❓ 常見問題

### **Q1: 首領被擊敗後，裝備的軍團卡會怎樣？**
A: 軍團卡會被棄置，但反應卡會保留。

### **Q2: 可以同時裝備多張軍團卡嗎？**
A: 不行，每個首領同時只能裝備1張軍團卡。

### **Q3: 暈眩的首領還能提供協助嗎？**
A: 不行，暈眩的首領不能提供任何協助。

### **Q4: 攻城時，磚堆和城牆哪個先承受傷害？**
A: 磚堆先承受傷害，剩餘傷害才會傷害城牆。

### **Q5: 反應卡可以安裝多張嗎？**
A: 可以，每個首領可以安裝多張反應卡。

### **Q6: 建築卡被破壞後會怎樣？**
A: 建築卡送入墓地，該區域的磚堆恢復正常。

### **Q7: 聯手攻擊時，如何計算傷害？**
A: 所有參與者的對敵值和攻擊協助加總，減去防禦方的防護協助。

### **Q8: 首領的回復力是什麼時候生效？**
A: 在回合開始階段，所有首領自動回復堅韌值。

## 🎯 設計理念

### **核心設計目標**
1. **策略深度** - 多種戰術選擇，需要思考和規劃
2. **互動性** - 雙方頻繁互動，不是單方面推進
3. **平衡性** - 四大職業各有特色，無絕對強弱
4. **易學難精** - 規則簡單易懂，但戰術變化豐富

### **職業平衡**
- **破壞者** - 攻擊型，快速推進
- **征服者** - 機動型，靈活突襲
- **指揮官** - 支援型，控制戰場
- **守護者** - 防禦型，持久戰

### **卡牌平衡**
- **首領卡** - 核心戰力，各有特色
- **軍團卡** - 強化首領，提供多樣性
- **事件卡** - 戰術變化，扭轉局勢
- **反應卡** - 防禦手段，增加互動
- **建築卡** - 場地控制，戰術深度
