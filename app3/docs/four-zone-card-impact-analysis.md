# 四區域設計卡牌影響分析

## 📊 區域變更總結

### **舊設計（三區域）**
```
[我方主堡區] ← [廣場區（中立）] → [敵方主堡區]
```

### **新設計（四區域）**
```
[我方基地] ← [我方戰場] ← [敵方戰場] → [敵方基地]
```

---

## 🎯 核心規則變更

### **1. 移動規則**
- **舊** - 移動1格（主堡↔廣場）
- **新** - 移動1格（基地↔戰場↔戰場↔基地），征服者可移動2格

### **2. 攻城規則**
- **舊** - 在敵方主堡區可攻城
- **新** - **只能在敵方基地攻城**（需要推進3格）

### **3. 修城規則**
- **舊** - 在我方主堡區可修城
- **新** - **只能在我方基地修城**

### **4. 築城規則**
- **舊** - 在我方區域可築城
- **新** - 在我方基地或我方戰場可築城

### **⚠️ 需要調整的首領卡**

#### **1. 哈比娘（征服者）**
**問題：**
- **絕招** - "移動至任意區域，對區域內1位敵首領對敵4、擊退1格"
- **影響** - 四區域下，"任意區域"可能過強（可直接跳到敵方基地）

**建議調整：**
```typescript
// 舊版
skill: {
  name: '俯衝突襲',
  description: '移動至任意區域，對區域內1位敵首領對敵4、擊退1格'
}

// 新版（建議）
skill: {
  name: '俯衝突襲',
  description: '移動至距離2格內的區域，對區域內1位敵首領對敵4、擊退1格',
  cooldown: 2
}
```
