## 🏗️ 建築卡核心機制

### 1. 建築堅韌度（Building Toughness）

**定義：**
- 建築卡的生命值
- 數值範圍：1-3
- 代表建築的耐久程度

**堅韌度等級：**
```
堅韌度 1：脆弱建築
- 容易被破壞
- 通常是進攻型或經濟型建築
- 範例：火焰陷阱、魔力泉水、治癒聖泉

堅韌度 2：標準建築
- 中等耐久
- 大部分建築使用此數值
- 範例：元素祭壇、龍族聖殿、攻城塔、天空平台

堅韌度 3：堅固建築
- 難以破壞
- 通常是防禦型建築
- 範例：石牆要塞、戰爭要塞
```

### 2. 建築卡的破壞機制

#### 如何破壞建築卡？

**方法 1：攻城動作（主要方式）⭐**

當首領執行「攻城」動作時，可以選擇以下目標之一：

```
攻城目標選擇（3 選 1）：

a) 築城計數器
   - 築城計數器 -1
   - 如果歸 0，可以繼續前進

b) 建築卡 ⭐⭐⭐
   - 選擇該區域的 1 張建築卡
   - 建築堅韌度 -1
   - 如果建築堅韌度歸 0：
     * 建築卡被破壞
     * 觸發「被破壞時」效果（onDestroy）
     * 建築卡進入墓地

c) 獸穴生命值（僅限敵方基地且築城 = 0）
   - 獸穴HP - 對敵力
   - 如果獸穴HP歸 0 → 我方勝利
```

**戰略意義：**
- 玩家需要決定：先破壞築城？還是先破壞建築？
- 某些建築的地利效果很強，優先破壞
- 某些建築的破壞效果很危險，避免破壞

**方法 2：特殊效果（卡牌效果）**

某些卡牌可能有「直接破壞建築」的效果：
```typescript
// 範例效果
effect: {
  type: 'destroy_building',
  target: 'zone_enemy_building',
  description: '破壞當前區域 1 張敵方建築卡'
}
```

### 3. 破壞效果（onDestroy）

**定義：**
- 建築卡被破壞時觸發的**一次性效果**
- 在建築卡進入墓地前執行
- 無法被取消或反制（已確定破壞）

**觸發時機：**
```
1. 建築堅韌度降至 0
2. 立即執行 onDestroy 效果
3. 建築卡進入墓地
4. 地利效果（areaEffect）停止生效
```

**設計類型：**

#### 類型 1：補償效果（Compensation）
建築被破壞時，給予玩家補償

```typescript
// 元素祭壇
onDestroy: {
  type: 'heal_all',
  value: 1,
  target: 'all_allies',
  description: '所有我方首領堅韌+1'
}
// 設計理念：建築被破壞了，但至少治療了友軍

// 魔力泉水
onDestroy: {
  type: 'draw',
  value: 3,
  target: 'self',
  description: '抽 3 張牌'
}
// 設計理念：失去經濟建築，但獲得手牌資源
```

#### 類型 2：報復效果（Retaliation）
建築被破壞時，對敵人造成傷害

```typescript
// 火焰陷阱
onDestroy: {
  type: 'area_damage',
  value: 3,
  target: 'zone_all_enemies',
  description: '對當前區域所有敵首領造成 3 點傷害'
}
// 設計理念：陷阱被觸發，爆炸造成範圍傷害

// 戰爭要塞
onDestroy: {
  type: 'attack_bonus',
  value: 3,
  target: 'all_allies',
  duration: 'turn',
  description: '所有我方首領本回合對敵+3'
}
// 設計理念：要塞淪陷，激發全軍怒火
```

#### 類型 3：戰略效果（Strategic）
建築被破壞時，改變場地狀態

```typescript
// 石牆要塞
onDestroy: {
  type: 'build_fortification',
  value: 1,
  target: 'my_base',
  description: '我方基地築城計數器+1'
}
// 設計理念：要塞倒塌，但碎石可以重建防禦

// 築城工坊
onDestroy: {
  type: 'build_fortification',
  value: 1,
  target: 'all_my_zones',
  description: '所有我方區域築城計數器+1'
}
// 設計理念：工坊被毀，但工人分散到各處繼續築城
```

#### 類型 4：召喚效果（Summon）
建築被破壞時，召喚單位

```typescript
// 復活祭壇（假設範例）
onDestroy: {
  type: 'revive',
  target: 'random_ko_ally',
  description: '立即復活 1 位 KO 狀態的我方首領'
}
// 設計理念：祭壇被毀，釋放的能量復活了一位首領
```

### 4. 地利效果（Area Effect）

**定義：**
- 建築卡在場時，持續生效的區域效果
- 只影響建築所在的區域
- 建築被破壞後，地利效果立即停止

**與破壞效果的區別：**
```
地利效果（areaEffect）：
- 持續生效（建築在場時）
- 影響區域內的單位
- 建築被破壞後停止

破壞效果（onDestroy）：
- 一次性效果（建築被破壞時）
- 可以影響全場或其他區域
- 執行後建築進入墓地
```

**範例對比：**
```typescript
// 龍族聖殿
{
  // 地利效果：持續生效
  areaEffect: {
    name: '龍族庇護',
    description: '區域內所有 dragon tag 首領堅韌+1，對敵+1',
    effect: {...},
    target: 'ally'
  },
  
  // 破壞效果：一次性
  onDestroy: {
    type: 'draw',
    value: 2,
    description: '抽 2 張牌'
  }
}

// 遊戲流程：
// 1. 龍族聖殿在場 → dragon tag 首領獲得 +1/+1
// 2. 敵人攻城破壞聖殿 → 抽 2 張牌
// 3. 聖殿進入墓地 → dragon tag 首領失去 +1/+1 加成
```

### 5. 建築卡的戰略價值

#### 防禦建築的兩難選擇

**敵人的困境：**
```
情況：敵方場上有「石牆要塞」（堅韌 3）

選項 A：先破壞築城計數器
- 優點：可以快速前進
- 缺點：敵方首領持續獲得防禦加成

選項 B：先破壞石牆要塞
- 優點：移除敵方防禦加成
- 缺點：需要 3 次攻城，敵方還會獲得築城+1（破壞效果）

戰略決策：
- 如果我方對敵力高，優先破壞建築（移除加成）
- 如果我方對敵力低，優先破壞築城（快速前進）
```

#### 進攻建築的風險管理

**玩家的考量：**
```
情況：我方想在敵方戰場放置「火焰陷阱」

風險：
- 堅韌度只有 1，容易被破壞
- 被破壞時會造成 3 點範圍傷害

策略：
- 如果我方首領在該區域 → 不要放置（會傷到自己）
- 如果只有敵方首領在該區域 → 可以放置（敵人破壞會自傷）
- 如果該區域無人 → 可以放置（作為陷阱等待敵人進入）

心理博弈：
- 敵人知道破壞陷阱會受傷，可能選擇繞過
- 但繞過意味著放棄該區域的控制權
```

### 6. 建築卡的放置策略

#### 放置位置的選擇

**我方基地（my_base）：**
```
適合建築類型：
- 防禦型：保護獸穴
- 經濟型：安全的資源生產
- 特殊型：復活祭壇、築城工坊

優點：
- 安全，不易被破壞
- 可以長期提供地利效果

缺點：
- 不影響前線戰鬥
- 無法直接壓制敵人
```

**我方戰場（my_battlefield）：**
```
適合建築類型：
- 防禦型：前線防禦
- 輔助型：支援前線首領
- 進攻型：攻城加成

優點：
- 影響前線戰鬥
- 支援進攻首領

缺點：
- 容易被敵人攻擊
- 需要保護
```

**敵方戰場（enemy_battlefield）：**
```
適合建築類型：
- 進攻型：攻城塔、火焰陷阱
- 控制型：減益效果

優點：
- 直接壓制敵人
- 控制敵方區域

缺點：
- 非常容易被破壞
- 需要先破壞築城計數器才能放置
- 破壞效果可能傷到自己
```

**敵方基地（enemy_base）：**
```
適合建築類型：
- 進攻型：持續傷害
- 控制型：阻礙敵人

優點：
- 最大化壓制效果
- 接近勝利目標

缺點：
- 最難放置（需要突破重重防線）
- 極易被破壞
```

### 7. 設計原則

#### 破壞效果的設計平衡

**原則 1：補償與風險平衡**
```
堅韌度低 → 破壞效果強
- 火焰陷阱（堅韌 1）→ 破壞時造成 3 點範圍傷害
- 魔力泉水（堅韌 1）→ 破壞時抽 3 張牌

堅韌度高 → 破壞效果弱
- 石牆要塞（堅韌 3）→ 破壞時築城+1
- 戰爭要塞（堅韌 3）→ 破壞時全軍對敵+3（1 回合）
```

**原則 2：地利效果與破壞效果的關係**
```
地利效果強 → 破壞效果補償型
- 龍族聖殿（地利：+1/+1）→ 破壞時抽 2 張牌
- 元素祭壇（地利：堅韌+2）→ 破壞時全軍堅韌+1

地利效果弱 → 破壞效果報復型
- 火焰陷阱（地利：每回合 1 點傷害）→ 破壞時 3 點範圍傷害
```

**原則 3：避免必破建築**
```
❌ 錯誤設計：
onDestroy: {
  description: '抽 10 張牌，所有首領堅韌+5'
}
// 太強，敵人會故意破壞

✅ 正確設計：
onDestroy: {
  description: '抽 2 張牌'
}
// 合理補償，但不至於讓敵人想破壞
```

### 8. 常見問題 FAQ

**Q1：建築卡可以被「對敵」動作攻擊嗎？**
A：不行。建築卡只能被「攻城」動作攻擊，或被特殊效果破壞。

**Q2：一個區域可以有多少張建築卡？**
A：每個區域最多 2 張建築卡。

**Q3：建築卡的地利效果會疊加嗎？**
A：會。如果一個區域有 2 張建築卡，兩個地利效果都會生效。

**Q4：破壞效果可以被反制嗎？**
A：不行。一旦建築堅韌度歸 0，破壞效果必定觸發。

**Q5：建築卡被破壞後，可以復活嗎？**
A：目前設計中沒有復活建築卡的機制。建築卡進入墓地後，只能通過「搜尋墓地」等效果重新拿回手牌。

**Q6：攻城時，必須先破壞築城計數器才能攻擊建築卡嗎？**
A：不需要。玩家可以自由選擇攻擊目標（築城計數器或建築卡）。

**Q7：如果建築卡的破壞效果會傷到自己，還會觸發嗎？**
A：會。破壞效果無條件觸發，即使會傷到自己。這是放置進攻型建築的風險。

**Q8：建築卡可以主動犧牲嗎？**
A：目前設計中沒有主動犧牲建築的機制。但未來可以設計相關卡牌效果。

## 🎯 設計總結

建築卡系統的核心設計理念：

1. **戰略深度**：攻城時的目標選擇（築城 vs 建築）
2. **風險管理**：進攻型建築的破壞效果可能傷到自己
3. **資源交換**：犧牲建築卡的代價，換取破壞效果的收益
4. **心理博弈**：敵人是否敢破壞你的建築？
5. **多樣性**：不同類型建築提供不同的戰術選擇
