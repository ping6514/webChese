## 9. 成本分級（Cost Tiers）

### 低成本（Low Cost）

**消耗：無 或 任*1**

```
適用效果：
- 抽 1 張牌
- 堅韌 +2（本回合）
- 對敵 +2（本回合）
- 移動 1 次
- 築城計數器 +1
- 協助 +1
```

### 中成本（Medium Cost）

**消耗：技*1 或 任*2**

```
適用效果：
- 抽 2 張牌
- 堅韌 +3（本回合）
- 對敵 +3（本回合）
- 範圍傷害 2-3
- 特殊召喚 1 個軍團
- 築城計數器 +2
- 移動到任意區域
- 破壞 1 個軍團
```

### 高成本（High Cost）

**消耗：技*2 或 技*1+任*2**

```
適用效果：
- 抽 3 張牌
- 立即復活首領
- 範圍傷害 4-5
- 破壞所有敵方軍團
- 獸穴HP +2
```
