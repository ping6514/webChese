**主題**：奇幻國戰 + 魔物娘  
**版本**：3.0

## 📋 遊戲概述

### 世界觀

在這個世界，各個魔物種族為了爭奪領地而戰。每個種族由強大的魔物娘首領統領，她們率領各自的軍團，攻略敵方的獸穴。

### 勝利條件

**將敵方獸穴生命值降至 0 → 我方勝利** ⭐

### 混合組牌規則 ⭐⭐⭐

**核心原則：Tags 系統為主，種族為輔**

```
組牌自由度：
- 4 位首領可以來自任意種族
- 牌組（40-60 張）可以混合種族
- 沒有種族數量限制

Tags 觸發機制：
- 卡牌效果基於 Tags 觸發，不限制種族
- 例如：「flying tag 首領」而非「龍族首領」
- 例如：「elemental tag 軍團」而非「龍族軍團」

種族的用途：
- 作為 Tag 的一種（dragon, harpy, lamia 等）
- 可以作為被動能力的開啟條件
- 但不應該是卡牌效果的唯一觸發條件

範例：
✅ 正確：「區域內所有 flying tag 首領對敵+2」
✅ 正確：「如果首領有 elemental tag，受到傷害-1」
❌ 錯誤：「只有龍族首領可以使用」
❌ 錯誤：「只有同種族軍團才能安裝」

優勢：
- 最大化策略深度和組牌多樣性
- 跨種族協同成為可能
- 玩家可以根據 Tags 組合不同種族的首領
- 例如：flying 隊（龍族+哈比族）
- 例如：elemental 隊（龍族+史萊姆族+海族）
```

### 場地元素

**築城計數器** ⭐
- 初始值：2
- 上限：2
- 每個區域獨立
- 功能：阻擋移動、保護獸穴

**獸穴生命值** ⭐
- 初始值：4
- 只有基地有
- 勝利條件：敵方獸穴HP歸0

**建築卡槽位** ⭐
- 每個區域最多 2 張建築卡
- 提供地利效果

### 區域說明

**我方基地**：
- 起始位置（4位首領）
- 有獸穴生命值（4）
- 有築城計數器（初始2）
- 可放置建築卡（最多2張）

**我方戰場**：
- 前線區域
- 有築城計數器（初始2）
- 可放置建築卡（最多2張）

**敵方戰場**：
- 敵方前線
- 有築城計數器（初始2）
- 可放置建築卡（最多2張，需要先破壞築城計數器）

**敵方基地**：
- 攻略目標
- 有獸穴生命值（4）
- 有築城計數器（初始2）
- 可放置建築卡（最多2張）

### 首領配置

```
對戰模式：4 位首領（固定）
單機模式：1-4 位首領（隨關卡增加）
```

### 首領卡結構

```typescript
type LeaderCard = {
  id: string
  name: string
  race: RaceType
  class: ClassType
  
  // 基礎屬性
  baseToughness: number  // 堅韌度
  baseAttack: number     // 對敵力
  baseSupport: number    // 協助力

  tags: Tag[]
  
  // 被動能力（自動生效）
  passive: {

    effect: Effect
  }
  
  // 主動技能（時機點掛勾）⭐
  skill: {

    timing: SkillTiming[]  // 準備階段/行動階段等
    cost: Cost
    cooldown: number
    effect: Effect[]
  }
  
  // 連動支援（聯合攻擊時觸發）
```

### 種族系統（6 種）⭐ 魔物娘主題

```
1. 哈比族（Harpy）
   - 主題：鳥人、翼人
   - 特色：高機動、空中優勢
   - 協同：移動後對敵+2，移動時無視築城計數器
   - 代表色：天藍色

2. 拉米亞族（Lamia）
   - 主題：蛇人、娜迦
   - 特色：詛咒、控制
   - 協同：對敵時敵人下回合無法移動，負面狀態持續+1
   - 代表色：紫色

3. 龍族（Dragon）
   - 主題：龍娘、龍人
   - 特色：高攻擊、高堅韌
   - 協同：對敵+1，攻城額外-1築城計數器
   - 代表色：紅色

4. 史萊姆族（Slime）
   - 主題：史萊姆娘
   - 特色：分裂、復原
   - 協同：軍團被擊破時召喚2個小史萊姆，堅韌度低於一半時堅韌+2
   - 代表色：綠色

5. 半人馬族（Centaur）
   - 主題：馬娘、鹿娘
   - 特色：突襲、踐踏
   - 協同：移動後對敵+3，可連續移動2次
   - 代表色：棕色

6. 海族（Aquatic）
   - 主題：人魚、海龍、魚人
   - 特色：治療、水流
   - 協同：每回合回復堅韌度1，協助力+2
   - 代表色：藍色
```

### 職業系統（4 種）

```
1. 破壞者（Destroyer）
   - 特色：攻城、範圍攻擊
   - 代表種族：龍族、史萊姆族

2. 征服者（Conqueror）
   - 特色：高機動、單體爆發
   - 代表種族：哈比族、半人馬族

3. 統御者（Commander）
   - 特色：遠程、控制、輔助
   - 代表種族：拉米亞族、海族

4. 守護者（Guardian）
   - 特色：高防禦、築城
   - 代表種族：龍族、史萊姆族
   - 特殊能力：可透過技能築城
```

### 首領狀態 ⭐

```
1. 普通狀態（Normal）
   - 可正常行動
   - 可提供協助力
   - 可參與聯合攻擊

2. 暈眩狀態（Stunned）
   - 無法主動行動
   - 可提供協助力（被動）
   - 可參與聯合攻擊（被動）
   - 可被收割
   - 下回合開始時自動恢復為普通狀態 ⭐

3. KO 狀態（KO）⭐
   - 立即退回我方基地
   - 無法行動
   - 無法提供協助力
   - 無法參與聯合攻擊
   - 無法被攻擊（在基地內）
   - 所有軍團觸發「首領被擊破時」效果
   - koTurnCount 計數

4. 復活中狀態（Reviving）⭐
   - 準備階段開始時復活在我方基地
   - 狀態變為普通
```

## ⚔️ 軍團系統

### 軍團堆疊機制 ⭐⭐

```
軍團卡是真正的裝備卡：
- 軍團屬性堆疊到首領
- 堅韌度、對敵力、協助力加成
- 首領總屬性 = 基礎屬性 + 所有軍團加成

範例：
炎龍女王：堅韌5 / 對敵3 / 協助2
+ 炎龍戰士：堅韌+2 / 對敵+1 / 協助+0
+ 炎龍法師：堅韌+1 / 對敵+0 / 協助+2
= 總屬性：堅韌8 / 對敵4 / 協助4 ⭐
```

### 軍團卡結構

```typescript
type LegionCard = {
  id: string
  name: string
  race: RaceType
  type: LegionType
  rank: 'normal' | 'elite' | 'legendary'
  
  // Tags 系統
  tags: Tag[]
  
  // ⭐ 屬性加成（堆疊到首領）
  bonusStats: {
    toughness: number
    attack: number
    support: number
  }
  
  // 召喚需求（升級召喚）
  summonCost?: {
    tributeCount: number
    tributeRace?: RaceType
  }
  
  // 被動能力（自動生效）
  passive: {
    name: string
    effect: Effect
  }
  
  // 主動技能（功能性，時機點掛勾）⭐
  activeSkill?: {
    name: string
    timing: SkillTiming[]
    cost: Cost
    cooldown: number
    effect: Effect
  }
  
  // 犧牲技能（捨棄本卡發動）
  sacrificeSkill?: {
    name: string
    effect: Effect
  }
  
  // ⭐ 首領被擊破時的處理
  onLeaderKO?: {
    type: 'discard' | 'keep' | 'choice'
    cost?: Cost
    effect?: Effect
  }
}
```

### 軍團等級系統

```
普通軍團（Normal）：
- 屬性加成：堅韌+1~2 / 對敵+0~1 / 協助+0~1
- 召喚需求：無

精英軍團（Elite）：
- 屬性加成：堅韌+2~3 / 對敵+1~2 / 協助+1~2
- 召喚需求：獻祭 1 個軍團

傳說軍團（Legendary）：
- 屬性加成：堅韌+3~4 / 對敵+2~3 / 協助+2~3
- 召喚需求：獻祭 2 個軍團
```

### 軍團召喚系統

```
a) 通常召喚（1 回合 1 次）
   - 從手牌召喚軍團卡到首領
   - 安裝到軍團槽
   - 屬性堆疊到首領

b) 特殊召喚（依效果觸發）
   - 通過技能/事件/建築效果
   - 可從手牌/墓地/牌組召喚
   - 不計入通常召喚次數

c) 升級召喚（獻祭召喚）
   - 獻祭場上的軍團
   - 召喚更強大的軍團
   - 不計入通常召喚次數
```

## 🎴 戰術卡系統（反應卡）⭐⭐

### 戰術卡特性

```
- 消耗品（觸發後進墓地）⭐
- 面朝下安裝（隱藏資訊）⭐
- 對手不知道戰術卡種類
- 觸發時機多樣
- 1 位首領最多 1 張戰術卡
```

### 戰術卡結構

```typescript
type TacticalCard = {
  id: string
  name: string
  
  // ⭐ 觸發時機（反應卡的核心）
  trigger: {
    timing: TriggerTiming
    condition?: (context: GameContext) => boolean
  }
  
  // 效果
  effect: Effect[]
  
  // 消耗（觸發時需要支付）
  cost?: Cost
  
  // 隱藏資訊 ⭐
  hidden: true
}
```

### 觸發時機

```typescript
type TriggerTiming = 
  // 攻擊相關
  | 'on_attack'           // 首領攻擊時
  | 'on_attacked'         // 首領被攻擊時
  | 'on_damage'           // 首領受到傷害時
  | 'on_stunned'          // 首領被暈眩時
  | 'on_ko'               // 首領被收割時
  
  // 移動相關
  | 'on_move'             // 首領移動時
  | 'on_enemy_move'       // 敵人移動時
  
  // 召喚相關
  | 'on_summon_legion'    // 召喚軍團時
  | 'on_legion_destroyed' // 軍團被擊破時
  
  // 回合相關
  | 'on_turn_start'       // 回合開始時
  | 'on_turn_end'         // 回合結束時
  
  // 其他
  | 'on_draw'             // 抽牌時
  | 'on_fortification_destroyed' // 築城計數器被破壞時
```

## 🏗️ 建築卡系統 ⭐⭐

### 建築卡特性

```
- 有獨立的建築堅韌度（1-3）⭐
- 提供地利效果（區域內持續生效）
- 可以被攻城破壞
- 每個區域最多 2 張建築卡
- 可以放置在敵方戰場（進攻型建築）
```

### 建築卡結構

```typescript
type BuildingCard = {
  id: string
  name: string
  category: BuildingCategory
  
  // ⭐ 代價（可選）
  cost?: {
    discardCount?: number  // 丟棄手牌數量
    fortificationCost?: number  // 消耗築城計數器
  }
  
  // ⭐ 放置條件（可選）
  placementCondition?: {
    myFortification?: {
      min?: number  // 我方該區域築城計數器最小值
      max?: number  // 我方該區域築城計數器最大值
    }
    enemyFortification?: {
      min?: number  // 敵方該區域築城計數器最小值
      max?: number  // 敵方該區域築城計數器最大值
    }
  }
  
  // 建築堅韌度
  buildingToughness: 1 | 2 | 3
  
  // 放置位置限制
  placement: PlacementZone[]
  
  // ⭐ 地利效果（區域內持續生效）
  areaEffect: {
    name: string
    description: string
    effect: Effect
    target: 'ally' | 'enemy' | 'all'
  }
  
  // 被動能力（全局效果）
  passive?: {
    name: string
    effect: Effect
  }
  
  // 被破壞時效果
  onDestroyed?: {
    effect: Effect
  }

type PlacementZone = 
  | 'my_lair'
  | 'my_battlefield'
  | 'enemy_battlefield'

type BuildingCategory = 
  | 'defense'    // 防禦型
  | 'economy'    // 經濟型
  | 'offense'    // 進攻型
  | 'support'    // 輔助型
  | 'special'    // 特殊型
```

## 🎯 築城/攻城系統 ⭐⭐⭐

### 築城計數器

```
築城計數器：
- 每個區域獨立（0-2）
- 初始值：2 ⭐
- 上限：2
- 只能透過特殊效果增加（技能/事件卡/建築卡）
- 規則不會主動提供增加機會

功能：
1. 阻擋移動
   - 築城計數器 ≥ 1 → 敵人無法移動到下個區域

2. 保護獸穴
   - 我方基地築城計數器 ≥ 1 → 敵人無法攻擊獸穴HP
```

### 攻城動作 ⭐

```
執行「攻城」通常動作時，選擇目標：

a) 築城計數器
   - 築城計數器 -1
   - 如果築城計數器歸 0：
     * 可以移動到下個區域
     * 可以攻擊獸穴HP（如果在敵方基地）

b) 建築卡（如果該區域有建築卡）⭐
   - 選擇 1 張建築卡
   - 建築堅韌度 -1
   - 如果建築堅韌度歸 0：
     * 建築卡被破壞
     * 觸發「被破壞時」效果
     * 建築卡進入墓地

c) 獸穴生命值（如果在敵方基地且築城計數器 = 0）⭐
   - 獸穴HP - 對敵力
   - 如果獸穴HP歸 0 → 我方勝利
```

### 優先級規則 ⭐⭐

```
優先級層級（從高到低）：

1. 強制觸發效果（Mandatory）
   - 被動能力
   - 自動觸發的效果
   - 無法選擇是否觸發

2. 可選觸發效果（Optional）
   - 主動技能
   - 戰術卡
   - 可以選擇是否觸發

3. 延遲觸發效果（Delayed）
   - 「下回合」、「回合結束時」等
   - 在特定時機才觸發

優先級順序：
強制觸發 > 可選觸發 > 延遲觸發
```

### 同時觸發處理 ⭐⭐⭐

```
當多個效果同時觸發時：

規則 1：回合玩家優先
- 當前回合的玩家先處理自己的效果
- 然後對手處理自己的效果

規則 2：同一玩家的效果
- 強制觸發效果先處理
- 可選觸發效果後處理
- 玩家選擇處理順序

規則 3：效果堆疊
- 後觸發的效果先結算（堆疊）
- 類似遊戲王的連鎖系統

範例：
1. 我方首領 A 攻擊敵方首領 B
2. 觸發：
   - 首領 A 的「攻擊時」技能（我方，可選）
   - 首領 B 的「被攻擊時」戰術卡（敵方，可選）
   - 首領 A 的「造成傷害時」被動（我方，強制）

處理順序：
a) 我方回合，我方優先
b) 我方強制觸發：首領 A 的「造成傷害時」被動
c) 我方可選觸發：首領 A 的「攻擊時」技能（玩家選擇是否觸發）
d) 敵方可選觸發：首領 B 的「被攻擊時」戰術卡（對手選擇是否觸發）
e) 按堆疊順序結算（後進先出）
```

### 時機點詳細說明

```
準備階段開始時（preparation_start）：
- 復活處理

- 移動：執行移動
- 移動後：觸發「移動後」效果
- 攻擊前：觸發「攻擊前」效果
- 攻擊：執行攻擊
- 攻擊後：觸發「攻擊後」效果
```

## � 完整遊戲流程

### 遊戲開始

```
1. 雙方選擇 4 位首領
2. 雙方準備牌組（40-60 張）
3. 決定先攻/後攻
4. 雙方洗牌
5. 先攻抽 5 張，後攻抽 7 張
6. 可進行 1 次調度（全部洗回重抽）
7. 4 位首領全部配置在我方基地，狀態為 'normal'
8. 所有區域築城計數器 = 2 ⭐
9. 雙方獸穴生命值 = 4 ⭐
10. 先攻玩家開始第 1 回合
```

### 回合流程

#### Step 1：準備階段

```
1. 復活處理
   - 'reviving' 狀態首領復活在我方基地
   - 狀態變為 'normal'

2. 抽 2 張牌 ⭐

3. 暈眩恢復
   - 所有 'stunned' 狀態首領變為 'normal' ⭐

4. 技能使用（準備階段時機）
   - 首領技能（不占行動次數）⭐
   - 例如：築城、抽牌、buff
```

#### Step 2：主要階段

```
1. 打出建築卡（1 張）
   - 選擇放置的區域
   - 建築卡進入場地
   - 地利效果開始生效
   - 每個區域最多 2 張建築卡

2. 打出事件卡（複數）
   - 立即執行效果
   - 事件卡進入墓地
```

#### Step 3：行動階段 ⭐⭐

```
固定 2 次行動 ⭐

每次行動：
1. 選擇行動類型：
   a) 單獨行動（1 位首領）
      - 同區域其他首領提供協助力 ⭐
      - 檢查連動支援
   
   b) 聯合攻擊（2 位首領，同區域）⭐
      - 消耗 1 次行動
      - 兩位首領都參與
      - 檢查連動支援
      - 對敵力和協助力堆疊

2. 移動首領
   - 移動到相鄰區域
   - 限制：如果目標區域有築城計數器 ≥ 1，無法移動

3. 執行通常動作（3 選 1）：
   a) 對敵（敵方首領）
   b) 攻城（築城計數器/建築卡/獸穴HP）⭐
   c) 收割（暈眩首領 → KO）

4. 技能使用（行動階段時機）
   - 首領技能（不占行動次數）⭐
```

#### Step 4：裝備階段

```
1. 安裝戰術卡（不限次數）
   - 從手牌打出
   - 面朝下安裝到任一首領 ⭐
   - 1 位首領最多 1 張戰術卡

2. 召喚軍團卡（堆疊到首領）⭐
   - 通常召喚（1 回合 1 次）
   - 特殊召喚（依效果）
   - 升級召喚（獻祭）
   - 軍團屬性堆疊到首領
```

#### Step 5：結束階段

```
1. 手牌上限處理
   - 手牌 > 6 張 → 玩家選擇捨棄到 6 張 ⭐

2. 技能冷卻 -1

3. KO 狀態處理
   - koTurnCount++
   - 達到復活時間 → 'reviving'

4. 回合交給對手
```

## ⚔️ 戰鬥系統詳解

### 對敵判定流程

```
1. 宣告攻擊目標（敵首領）
2. 計算總傷害：
   - 單獨行動：(首領對敵 + 軍團對敵) + (同區域首領協助 + 軍團協助)
   - 聯合攻擊：(首領A對敵 + 首領B對敵 + 軍團對敵) + 連動支援加成
3. 傷害判定：
   - 傷害 < 總堅韌度 → 無事
   - 傷害 ≥ 總堅韌度 → 暈眩（Stunned）
   - 傷害 ≥ 總堅韌度 × 2 → 收割（KO）
   - 已暈眩再受傷 → 收割（KO）
4. 首領被收割處理：
   - 立即回到我方基地
   - 狀態變為 'ko'
   - 每個軍團結算「首領被擊破時」效果 ⭐
   - 觸發首領被擊破效果（如果有）
5. 觸發戰術卡（如果有）⭐
```

### 聯合系統 ⭐

```
單獨行動：
- 1 位首領主動行動
- 同區域其他首領提供協助力（被動）
- 檢查連動支援

聯合攻擊：
- 2 位首領主動參與（消耗 1 次行動）
- 兩位首領的對敵力和協助力堆疊
- 檢查兩位首領的連動支援
- 連動支援加成疊加

範例：
- 2 次單獨行動 = 2 位首領主動 + 其他首領被動協助
- 2 次聯合攻擊 = 4 位首領都參與（每次 2 位）
- 1 次聯合 + 1 次單獨 = 3 位首領參與
```
